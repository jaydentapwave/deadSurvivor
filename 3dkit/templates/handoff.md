# 단계 인수인계 양식

단계가 끝날 때 현재 상태(프로젝트의 `docs/현재상태.md`)의 해당 행이나 작업 기록에 아래 항목을 짧게 쓴다. 새 세션은 이것과 [핵심 규칙](../workflows/core-rules.md)만 읽고 시작할 수 있어야 한다. 근거: [핵심 규칙 4절](../workflows/core-rules.md#4-단계마다-새-대화).

- **끝난 것:** 게임에 들어간 것 / 시험 장면 / 문서. 장면·파일 경로.
- **검증 상태:** 단계별 PASS·FAIL·NOT_RUN과 근거 경로. 마지막 전체 PASS 실행 ID(`tier.py plan` 결과).
- **사용자 결정:** 이번 단계에서 사용자가 정한 것(원문 짧게)과 아직 물어야 할 것.
- **다음 할 일:** 첫 작업 1~3개와 완료 조건.
- **주의:** 열려 있는 위험, 알려진 결함, 비용(크레딧 등) 잔액.
- **시간·토큰:** `session_time_*.py` 같은 집계가 있으면 이번 단계 수치 한 줄.
