# 데드 서바이버 개발

저장소 [AGENTS](../../../AGENTS.md)와 [개발 워크플로우](../../../docs/workflows/development.md)를 읽는다. 파일 경로는 이 스킬 폴더 기준이다.

요청을 L0/L1/L2로 분류하고 해당 절차를 수행한다. L2는 구현 전 design-reviewer, L1/L2는 구현 후 validator-client 독립 서브에이전트 검토를 수행한다. 계산 변경에는 algorithm-tester 계약도 적용한다. 역할 지침은 개발 워크플로우의 링크로 읽는다. 서브에이전트는 관련 로컬 파일만 읽고 메인에게 보고하며 외부 서비스를 쓰거나 파일을 수정하지 않는다.

리뷰어에게 사용자 요청, 브리핑/변경 파일, 관련 기획, 실제 검증 결과와 미실행 항목을 전달한다. 검토 결과를 미리 유도하지 않는다. 모델은 현재 설정을 상속한다. 독립 검토가 불가능하면 BLOCKED로 보고한다.

메인이 구현과 지적 수정을 담당한다. 로컬 검사는 저장소에서 `python3 Tools/Verify/run.py local`로 실행한다. 런타임 검사는 unity-cli 스킬을 읽고 대상 프로젝트를 확인한 다음 수행한다. 로컬 정적 PASS만으로 게임 검증 완료를 주장하지 않는다.

결과와 결정은 저장소 docs/reviews, docs/decisions에만 남긴다. 커밋/게시나 회사 서비스 연결은 실행하지 않는다.
