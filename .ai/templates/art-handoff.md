# 단계 인수인계 양식

단계가 끝날 때 현재 상태(프로젝트의 `docs/현재상태.md`)의 해당 행이나 작업 기록에 아래 항목을 짧게 쓴다. 새 세션은 이것과 [핵심 규칙](../rules/art-core-rules.md)만 읽고 시작할 수 있어야 한다. 근거: [핵심 규칙 4절](../rules/art-core-rules.md#4-단계마다-새-대화).

현재 상태 문서에는 **지금 인수인계 하나만** 둔다. 새 인수인계를 쓰면 이전 인수인계와 날짜별 진행 기록은 이력 문서(예: `docs/현재상태-이력.md`) 맨 위로 옮긴다. 이미 끝난 항목을 줄 긋기로 남겨 두지 않는다. 계기(2026-11-04): 현재 상태 문서가 날짜별 기록과 지난 인수인계를 겹겹이 쌓아 250줄이 되었고, 새 세션이 지금 할 일을 찾기 어려웠다.

- **끝난 것:** 게임에 들어간 것 / 시험 장면 / 문서. 장면·파일 경로.
- **범위 대조:** 기준서 에셋 목록(3.3절)과 기획서의 종류·개수 표를 행마다 대조한다. 숫자는 쓰기 직전에 파일·데이터에서 다시 센다. 차이가 남아 있으면 "완료"라고 쓰지 않는다([핵심 규칙 6절](../rules/art-core-rules.md)).

  | 기준 문서 행 | 기준 | 지금 게임 | 차이 | 차이를 정한 사람(원문·날짜) |
  |---|---|---|---|---|
- **검증 상태:** 단계별 PASS·FAIL·NOT_RUN과 근거 경로. 마지막 전체 PASS 기록(`play_check.py full`이 `<probe_dir>/full-log.txt`에 남긴 PASS 줄).
- **사용자 결정:** 이번 단계에서 사용자가 정한 것(원문 짧게)과 아직 물어야 할 것.
- **진행 중인 작업 단위:** 에셋·클립마다 단계 기록 표의 위치와 지금 단계(3D 동작은 `.ai/rules/3d-animation.md` 3절, 3D 모델은 `/3d-art-produce`). 다른 세션이 진행 중인 단위도 아는 만큼 적는다.
- **다음 할 일:** 첫 작업 1~3개와 완료 조건.
- **세션 간 요청:** 같은 프로젝트를 여러 세션(예: 아트·시스템)이 나눠 할 때, 서로 기다리는 일을 한 표로 적는다.

  | 요청한 쪽 | 받을 쪽 | 무엇 | 상태(대기·진행·확인 필요·끝남) | 근거 |
  |---|---|---|---|---|
- **주의:** 열려 있는 위험, 알려진 결함, 비용(크레딧 등) 잔액.
- **시간·토큰:** 시간·토큰 집계(3D 팩: `.ai/3d-art/tools/session_time.py`)가 있으면 이번 단계 수치 한 줄.
