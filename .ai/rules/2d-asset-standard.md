# 2D 에셋 규격 — 임포트·폴더·이름

2d-art 팩 규칙. 스프라이트를 프로젝트에 넣거나 임포트 설정을 바꿀 때 읽는다. 프로젝트 정책(예외 경로, 배율, 이름 유일성)은
`Assets/Game/03.Resources/Art/CLAUDE.md`가 정하고, 그 문서와 이 규칙이 부딪히면 그 문서를 따른다.

## 1. 임포트 규약은 프리셋 하나

- 스프라이트 임포트 규약의 원본은 Preset + Preset Manager 경로 필터다. 개별 `.meta`를 손으로 고치지 않는다 —
  규약을 바꾸려면 프리셋을 고치고 폴더를 재임포트한다. 임포트 문제를 보면 `.meta`보다 프리셋을 먼저 의심한다
  (출처 프로젝트: 잘못 저장된 프리셋이 새 에셋을 계속 오염시켰다).
- **Preset Manager는 경로가 맞는 프리셋을 위에서부터 모두 적용하고 마지막 것이 이긴다.** 좁은 경로의 예외 프리셋은 일반 프리셋보다
  목록 **뒤**에 둔다(출처 사례: 좁은 필터를 앞에 두자 일반 프리셋의 PPU 200이 예외 PPU 100을 덮었다). 프리셋 대조 검사가 있으면 이 순서도 보게 한다.
- **기본 프리셋은 새로 들어오는 그림에만 적용된다.** 목록을 고친 뒤 다시 임포트해도 이미 들어온 그림은 그대로다 — 그 그림들에는
  `Preset.ApplyTo`를 한 뒤 다시 임포트한다. 목록을 고쳤으면 새 그림 1장을 넣어 값이 붙는지 확인한다.
- PPU·피벗·Full Rect 예외는 `Assets/Game/03.Resources/Art/CLAUDE.md` 예외 표에 경로로 적는다. 프로젝트에 프리셋 대조 검사가 있으면 그 검사를 통과시킨다.
- 모바일 플랫폼 블록은 `overridden: 1`과 최대 크기·압축을 명시한다. `overridden: 0`이면 플랫폼 값은 무시되고 Default가 쓰인다
  (출처: 전 텍스처가 무시돼 모바일 110.8MB, 교정 후 22.5MB).
- Sliced·Tiled로 그리는 그림은 Full Rect.

## 2. 폴더와 출처

- AI가 만들거나 편집·분할한 그림은 `Assets/Game/03.Resources/Art/AIGenerated/` 아래에만 둔다. 디자이너 원화와 섞지 않는다.
- 그림 옆에 `source.txt`: 도구·모델·세션, 참고 그림 경로와 sha256, 최종 프롬프트, 후처리, `measure.py` 판정.
  출처를 모르는 그림을 겉모습만으로 분류하지 않는다.
- PSD는 넣지 않는다. 그룹별로 나눈 PNG만.

## 3. 이름

- 이름 변경은 `AssetDatabase.RenameAsset`/`MoveAsset`으로 GUID를 보존한다. 경로·이름을 직접 쓰는 코드·데이터도 같이 고친다.
- 같은 이름 덮어쓰기는 GUID 참조라 참조처가 자동으로 바뀐다 — 그림과 자리의 대응표(두 번째 진실)를 따로 만들지 않는다.
- 코드가 이름(키)으로 그림을 고르면 그 범위에서 파일명이 유일해야 한다. 범위는 `Assets/Game/03.Resources/Art/CLAUDE.md` 정책 표.

## 4. 원본은 시안 그대로

- 화면 모양이 바뀌는 최적화(원본 축소, 여백 자르기, 압축 등급 낮춤, 그리는 방식 변경)는 기본 제외다. 같은 그림이 유지되는 대안만 제시한다.
- 아트·최적화 보고는 "원본 파일을 고쳤는가 / 화면 모양이 달라지는가 / 기기에서 확인했는가"를 나눠 쓴다.
