# 게임 효과 눈가림 판독 요청

새 컨텍스트의 Claude 판독자(validator-client 시각 역할), 읽기 전용.

1. 이 폴더의 `compact-01.png`~`compact-15.png`와 `all-01.png`~`all-15.png`만 먼저 본다. 각 줄은 실제 게임에서 1/60초 간격, 총0.35초의 연속 캡처다. compact는 대표6장, all은21장이다. 번호마다 첫째·둘째 해석과 보이는 움직임·사라짐을 기록한다. map/종류 파일명/구현자 관찰은 첫 판독 이후에 연다.
2. 첫 판독을 확정한 뒤 `blind-map.json`을 열어 의도와 대조한다. F7-V1 종류, V2 움직임·쪼개짐·도트 결, V3 세운/눕힌 깊이, V4 배경 대비·흰 심 번짐을 판정한다. 짧은 효과를 첫 장만 보고 판정하지 않는다.
3. `../battle-fx.png`(1920×1080)를 보고 F7-V3/V4를 확인한다. 베기·별과 인물의 깊이, 발밑 고리, 그 위 HP/숫자, 흰 심 번짐을 기록한다. 시트에서 확인 안 되는 것은 미확인으로 구분한다. 성능·300마리는 평가 범위가 아니다.
4. 결과를 `hd2d-fx-game-read-r001.md`에 VERDICT: PASS 또는 FAIL, 번호별 관찰, 기준별 근거와 필수 수정/후속을 구분해 기록한다. 첫 판독 때 정답을 보지 않는다.

F0 그림 단계 Claude 판독 PASS는 유지되지만 게임 깊이/Bloom 판정을 대신하지 않는다.
