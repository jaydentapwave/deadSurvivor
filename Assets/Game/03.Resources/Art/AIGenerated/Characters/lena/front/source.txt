## 후처리
1. pixelize.py grid --bg-tol 100 --size 32x48 → native grid 33x47 (block 19.5px, score 0.56). 생성 그림의 키는 920px = 47칸(1254/64 = 19.6px 칸). 1·2회차 8장이 모두 47칸으로 나왔다.
2. pixelize.py one --size 33x47 --palette <브루노와 같은 팔레트: 기준서 3.5 36색 + 강철 3색 #c8b8b8 #a89898 #786868> --bg-tol 100 → 33x47 (f5233dd9b124b0295dcdbd5d6d1005a2c6cefee8981e87279bdad23b8b463f4e)
   - 34x48로 바로 내리면(47칸을 48칸으로 다시 나눔) 몸통·얼굴에 섞인 칸이 늘어 지저분했다(px2_view.png 아랫줄). 그래서 본래 격자 47줄로 내렸다.
3. 키 48px 맞추기(일회성 스크립트 output/2d-art/lena-front/tools/stretch_row.py): 다리 높이(그림 높이 70~85%) 안에서 아래 줄과 가장 비슷한 줄 하나(35번 줄, 차이 8px)를 한 번 더 넣었다 → 33x48 (383d04405225f219f9209fd50cd228ce60560998ee05ad99ee95506789b25cd4). 다리가 1px 길어진다.
4. 64x64 캔버스에 놓기(bruno-front의 place.py 그대로): 맨 아래 3줄(신발)의 가로 범위 가운데를 x 32에, 신발 바닥을 63줄에. 오프셋 (16,16).
5. 다른 편집 없음.
