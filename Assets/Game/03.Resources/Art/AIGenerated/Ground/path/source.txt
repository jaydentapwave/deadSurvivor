## 이웃 네 칸 → 고를 타일 (3.3 고르는 규칙)
이웃 = 마름모 변을 맞댄 네 칸. ↗ = 오른쪽 위 변, ↘ = 오른쪽 아래 변, ↙ = 왼쪽 아래 변, ↖ = 왼쪽 위 변.
꺾임 이름 = 길이 지나는 두 변이 만나는 마름모 꼭짓점(n 위, e 오른쪽, s 아래, w 왼쪽). 끝 이름 = 길이 이어지는 변.
| 길인 이웃 | 타일 | 반전 |
|---|---|---|
| ↗ ↙ | path_ne | 아니오 |
| ↖ ↘ | path_ne | 좌우 반전 |
| ↗ ↖ | path_corner_n | 아니오 |
| ↗ ↘ | path_corner_e | 아니오 |
| ↘ ↙ | path_corner_s | 아니오 |
| ↙ ↖ | path_corner_w | 아니오 |
| ↗ 만 | path_end_ne | 아니오 |
| ↘ 만 | path_end_se | 아니오 |
| ↙ 만 | path_end_sw | 아니오 |
| ↖ 만 | path_end_nw | 아니오 |
| 없음(외딴 칸) | 타일 없음 — 지도에 두지 않는다(풀 타일) | — |
| 셋·넷(갈림) | 타일 없음 — 기준서 3.3 범위 밖. 지도에 두지 않는다 | — |
같은 표가 docs/art/sheets/ground-path-build.py의 pick()에 코드로 있다(시험 지도·합성이 이 표로 깔렸다).
