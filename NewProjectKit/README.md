# NewProjectKit — 사용법

2026-11-03 Deadsurvivor에서 만든 이식 키트다. **지금의 주인공은 `3dkit/`이다.** 사용자 정리: "우선 우리가 새롭게 만든 키트를 3dkit이라고 한다면, 이 3dkit을 완성이 되었다고 판단될떄쯤, studio=kit에 업데이트를 할거야, 그러면 아주 나중에 stuio-kit을 활용해서 새로운 프로젝트에서 게임을 제작할거야"

두 부분으로 나뉜다.

| 부분 | 위치 | 어디로 가나 |
|---|---|---|
| **공통(3dkit)** | `3dkit/` | 완성해서 하나의 에이전트로 묶을 3D 키트. 완성 뒤 `git@github.com:jaydentapwave/studio-kit.git`로 간다(지금은 올리지 않음) |
| **나중 단계: 새 게임 프로젝트 자료** | 나머지 전부(`AGENTS.md`, `CLAUDE.md`, `.claude/`, `docs/`) | 아주 나중에 studio-kit으로 새 게임을 만들 때 그 루트에 넣는다. 그때까지 보관 |

이 폴더 자체가 "새 프로젝트 루트에 3dkit이 들어간 모습"이다. **디벨롭 중(2026-11-03 051부터) 키트 원본은 Deadsurvivor 저장소 루트 `3dkit/`에 있다**(원본은 한 곳). 그래서 이 폴더 안의 `3dkit/...` 링크는 새 프로젝트에 키트를 복사해 넣은 뒤에 맞는다.

## 순서 (아래 2~5는 나중 단계인 새 게임 제작 때)

0. **지금: 3dkit 완성.** `3dkit/README.md` 로드맵 v1(도구 구현) → v2(하나의 에이전트) → v3(이식 검증). 완성 판단은 사용자가 한다.

1. **3dkit은 지금 올리지 않는다.** 목표 순서는 키트 완성 → 하나의 에이전트로 묶기 → 그다음 studio-kit 저장소(사용자, 2026-11-03: "어익후 올린다는 이야기를 한건 아냐야, 우리가 만든 3d kit을 완성시킨다음에 하나이ㅡ 에이전트로 이식시키는게 목표야"). 그때까지는 폴더 복사로 쓴다.
2. **새 Unity 프로젝트 만들기**: Unity Hub에서 Unity 6000.4.3f1, **URP 템플릿**으로 생성.
3. **키트 넣기**
   ```bash
   cd <새 프로젝트 루트>
   cp -R <Deadsurvivor>/NewProjectKit/AGENTS.md <Deadsurvivor>/NewProjectKit/CLAUDE.md <Deadsurvivor>/NewProjectKit/.claude <Deadsurvivor>/NewProjectKit/docs .
   cp -R <Deadsurvivor>/3dkit .
   git init -b main
   ```
4. **Tripo 키**: 필요하면 이전 프로젝트의 `.env.local`을 새 루트로 직접 복사한다(Git 제외 확인).
5. **새 프로젝트에서 Claude Code를 열고 첫 요청**: "CLAUDE.md와 docs/현재상태.md를 읽고 docs/plan/001-출발-계획.md의 P0부터 진행해줘".

## 들어 있는 것

- 공통: 핵심 규칙, 개발 워크플로우, 하네스 설계도(H0~H4), 에셋 규격 틀(미드폴리 숫자는 미정), Tripo 생성 기준, 성능 절차, 빌더 규칙, 시각 설계 절차, 도구 연결, 검토 역할 계약 3개, 교훈(이전 실패 → 원인 → 규칙), 양식, 프로젝트 틀, 참고 구현 코드.
- 게임 전용: 출발 계획(비주얼 → 셰이더 → URP → 이펙트), 게임 규칙 7개(컨셉·장비·웨이브·범위·종료 보상·전투 연출·전체 맵), 이전 로우폴리 미술 기록과 에셋 카탈로그.
