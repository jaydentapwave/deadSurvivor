## 입력과 제안

실제 [원본 PNG](../art/maps/references/VerdantMeadowsFullMap.png)를 native imagegen 입력으로 직접 전달했다. 원본의 낮고 넓은 암녹색 관목과 회녹/회청의 낮은 깨진 돌 파편을 관찰했다. 028/ENV-S01/037의 소품 외형은 새 생성 입력에서 제외했다. 037은 배치·지면 비교 기반이다.

관목 X/Y/Z 목표 1.0/.40/.90, 허용 .8–1.2/.30–.50/.7–1.1. 석재 1.4/.32/.55, 허용 1.1–1.7/.22–.42/.40–.70 Unity 단위. 원본 실측이 아닌 캐릭터 표시높이 .72와 비교하는 시험안이다. 중앙 바닥 원점, 정적 무광, 금속도0, UV, 각 1재질, 최종1K BaseColor/Normal. 관목 face_limit2500/최종3500삼각형 이하, 석재1500/최종2000 이하를 후보 예산으로 둔다. 정확한 최종 값은 Blender/Unity에서 확인한다.

요청은 H3.1 v3.1-20260211, texture v3.5-20260815, standard geometry/texture, texture/PBR/smart_low_poly/delight/UV, quad/auto_size/parts/autofix 비활성. 각 후보1, 유료 생성 각각40크레딧·합계80 한도. 새 기준 이미지2장만 Tripo에 업로드하며 원본 지도·코드·키를 전송하지 않는다. 사용자의 두 모델 제작 지시가 해당 생성·입력 업로드 허용 근거다. 제출 전 journal을 만들고 수락 task만 추적한다. 모호한 제출 결과를 자동 재제출하지 않는다.

## 배치와 검사

기존 네 관목 위치를 우선 교체하고 짧은 석재를 잔해 내부와 깨진 끝의 기존 C 안에 분산한다. 연속 벽처럼 연결하지 않는다. 기존 지형·길·통행·충돌 데이터와 게임 코드는 보존한다. 새 Collider는 추가하지 않는다. 고유 모델2종의 반복배치이며 배치 개수는 원본 밀도·화면·C 경계 확인으로 정한다.

최소 확인: 원본/기준 이미지/실제 앞뒤 모델 비교, 저장 모델 재가져오기와 치수·피벗·UV·예산 확인, Unity 실제 bounds·재질·C 내부 배치, 동일 구역 상면과55도 전체 및 실제 정상프레임/이동/가림 캡처. 현재 도구를 재사용하며 무관한 전수 경로/신규 범용 검사기를 추가하지 않는다. Play 뒤 기존 파일·폰트·편집상태를 먼저 복구한 다음 필요한 최종 all --screens와 gate를 실행한다. 독립 검토자는 실제 증거와 미실행 범위를 구분한다.

[Tripo 공식 현재 옵션](https://developers.tripo3d.ai/en/docs/generation-image-to-model/standard)을 2026-11-02 확인했고 설치 CLI0.8.1 dry-run에서 유효·경고없음·각40을 확인했다. 요청·기준 이미지·지문·원자료는 [038 작업 폴더](../../output/tripo-pair-038/20261102-r001)에 보존한다.
