# 047 전투 효과·연출 정리

047에서 `Map046_Full`에 넣은 전투 효과, 몬스터·영웅 연출, 밤 화면을 한 곳에 모은 문서다. 값은 2026-11-03 코드 기준이며, 바꾸면 이 표도 고친다. 만든 과정·에러·검증은 [047 작업 기록](../reviews/combat-fx-047-log.md)에 있다.

상태: **시험 반영(사용자 플레이 전)**. 크기·밝기·밤 값은 사용자가 직접 플레이한 뒤 조정한다.

효과 종류는 게임 코드가 `Burst(위치, 반경, 수명, 색)`로 넘기는 **색 문자열로 구분**한다(게임 데이터에 효과 종류 필드가 없음). 게임 코드의 색과 `DSMapFx`의 `case` 목록이 어긋나면 효과가 기본 불꽃으로 조용히 바뀌므로, gate 정적 검사 `refs`가 둘을 대조한다(047 H11, 048).

단위: 게임 반경(논리 px) × 0.02 = 효과 크기(월드 m). 시간은 `Time.unscaledDeltaTime` 기준이라 일시정지 중에도 사라지는 중인 효과는 끝까지 재생된다.

## 영웅 공격 동작

- Tripo 동작 `slash`·`shoot`(047, 20크레딧)을 `Hero045v2.controller`의 상체 레이어 `Attack047`(트리거 `Slash`·`Shoot`, 상체 마스크 `UpperBody047`)로 넣었다. 달리면서도 공격한다.
- 근접 무기(검·도끼) = `Slash`, 원거리·마법·치유 = `Shoot`. 같은 영웅은 0.28초 안에 다시 시작하지 않는다. 서 있을 때는 대상 쪽으로 몸을 돌린다.
- 클립 자르기(047-E1): `slash` 1.2~2.3초를 2배속, `shoot` 0.15~0.95초를 1.6배속. 들어갈 때 0.06초, 나올 때 끝 90%에서 0.1초 섞기.
- 알려진 문제: `hero_attack.fbx` 가져오기 경고(047-E6, 원인 미조사, 재생은 정상).

## 바꾸거나 더할 때

- **크기·밝기 조정**: 위 표의 값은 `DSMapFx.cs`의 각 함수(`Slash`, `Heal`, `Lightning`, `Explosion`, `ShotColor`, `ShotScale`)와 `DSMapActorViews.Pose`의 상수다. 밤 값은 `DSDayNight` 공개 필드라 장면 Inspector에서도 바꿀 수 있다.
- **새 효과 추가**: 게임 코드에서 새 색으로 `Burst`를 부르고 `DSMapFx`의 `switch`에 같은 색의 `case`를 넣는다. 색은 문자열 상수여야 한다. 하나만 넣으면 gate `refs`가 FAIL한다(`python3 Tools/Verify/run.py refs`).
- **확인**: 효과는 0.2~0.5초라 정지 캡처 1장으로 판단하지 않는다. `play_probe.py --wave 6 --hp-lock --captures 6 --interval 0.1`로 연속 캡처하고 보고서의 효과 수(`projectiles`, `timed_fx`)를 함께 본다([핵심 규칙](../workflows/core-rules.md) 2절).
- **성능**: 예산과 측정 방법은 [성능 절차](../workflows/performance.md). 049 모바일 기준(바닥 그림자 뒤) 7웨이브 그리기 호출 147, 삼각형 7.1만이다. 효과를 크게 늘렸으면 같은 명령으로 다시 잰다([049](../reviews/perf-049.md)). 048의 401·29.2만은 PC 렌더 설정 값이라 비교하지 않는다.
