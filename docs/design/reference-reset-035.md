# 035 — 원본 직접 대조로 대표 구역 미술 기준 재설정

2026-11-01 · L1 · 이미지/설계 기준 재설정. 기존 Unity 코드·자산·C·검증 gate 구현 변경 없음.

## 이번 결과·완료 조건
사용자가 원본 레퍼런스와 현재 맵 형태가 다르다고 지적했고, 원본 대표 구역 하나의 지면·길·잔해부터 다시 맞추는 방향에 동의했다. 원본과 직접 비교할 수 있는 기준 이미지 1개, 비교 보기, 차이/미정/후속 제작 순서를 제공한다. 최종 게임 미술 채택·전체 맵 완성·추가 Tripo 생성은 이 이미지 제작과 구분한다.

## 입력 원본과 범위
원본: [Verdant Meadows](../art/maps/references/VerdantMeadowsFullMap.png), 1195×1110. [출처 기록](3D배경-VerdantMeadows-구조분석-03.md).
선정 영역은 원본 픽셀 x=100..520, y=100..360이다. 원래 028의 x140..420/y105..340보다 좌우를 넓혀 왼쪽 흙길, 세 번째 굽은 잔해, 작은 군집, 하부 가로 돌길을 함께 비교한다. 이 사각형은 참조 범위이며 새 월드 좌표·충돌 영역이 아니다.
원본은 수정하지 않고 이미지 생성에 원본 파일 자체를 전달한다. 비교 보기의 원본 확대는 원본 PNG를 SVG viewport로 보여주며 재생성·색 보정·픽셀 편집을 하지 않는다. 원본 카메라와 기존 Unity55도 카메라의 차이를 표시한다.

## 사용자 요구·관찰·제안·미정
- 사용자 요구: 원본의 핵심 형태와 분위기를 회복한다.
- 원본 관찰: 해당 구역의 주요 잔해는 큰 둥근1·곡선3·작은 둥근2다. 얇은 불규칙 회색 외곽, 넓은 녹색 상부로 읽히는 면, 일부 어두운 작은 식생, 초록 지면과 베이지 마른 흙, 아래쪽 회청색 자갈길이 구별된다.
- 표현 제안: 낮은 융기 형태에 얕은 깨진 석재 테두리와 이끼/잔디색 상부를 만들고, 지면과 길을 먼저 맞춘다. 녹색 면이 지면과 같은 높이인지 융기/식생인지 원본만으로 단정하지 않는다.
- 미정: 3D 높이·단면·세계 치수·충돌/통과 가능성, 원본과의 정밀 점유율, 최종 사용자 미술 채택.

## 폐기할 전제
028/r004의 회색으로 꽉 찬 큰 다면체와 규칙적인 돌 반복, 그것을 입력으로 만든 ENV-S01/r001 바위 줄을 새 미술의 기준으로 쓰지 않는다. 기존 시안/코드/생성 원본/기능 시험 증거는 보존한다. 기능 PASS는 현재 원본 충실도 PASS가 아니다.
새 기준에서 '잔해 내부가 녹색'을 비어 있는 방/구멍/통행 공간으로 해석하지 않는다. 기존 C는 그대로 두고, 후속 시각 적용 시 V/C/U의 관계를 별도로 확인한다.

## 순서와 최소 검사
1. 원본과 현재 캡처 직접 비교, 선정 구역과 주요 형태 고정.
2. native image_gen에 원본을 직접 입력하여 같은 위쪽 시점의 구역 기준 이미지 생성. 프롬프트/파일/해시 기록.
3. GPT-6.1 Sol high 독립 검토자가 실루엣·녹색 상부·길 연속·공간/밀도·팔레트를 대조. 핵심 실패 시 같은 원본을 유지해 해당 결함만 수정한다.
4. 새 기준과 원본을 나란히/겹쳐 볼 수 있도록 제공. 생성 그림은 정밀 배치 데이터/충돌 도면으로 사용하지 않는다.
5. 현재 상태/자산 계획에서 이전 미술 기준을 명확히 대체하고 최종 gate의 문서 검사만 실행한다. 코드·자산·수집기 지문이 그대로인 Unity 근거는 gate가 재확인하며 게임/전체 Python/topology를 다시 실행하지 않는다.

## 후속 제작 방향
지면과 연속 돌길 → 녹색 상부가 있는 둥근/곡선 잔해의 단면·실루엣 → 같은 원본 영역의 Unity 비교 순서다. 기존 S01의2.4×.5×.6 치수와 회색 돌줄 단면을 신규 기준에 자동 승계하지 않는다. 독자 3D 소품이 필요한 경우 전체 풍경이 아닌 해당 잔해 하나의 원본 대응/다각도/명세를 먼저 정리한다.
