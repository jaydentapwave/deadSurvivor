# TRIPO-GENERATION-014 변경 브리핑

2026-10-31 · L1 문서/워크플로우. 사용자 요청: Tripo 요청의 대상/형태/크기/재질/텍스처/조명/생성 버전을 정리하여 다음 작업부터 일관되게 적용한다.

원본 규칙은 [Tripo 생성 기준](../workflows/tripo-generation-standard.md)에 둔다. 기존 A0 워크플로우와 자산 작업 양식, 개발 입구/현재 상태에서 해당 기준을 연결한다. 프롬프트 요구·실제 공급자 옵션·Unity 실측 인수를 구분한다. 소품마다 필요한 수치는 근거와 함께 동결하며 과거 전송 시험 수치를 최종 예산으로 승격하지 않는다.

이번 변경은 문서와 작성 양식뿐이다. 기존 JSON schema/도구/처리 캐시·hook/baseline을 변경하지 않고 새 생성/업로드/과금이나 Unity 실행을 하지 않는다. Tripo 생성 CLI/API 자동 제출은 여전히 미구현이며 이 작성 양식을 제출 가능한 설정 파일로 주장하지 않는다.

완료 기준: 공식 기능 근거/버전 조건, 재사용 가능한 필수 작성 항목과 기본값/예외, 비용/공개 근거, 실제 전송 필드 및 반환 결과 보존, 기존 A0~A5와의 연결, local 문서/데이터 검사, validator-client 독립 문서 검토·지적 수정, 최종 gate. 새 자산 동작/시각 인수는 NOT_RUN이다.
