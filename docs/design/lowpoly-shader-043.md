## 설계

### 팔레트 (색의 단일 원본)

- 8열×4행 = 32칸, 칸당 8×8px → 64×32 PNG. Point 필터, mipmap 없음, Clamp, sRGB. 메시 UV는 칸 중앙 `((c+.5)/8, (r+.5)/4)`를 가리킨다.
- 행 구성(에이전트 제안): 0 풀·식생, 1 흙·길, 2 돌, 3 물·꽃·강조. 캐릭터 색 행은 042 결과를 본 뒤 정한다.
- 알파 채널은 발광 마스크다. A=1(기본)은 비발광, A<1이면 `(1-A)`만큼 발광한다. 이번 32색은 모두 A=1.
- 추출: `day.png` 픽셀을 OKLab에서 군집화하고, 색상·채도로 행을 나눈 뒤 행마다 명도 순으로 8색을 고른다. `day.png`는 조명이 들어간 화면이므로 이 색은 "햇빛을 받은 윗면이 보이는 색"으로 해석한다. 셰이더 조명은 해를 정면으로 받은 윗면이 팔레트 색에 가깝게 나오도록 맞춘다.

### 다시 칠하기

- **Tripo 소품(Blender):** 원본 GLB의 BaseColor를 면마다 평균 샘플 → OKLab 최근접 팔레트 칸 → 이웃 면 다수결 2회로 얼룩 정리 → 면의 UV를 해당 칸 중앙으로 모음 → 텍스처 연결 제거. 형상·삼각형 수·치수는 038 전달본과 같아야 한다. 노멀 맵은 쓰지 않는다.
- **037 자체 메시(Unity):** 서브메시마다 원래 재질의 대표색(BaseColor × 텍스처 평균)을 최근접 팔레트 칸으로 바꾼다. 메시 **사본**의 UV만 바꾸며 037 원본 메시·재질은 수정하지 않는다.

### 셰이더 `DeadSurvivor/LowPolyPalette`

- 코드 파일(HLSL)로 작성한다. Shader Graph를 쓰지 않는 이유: 에이전트가 직접 읽고 고치고 diff로 검토할 수 있어야 한다.
- 패스: UniversalForward, ShadowCaster, DepthOnly, DepthNormals. 키워드·include는 설치된 URP 17.4.0 SimpleLit 원본을 기준으로 한다.
- 색 계산: 팔레트 색 × 높이 그라디언트 → 상면 투영(윗면을 팔레트의 지정 칸 색으로 섞음) → 조명(감싸는 확산광 램프 + 그림자 + 환경광 SH) → 발광 → 안개.
- 재질 프리셋(같은 셰이더·같은 팔레트, 매개변수만 다름): Ground(그라디언트·상면 투영 없음), Prop(돌: 그라디언트 + 이끼 상면 투영), Foliage(그라디언트 + 바람). SRP Batcher는 같은 셰이더 변형끼리 재질이 달라도 묶는다.
- 전역 값(`_DS_` 접두사, 기본 0 = 꺼짐): 그림자 색 `_DS_ShadowTint`(rgb, a=세기), 구름 그림자 `_DS_CloudShadow`(세기·크기·속도·방향). 낮밤 전환은 Directional Light 색·세기, 환경광, 위 전역 값으로 한다. 영구 낮밤 컴포넌트는 C# 런타임 추가가 필요하므로 후속이며, 이번 캡처는 캡처 스크립트가 값을 설정한다.
- 면 음영 옵션 `_FLAT_SHADING`: 화면 미분으로 면 노멀을 만든다. 캐릭터·몬스터용(039 규칙). 이번 장면의 환경에는 쓰지 않는다.

### 구현 중 바뀐 점 (r001 실행 결과 반영)

| 항목 | 처음 설계 | 바뀐 내용과 이유 |
|---|---|---|
| Tripo 재칠 | 면 색 → 팔레트 최근접 | 최근접만 쓰면 038의 어두운 명도가 그대로 옮겨진다(관목 83%가 가장 어두운 초록). 자산마다 **기준 칸** 하나를 정해 OKLab 3축의 면적 가중 중앙값을 그 칸으로 옮기고 편차를 줄인 뒤(관목 칸5·0.6, 석재 칸21·0.5) 최근접을 고른다. 석재는 돌 행만 허용하고 이끼는 셰이더 상면 투영으로 준다 |
| 흙·조약돌 바닥 | 불투명 | 원본은 꼭짓점 알파(바깥 0, 안쪽 0.6~0.9)로 가장자리를 흐린 반투명 층이다. `_VERTEX_ALPHA_CLIP`(기준 0.15)으로 또렷한 다각형 가장자리로 바꾼다. 기준 0.5는 패치가 작은 조각으로 쪼개져 폐기 |
| 높이 기준 | 물체 공간 Y | Blender FBX는 Unity에서 Z-up 데이터에 -90° 회전과 ×100 크기로 들어와 물체 공간 Y가 높이가 아니다. 이 때문에 관목·석재가 그라디언트 바닥값으로 통째로 어두워지고 바람이 0이었다. **피벗 기준 월드 높이**로 바꿨다 |
| 지면 변화 | 없음 | 단색 지면이 평평해 보여 `_NoiseStrength/_NoiseScale`(월드 XZ 값 노이즈, Ground·Soil 0.08)을 추가 |
| 밤 | 조명·환경광·그림자 색 | 초록 재질에 푸른 빛을 곱해도 초록으로 남는다. 전역 `_DS_GradeTint`(재질색 채도를 낮추고 색을 입힘, a=0이면 꺼짐)를 추가 |
| 구름 그림자 | 세기 0.35·크기 7 | 화면에서 거의 보이지 않아 세기 0.45·크기 5.5, 경계 0.42~0.55로 조정 |

지원 범위(검토 043-V5 반영): 주광 그림자(단일·캐스케이드·화면 공간, 좌표 분기는 URP SimpleLit과 같음), SSAO, 조명 레이어, 추가광은 픽셀 단위(정점 추가광 설정도 픽셀로 계산), 안개. 미지원: 라이트맵·그림자 마스크·반사·스펙큘러·데칼 버퍼·DOTS 인스턴싱(GPU Resident Drawer 대상 아님, SRP Batcher로 묶임).

캐릭터는 사용자 결정(2026-11-02, 042 세션 전달)으로 당분간 2D 스프라이트를 유지한다. rim·면 음영은 셰이더에 남지만 이번 장면에서 쓰지 않는다. 밤 화면의 2D 스프라이트 가독성은 이 시험 장면 범위가 아니다(아래 미정).

## 경계와 복구

- 038 장면은 `AssetDatabase.CopyAsset`으로 복사한 뒤 사본만 연다. 작업 전 활성 장면 구성·선택을 저장하고 끝나면 복구한다(038 빌드 스크립트와 같은 방식).
- 대상 경로가 이미 있으면 덮지 않고 실패한다. 실패한 부분 결과는 보존하고 새 개정(r002)으로 다시 만든다.
- 같은 Unity 에디터를 042 세션과 함께 쓴다. 장면 열기·Play·대량 임포트 전에 서로 알리고, 끝나면 원래 장면을 복구한다(2026-11-02 세션 간 합의).
- 레이아웃 지문(`ExpectedDataSha`)과 Collider 수가 038과 같아야 한다. 다르면 중단한다.
