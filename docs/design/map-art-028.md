# 028 — N3 대표 구역 미술 시험

> 035 후속: 사용자의 원본 불일치 피드백에 따라 이 시안은 [현재 미술 기준에서 제외](reference-reset-035.md)했다. 아래 실행/검증 기록은 당시 기능·Editor 범위의 근거로 보존한다.

- 상태: 대표 구역 Editor 시안 구현·동결 비교·기존 게임 회귀·독립 검토 PASS. 실행 파일 성능/최종 미술 채택/전체 맵 G5는 미완료.
- 규모: L2. 별도 저장 장면과 시각 메시 생성·소유/복원 경계를 추가한다.
- 사용자 확정: 전체 후속 작업을 자율 진행한다. 2026-11-01 추가 지시에 따라 N2 실제 빌드·테스트는 사용자가 직접 수행하므로 실행하지 않고 N3로 넘어간다. N1/G2/G3 미완료를 완료로 바꾸지 않는다.
- 요구: 024 §5의 대표 구역에서 구조를 유지하며 바닥·돌·식생·조명 표현을 비교한다. 전체 맵 최종 미술/G5, 유료 생성, 외부 자산 최종 채택, N2 부하/빌드는 제외한다. N3에 필요한 Editor 동작 검사는 별도다.

## 입력과 표현 기준

원본 `docs/art/maps/references/VerdantMeadowsFullMap.png`(1195×1110)를 2026-11-01 직접 확인했다. 출처와 구조 해석은 [03 분석](3D배경-VerdantMeadows-구조분석-03.md)을 따른다. 관찰: 녹색 지면 위 밝은 마른 지면이 분포하고, 낮고 끊긴 돌 군집·곡선 장애물 사이에 열린 공간이 있다. 이것이 충돌이나 높이의 실측 근거는 아니다.

에이전트 제안: OB-001 중심과 인접 곡선 군집을 포함하는 원본 픽셀 사각형 x=140..420, y=105..340을 시험 범위로 삼는다. 원본 등록부와 실제 카메라를 대조한 후 범위/관찰점을 확정한다. 기존 원본 007/018 및 021~023은 보존한다. 개발 프로필 s4/55도/ortho6, 반경8은 변경하지 않는다.

시험 팔레트는 기존 문서의 저채도 녹색 지면·따뜻한 회색 돌·갈색 마른 땅 방향을 따른다. 색상은 최종 사용자 승인이나 공용 아트 바이블이 아닌 이 시험의 제안이다. 픽셀 캐릭터·UI·공격 표현은 유지한다.

## 소유처와 변경

- C 원본: `Assets/DeadSurvivor/Scenes/Map018_r001/Layout.json`, 소비처 DSMapSession/DSMapGeometry. 파일과 충돌 경로는 변경하지 않는다.
- 게임/카메라/가림: DSGame, DSWorld.Map, DSMapVisibility를 재사용한다. 새 시각 메시가 충돌 메시를 대체하지 않는다. 새 Collider를 만들지 않는다.
- 추가 예정: `Assets/DeadSurvivor/Editor/DSMapArtVerification.cs`, 필요 시 전용 시각 메시 helper, 별도 `Assets/DeadSurvivor/Scenes/Map028_ArtExperimental/` 아래 씬/메시/재질. Unity API로 생성한다.
- 바닥은 평면 조각과 제한된 색/높이 변화, 돌은 기존 C 바닥 윤곽 안쪽의 상부 단면과 서로 다른 면 명도, 식생은 작은 군집으로 표현한다. 원본 외형 전체를 정밀 복원했다고 주장하지 않는다.
- 기존 TEST Tripo 바위는 외부 자산 채택으로 승격하지 않는다. 새 시험의 돌은 자체 메시로 만들어 원본 테스트 자산의 재질/원본을 수정하지 않는다.
- 키 큰 시각 요소는 초기화 전 가림 목록에 등록하고, 통로 시인성과 가림 복원을 확인한다. 생성 개수·삼각형·재질 수를 기록한다.

## 실패·취소·복구

기존 owned-session 어댑터와 Editor 잠금을 재사용한다. 사용자 Play/dirty scene이면 BLOCKED. 시작 시 씬/선택/설정과 기존 파일 SHA를 로컬 output에 동결한다. 성공/실패 모두 소유 객체/가상 입력/임시 설정을 정리하고 원래 씬을 복원한다. 다른 에이전트의 미커밋 문서는 보존하며 자동 커밋하지 않는다. 새 폴더에 기존 산출물이 있으면 자동 덮어쓰기하지 않는다.

사망/부활/정비/전투 상태는 기존 DSGame에 남긴다. 미술 코드에서 타이머·이동·스폰·명령 큐를 수정하지 않는다. 조명과 재질은 새 씬 범위로 제한한다.

## 검증과 완료 조건

1. 생성 전후 Layout 및 기존 018/021~023 지문 동일, 충돌 개수/좌표·개발 프로필 동일 확인.
2. 같은 카메라·캐릭터 위치·해상도로 기본 도형과 미술 적용 캡처. 원본의 해당 구역과 밀도·형태·열린 공간·통로를 비교하며 실제 시각 검토/수정 1회를 남긴다.
3. 소유 세션에서 실제 프레임 진행·이동 입력·정지/가림/전투를 확인하고 Console/정리 결과 기록. 기존 Map23 시험을 새 씬 인수의 대체물로 쓰지 않는다.
4. 독립 코드/증거 검토, `python3 Tools/Verify/run.py local`, 런타임 변경 시 `all --screens`, 최종 gate. N2 실행 파일/최대 부하/성능 인수는 USER_RUN/NOT_RUN으로 유지한다.
5. 대표 구역 시각 시험 결과와 미실행 항목을 `docs/reviews/map-art-028-review.md`에 기록한다. 성능 근거가 미충족이면 N3 전체 인수를 완료로 표시하지 않는다.

## 미정 및 검토

정확한 관찰점, 팔레트 RGB, 메시 상세/수량은 실제 기준 화면을 본 뒤 시험 개정에 기록한다. 전체 맵 구조 변경은 이 설계로 허용하지 않는다. 독립 설계 검토 결과 대기 중.

## 설계 검토 보완 (ART028-01~04)

- ART028-01: 바인딩 Transform과 Layout을 보존한다. 기본 비교 씬은 원래 렌더러, 미술 씬은 범위 내 OB Renderer만 꺼서 자체 메시를 표시한다. 범위 밖 도형은 그대로다. TEST 바위 Renderer는 미술 씬에서만 끄며 원본 자산은 변경하지 않는다. StaticGeometry/RockHolder root를 끄거나 삭제하지 않는다.
- ART028-02: 모드 전환은 같은 실행 중 수행하지 않는다. 별도의 기본/미술 저장 씬을 각각 열어 최초 Refresh 전에 Blockers를 확정한다. URP/Lit의 _BaseColor/투명 속성을 지원하는 재질만 사용하고 목록의 null/중복을 거부한다. 가림 발생과 해제 후 sharedMaterials 원복을 관측한다.
- ART028-03: 생성 seed=28001, s4/55도/ortho6, 1280×720. 인수 실행 전에 실제 안전 관찰점·해당 OB/RT·입력열·파티/장비·동일 조명·캡처 프레임을 별도 manifest로 동결한다. 제안 범위와 후보 화면은 인수 PASS에 사용하지 않는다. 이동은 실제 프레임에서 위치 변화와 sweep 안전, 정지는 입력 해제 후 정지, 가림은 fade/restore, 전투는 시간·적/공격 진행과 캐릭터 식별을 각각 검사한다.
- ART028-04: 새 폴더 생성 전 output/map-art-028에 intent와 기존 원본 SHA 목록을 저장한다. 신규 파일별 생성 직후 SHA와 소유 목록을 기록한다. 실패 시 부분 산출물은 FAILED journal과 함께 보존하고 자동 재시도/덮어쓰기를 거부한다. 임시 Play 객체/장치는 owned-session으로 별도 정리한다. 성공 뒤 저장 씬 재개방·참조 검사 및 원래 씬/조명 설정 복원을 확인한다.


## 화면 회귀 도구 보완

기존 all --screens가 실제 GameView RT1280×720과 UI layout3088×1440 불일치를 탐지했다. `DSScreenVerification.Resize`가 Editor Focus와 Simulator.Update에 의존하여 Disabled enum인데도 Device.Screen shim이 남는 상태였다. 소유 세션 진단에서 동일 모드의 명시적 main.Disable 후 native frame의 UI layout1280×720·기존 Check PASS, 설정/장치/씬 복원을 확인했다. 이를 Resize의 SuspendSimulators에 적용한다. Restore와 같은 API이며 게임 DSUI·해상도 assertion·gate 기준을 변경하지 않는다. 기존 FAIL은 보존하고 현 소스로 N3 비교/전체 회귀를 새로 수행한다.
