# 현재 아이템 규칙

2026-10-29 병렬 실행 적용. [데이터 원본](../../Assets/DeadSurvivor/Resources/DeadSurvivor/PrototypeData.json), [계산 규칙](../../Assets/DeadSurvivor/Runtime/EquipmentRules.cs), [변경 설계](아이템-병렬실행.md).

## 배치와 실행

주무기/보조 분류, 주무기 한 개 제한, 자동 교체, 장비 기반 직업 전환을 제거했다. 고정4×4에 들어가는 아이템은 여러 개 장착한다. 공격·직접 회복 기능이 있는8종은 인스턴스별 쿨타임으로 독립 발동한다. 같은 타입 두 개도 각각 작동하며 같은칸 동일등급 드롭만 합성이다. 방어/체력 등 지속 효과 아이템에 새 공격은 추가하지 않았다.

모든 아이템은90도 회전·경계·충돌 규칙을 따른다. 다른 무기에 겹쳐 놓으면 자동 교체하지 않고 거부한다. 실패는 위치/소유/등급/회전/쿨타임을 보존한다. 사망자 장비는 잠기며 무료 부활 후 조작 가능하다. 공격 장비가 없어도 출발할 수 있다.

한 아이템이 쿨타임 중이거나 공격/회복 대상을 못 찾아도 다른 아이템은 계속 검사한다. 정비 중 쿨타임은 멈추고 사망 시 실행하지 않는다. 해제한 아이템은 실행 대상에서 빠지며 부활 시 장착한 아이템의 쿨타임을 초기화한다.

## 효과와 대상

기본 효과는 캐릭터 전체에 한 번씩 적용한다. 직업 조건은 없으며 추가 효과는 대상 공격 방식과 인접 조건으로 판단한다. 특정 무기에 인접한 가속·관통·피해 증가는 해당 무기만 받는다. 같은 아이템이 여러 적합한 무기에 인접하면 각각 강화한다. 떨어진 무기나 자기/공유 회복 주기에 인접 가속이 새지 않는다.

방어80%, 속도+100% 상한을 유지한다. 관통/추가발사/연쇄 최댓값과 가속 상한은 각 무기에 실제 적용되는 집합에서 계산한다. 보호막은 한도 보충이며 무한 누적되지 않는다. HP장비는 착용만으로 무료회복하지 않고 해제 시 새 최대HP를 초과한 현재HP만 제한한다.

회복 아이템의 기본 자기회복은3초이며 공통 속도의 영향을 받는다. 공유 효과가 있는 아이템을 장착한 생존자가 다른 생존자에게 자기회복을 공유한다. 직업이 필요하지 않다. 최고 초당 회복량 제공자1명, 자기 제외, 동률 앞슬롯, 거리 무관이다. 직접 회복과 외부에서 받은 공유는 재공유하지 않는다. 제공자/주기가 바뀌면 공유 타이머를 재시작한다.

주기 피해 아이템은 자체 쿨타임을 사용한다. 현재 데이터는 한 아이템에 직접 공격과 주기 피해를 중복 정의하지 않는다. 캐릭터 자기회복/보호막/공유의 합산 타이머는 해당 효과의 기존 중첩 규칙을 유지한다.

## 입력과 비교

선택→대상 첫탭 미리보기→재탭 적용. 해제와 보관함 합성에도 같은 절차를 사용한다. 드래그는 놓을 때 적용하며 회전은 확정 전 원본을 바꾸지 않는다.

복사 상태와 실제 상태는 동일한 거래/효과 계산을 쓴다. 캐릭터 공통 능력치와 각 발동 아이템의 피해/주기/거리/관통/추가발사/연쇄/폭발 반경을 비교한다. 같은 이름의 무기도Gear ID로 구별한다. 진형 화면은 발동 장비 개수와 최대3개 아이콘을 표시한다. 추천은 직업이 아니라 현재 발동 아이템의 대상 조건에 따른다.

## 보상과 현재 수치

정비마다3~5개 무작위,9회 총27~45개. 기존 아이템 가중치와 테스트용 고정 개수 설정은 유지한다. adaptiveDrops=true이면 초반1~3웨이브는 추가효과의 대상 조건을 만족하는 아이템2배, 후반4~9는 생존자 장착 일반등급 동일ID1.5배. 보상 직전 스냅샷이며 사망자/보관함/새 보상은 제외한다.

성전4칸/회복4.8,등불L4칸/4.4,종L3칸/3.3,의복막대3칸/3.0은 시험 수치다. 직업 제한 제거와 다중 공격으로 전투 밸런스가 달라지므로 이전 정책의 실험을 최종 밸런스 근거로 재사용하지 않는다. 캐릭터별 범위 제안은 아직 미적용이다.

### 전리품으로 장비 꺼내기 (L1 입력 수정, 2026-10-29)

전리품 빈 영역과 합성 불가능한 전리품 아이템 위에 놓으면 장착 장비를 해제한다. 합성 가능한 대상은 기존 합성을 유지한다. 탭 미리보기와 드래그 적용은 같은 대상 판정을 사용한다. 사망 장비 잠금과 배낭 충돌 규칙은 유지한다. 드래그 후 새 포인터 누름은 이전 클릭 억제 상태를 초기화한다. 검증은 해제·합성·탭/드래그 및 기존 규칙 회귀를 포함한다.

### 사망 인벤토리 부활 UI (L1, 2026-10-29)

사망자의 정비 인벤토리 전체를 불투명 검은 배경으로 표시하고 중앙에 부활하기 버튼을 둔다. 캐릭터 이름은 표시만 한다. 사망 중 장비 칸 입력은 생성하지 않는다. 버튼은 해당 캐릭터의 기존 무료 부활을 실행하고 정상 인벤토리를 복구한다. 장비 데이터는 보존한다. 검증: 검은 배경/중앙 버튼/장비 입력 차단/체력과 장비 복구 및 실제 캡처.
