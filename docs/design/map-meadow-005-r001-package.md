# MAP-MEADOW-005 / r001 — 지형·통로·시험 연결

작성일 2026-10-30 KST. 작성자 Codex. 문서 상태 검토중 / 게임 적용 미구현. 이전 자료: [03 분석](3D배경-VerdantMeadows-구조분석-03.md), [04 적용](3D배경-우리맵-적용설계-04.md), [특징 대응표](맵-레퍼런스-대응표.md).

## 설계 브리핑

- 규모 L1: 등록 자료의 필드·계획 사례 연결·검토 방법을 구체화하는 문서 워크플로우 작업. 게임 데이터 스키마나 하네스 실행 코드에는 적용하지 않는다.
- 사용자 요구: 제작 전 설계를 계속하여 개별 군집·필수 통로 ID, 실제 참조 위치, 시험 입력·판정 기준 연결. 실제 맵/Unity/하네스 제작 제외.
- 기존 소유처: RF/MC 정의는 기존 문서, 원본은 REF-VM-001. 이번 CSV는 설계 등록부이며 게임이 읽는 콘텐츠가 아니다.
- 변경: 본 작업 묶음, 객체/통로/계획 사례 CSV, 등록부 읽기 문서, 기존 대응표·산출물 규격·현재 상태 연결. 군집 미등록 상태에서 이미지 참조 위치와 시험 ID를 추적 가능한 상태로 전환한다.
- 재사용: 기존 ID 접두어·정규화 좌표·검사 상태·사례 정의를 사용한다. 새 런타임 프레임워크·전역 설정·회사 연동 없음.
- 실패·취소·생사·전환: 위치 불명은 추정 표시, 필수 값 미정이면 실행 준비 BLOCKED. 생사/정비는 기존 사례군에 연결할 뿐 이번 기본 이동 계획에 포함 완료라고 주장하지 않는다.
- 복구·호환성: 원본/01~04 보존. 새 버전 등록부를 유지하고 채택 링크만 수정한다. 기존 CSV ID 삭제·재사용 금지. 초안 수정은 CH 기록.
- 검증 계획: 원본 직접 보기 → 수작업 바운딩 박스·경로 등록 → ID/범위/연결/조합 수 검사 → 원본과 영역별 재대조 → 문서 링크 검사 → validator-client 독립 검토.
- 미정: 정확한 실루엣·충돌·월드 변환·반경·dt·정지 시간·도달/정체 기준. 이 값 없이 실행 가능한 사례라는 주장 금지.
- 검토 결과: [검토 기록](../reviews/map-meadow-005-r001-review.md).

## 인수와 다음 조건

현재 범위는 G0/G1 등록 준비다. 최종 지도 충돌·전수 실루엣·모든 통로가 확정된 상태가 아니다. 외곽은 연속 돌 하나하나 대신 4개 조사 구역으로 등록하고 시각 잔돌·꽃·지면 무늬는 개별 객체에서 제외한다. 어두운 외곽에서 숨은 객체까지 전수 확인했다고 주장하지 않는다.

다음은 이 등록부를 바탕으로 충돌 후보의 윤곽·필수 통로 정책과 월드 변환의 결정안을 작성하는 일이다. 실제 제작은 사용자 지시에 따라 계속 보류한다.
