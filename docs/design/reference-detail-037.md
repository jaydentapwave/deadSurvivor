## 사용할 수 있게 될 결과

같은 원본 영역 x100..520/y100..360을 새 격리 장면에서 비교한다. 036의 단순한 다각형 테두리·빈 녹색 면, 큰 흙 얼룩과 연속 밝은 외곽 띠, 성긴 길을 개선한 후보가 완료 조건이다. 전체 맵/최종 미술 채택과 구분한다.

GPT-6.1 Sol high 읽기 전용 분석의 관찰 좌표를 반영한다.

- OB-001(x195..255/y140..200): 내부의 비대칭 회색 파편 2~3개. 배치는 원본 관찰 기반 제안이며 정밀 추적이 아니다.
- 곡선 OB-002..004: 석재 길이·폭·높이를 달리하고 드문 낮은 틈을 만들어 균일한 연석 인상을 줄인다.
- 작은 식생: 원본에서 대략 (224,185), (342,199), (238,272), (466,270)에 관찰된다. 기존 C 안에서 잎·낮은 군집 메시로 제안하며 네 지점에 한정한다.
- 흙: 왼쪽 x120..180/y190..300과 중앙 x270..340/y220..300의 큰 패치를 작은 얼룩으로 분할한다. 잔해 주변은 전둘레 띠 대신 국소 흔적으로 만든다.
- 길: RT-003 중심선 유지. 작은 돌로 틈을 채우고 회청색 재질 비중을 높인다. 줄 배열은 만들지 않는다.

## 최소 검사와 완료

먼저 실제 Unity 상면 렌더를 원본/036과 같은 범위로 비교한다. 독립 검토자가 소스·배치 계산과 직접 화면을 확인하고 필수 지적을 수정한다. 이어 기존 정상 키보드 입력 관찰을 재사용해 4인 풀밭/길 이동과 잔해 인접 가독성을 확인한다. 시각 장식이 C 밖으로 새 단단한 장애물처럼 보이지 않도록 배치 확인을 기록한다. 의미 없는 전체 경로 조합/새 범용 검사기는 추가하지 않는다.

Play 시험 뒤 **먼저** 폰트 캐시와 기존 파일·편집 상태를 복구하고 지문 일치를 강제 확인한다. 그 뒤 최종 자산에 필요한 `all --screens`와 최종 gate를 수행한다. 036의 자동 폰트 변경을 복구하기 전에 전체 회귀를 먼저 실행했던 순서를 반복하지 않는다. 독립 최종 증거 검토와 현재 상태 링크로 마감한다. 새 결함이나 의존 변경이 없으면 같은 검사를 반복하지 않는다.

독립 첫 검토 후 r002에서 실제 잎 외곽 전체 변의 C 내부 검사, 넓고 짧은 잎과 낮은 중심 볼륨, 옅은 연결 얼룩과 넓은 알파 경계를 보완한다. 첫 r001은 비교 이력으로 보존한다.
