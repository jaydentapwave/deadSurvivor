# MAP-MEADOW-007 r001 — 3. 크기·반경·카메라 보정 시험

상태: 실행 방법 설계. 모든 실측/런타임 NOT_RUN. [근거대장](map-meadow-007-r001-evidence.md)과 [006 변환식](map-meadow-006-r001-contract.md)을 사용한다. 숫자를 많이 채우는 것보다 숫자의 획득 방법과 단위를 고정한다.

## 정적 하한과 동적 검증

단위 통로 법선 n과 슬롯 o_i에 대해 `Wreq(n)=max(dot(n,o_i)+r_i)-min(dot(n,o_i)-r_i)+2m`. 분리된 양쪽 C 사이의 동일 단면 실제 간격을 w_px라 할 때 `s >= Wreq/w_px`가 그 단면의 필요 조건이다. 양쪽 윤곽·단면이 정의되고 w_px>0인 경우만 계산한다. 길의 그림 폭이나 객체 bbox 간격은 사용하지 않는다. 표본 단면 최대값은 전역 통과 보장이 아니며 곡률·끝단·전체 공간 연결을 추가 검사한다.

모든 수는 유한, r_i/m≥0, n은 단위 벡터, 파티 슬롯 비어있지 않음, s/k>0 및 곱 유한 조건을 만족해야 한다. 숫자가 없거나 표현 범위를 벗어나면 BLOCKED. 끝점 사이 거리만으로 곡선 통과를 합격 처리하지 않는다.

## 실험 순서와 고정 조건

1. **CAL00 자료 확인:** E01/배치/정책/코드 지문, V/C/U 상태, 몸체/단위/입력 지원 dt를 확정한 실행 후보 묶음 준비. 자료 불충분이면 실험 가능/판정 가능 상태를 분리.
2. **CAL01 빈 지면 기준:** 기존 속도140와 Lerp12dt를 유지하고 세 진형×1~4인에서 전진·정지·반전. 추종 오차, 정지 수렴, 실제시간/시뮬레이션시간 기록. 관찰 창·샘플 간격을 사전 고정.
3. **CAL02 맵 크기 비교:** 가장 제한적인 필수 단면들의 하한으로 S0 후보를 정하고 E12의0.85/1/1.15×S0를 탐색용으로 비교. 캐릭터/카메라/속도 고정. 실패 후보를 숨기지 않음. 모두 실패하면 C/정책/스케일 원인을 분리하고 CH 개정.
4. **CAL03 필수 이동:** 모든 필수 RT와 연속 원형 진입→내부→이탈, 전체 연결. 전진/역방향 별도 초기화와 정지 후 즉시 반전을 구분. 일부 대표 통과를 G3 전체 통과로 승격하지 않음.
5. **CAL04 카메라:** 스케일·신체를 고정하고45/55도 및 화면비 비교. 동일 P/T/경계 위치에 실제 UI를 켠 프레임. 발·적 접근/공격 예고가 보이는지와 화면 끝 지면 노출을 항목별 기록. 구조를 바꾸어 가림을 감추지 않음.
6. **CAL05 기준 채택:** 후보별 실패·성공·소요시간·최소 여유·가림을 비교해 선택 이유 기록. 사람이 판단할 조작감 항목은 직접 플레이 평가로 남김. 기준 버전 고정 후 독립된 새 실행으로 판정.

| 키 | 출처/선정 절차 | 합격에 필요한 것 |

| geometry_epsilon | E03 단위 변환/수치 표현 및 접촉·얇은 벽 대조 도형의 측정 오차. 최소 통로를 덮어 버리는 큰 값 금지 | 오차를 넘는 관통0. 해상도 미만 결과는 확정 PASS 대신 판정 불가 |

현재 이 표의 실측 수치는 null/미정이다. 출처가 없어서 비운 것이 아니라 원작에서 얻을 수 없는 **우리 게임의 측정값**임을 명시하고 측정 절차를 정한 것이다. 이 상태로 최종 실행 기준이 준비됐다고 보고하지 않는다.

## 기존 시간 경로를 보존하는 시험

E16 Update의 `dt_request=min(unscaledDeltaTime,0.05)*Config.speed`, E05 Simulate의 `dt_applied=min(dt_request,max(0,Duration-Elapsed))`를 구분한다. 원래 프레임 dt·배속·요청 dt·적용 dt 모두 기록한다. 지원할 Config.speed 집합은 실제 설정/시험 범위를 별도 고정한다. .05를 최종 dt 상한으로 쓰지 않는다. CAL01/03에는 정상 프레임, .05 전후, 배속, 마지막 남은 웨이브 시간이 요청보다 작은 경우를 포함한다. 입력0 추종 중 얇은 벽과 배속 관통도 별도 반례다. 음수/NaN dt와 비정상 배속은 시험 사전 조건에서 거부하며 기존 코드가 이미 이를 처리한다고 주장하지 않는다.
