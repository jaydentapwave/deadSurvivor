## 다음 등록 양식

개별 군집마다 OB ID / 연결 RF / 원본 정규화 바운딩 박스 / 시각 형태 / 불확실성 / 설계 좌표(없으면 미정) / 충돌 후보(미정 가능) / 인접 RT / 영향 MC / 변경 CH / 검토 증거를 채운다. 원형 잔해를 단일 충돌 원판으로 등록하지 않고 조각 ID와 군집 상위 ID를 구분한다.

RT에는 양 끝의 유효 지면 영역, 필요 통과 진형, 주 경로/대체 경로/장식 틈, 최소 폭 측정 방향, 연결 OB, 사례 ID를 기록한다. T 마커를 출발 좌표로 복사하지 않는다.

G1 통과 전에는 모든 주요 군집과 필수 통로가 등록되어야 한다. RF 표 10개 작성만으로 ‘지도 전체 대응 완료’라고 보고하지 않는다. 03/04의 정성적 PASS와 객체 단위 미완성을 분리한다.
