# MAP-MEADOW-007 r001 — 2. 공통 배치와 도면

[근거대장](map-meadow-007-r001-evidence.md) E01의 원본 픽셀 위에서 수작업으로 거친 관찰선을 작성했다. [공통 배치 JSON](map-meadow-007-r001-layout.json)은 **준비용 후보 원본**이다. 실제 게임 콘텐츠 원본이나 원작 충돌 자료로 승격하지 않는다.

## 무엇이 같은 원본을 쓰는가

| 판 | 표현 | 파일 |
|---|---|---|
| 구조 | 원본 이미지와 주요 군집 ID. 원본 그림을 다시 생성하지 않음 | [PNG](../art/maps/map-meadow-007-r001/map-meadow-007-r001-structure.png) / [SVG](../art/maps/map-meadow-007-r001/map-meadow-007-r001-structure.svg) |
| 충돌 후보 | V에 근거한 시험용 C 외피와 U, 외곽 후보. 원형 내부 비충돌 | [PNG](../art/maps/map-meadow-007-r001/map-meadow-007-r001-collision.png) / [SVG](../art/maps/map-meadow-007-r001/map-meadow-007-r001-collision.svg) |

네 판 모두2400×1800, 동일 지도 변환/범위/원본 해상도. 제목/범례/단위/상태/입력 지문을 표시한다. 구조판에서는 원본의 길·식생을 그대로 보여 주고, 시험판은 같은 지형을 흐리게 표시한다. 기존005 검색 박스는 비교 대상으로만 남기며 충돌로 사용하지 않는다. SVG가 표현 원본이고 PNG는 그 렌더다. 생성 모델을 이용해 네 판의 배치를 각각 재해석하지 않았다.

## 객체별 기록과 해석 한계

- 주요 군집64개의 V는 직접 관찰한 거친 외피 정점이다. 정밀 측량이 아니므로 precision_px는 null이다. 각 객체의 E01:OB 위치, RF, 부모, 관련 RT, C 선정 이유, U 영향 범위를 같이 기록한다.
- C는 처음 시험할 보수적 외피 후보다. 이번 개정은 V 외피를 C 후보로 사용했으나 **바닥 접촉면을 안다는 뜻이 아니다**. 외피 안의 그림자/식생/입체 높이를 분리하지 못한 영역을 U로 기록하고 모든 C 타당성은 BLOCKED로 둔다. 알 수 없는 실제 두께를 임의로 줄여 통로를 열지 않는다.
- 곡선/사선은 장축과 굴곡을 따라 정점을 직접 작성했다. bbox를 타원/사각형으로 자동 변환하지 않았다. OB060~063은 각각 띠 형상이며 OB-G01은 비충돌 부모다. 부모 원판이나 네 조각 사이 빈 영역을 추가하지 않았다.
- OB-B01~04는 벽 네 개가 아니라 외곽 조사 구역이다. PERIM-01은 이어진 **내측 경계 제안**이다. 특히 부착 군집 OB008/019/030/048/064의 경계 접합과 식생 아래 바닥은 미확정이다. 분리/합집합 정책은 실제 모델과 대조 후 개정하며 얇은 틈을 임의 통과 가능하게 취급하지 않는다.
- 군집 사이 미세 잔돌이나 각 군집 내부의 빈 틈까지 전수 관찰됐다고 보장하지 않는다. G1 충실도 최종 인수에는 남은 U 분류와 주요 구조 대조가 필요하다. 도형 유효성 검사 PASS와 충돌 의미의 타당성 PASS를 구분한다.

## 연결 그래프

005의17 RT를 이동시키지 않고006의 RT018을 추가 참조했다. 여기에 분리된 시험 구간을 잇는 LC01~11을 같은 layout에 등록했다. LC는 원본에 보이는 열린 지면을 바탕으로 작성한 **우리 시험 경로 제안**이며 원작 경로 데이터가 아니다. 정확한 끝점/중간점 공유를 통해18 RT 묶음이 연결되는지 정적으로 검사한다.

| 연결 후보 | 연결 |
|---|---|
| LC01/02 | 좌상 우회/우상 틈 ↔ 상부 가로길 |
| LC03/04 | 우하 사선/중부 풀밭 ↔ 하부 길/중앙 굴곡 |
| LC05 | 원형 좌상 진입 ↔ 하부 가로길 |
| LC06/07 | 추가 진단 개구부 RT007/009 ↔ 원형 내부 RT018 |
| LC08~11 | 좌/상/우/하 경계 접근 시작점 ↔ 내부 시험망 |

시작 P01은 RT016으로 중앙 연결에 붙는다. RT006→RT018→역RT008은 초기화 없이 연속으로 수행해야 한다. RT007/009는 진단 통로여도 충돌/경계 안전은 생략하지 않는다.

이 그래프는 **선의 연결**이다. 반경0 선분이 후보 C와 겹치지 않아도 파티가 통과한다는 뜻이 아니다. 실제 C 채택 뒤 각 진형 점유로 자유 지면의 연결 성분을 구하고 모든 필수 지면 성분이 P와 연결되는지 확인한다. LC를 붙였다는 이유로 MC-CONN-01을 통과시키지 않는다. 도형 연결 분석과 실제 입력 재생 둘 다 필요하다.

## 갱신 절차

원본/정점/통로를 변경하면 CH에 대상 OB/RT/RF를 기록하고 layout 개정과 지문을 바꾼다. [도면 출력용 파일](../art/maps/map-meadow-007-r001/render_sheets.py)로 SVG 네 판을 함께 갱신하고 같은 SVG를 PNG로 렌더한다. 자동 수치 판정/Unity 하네스 기능은 아니다. [준비 자료 검사](../art/maps/map-meadow-007-r001/audit_preparation.py)는 ID·도형·연결·지문과 후보 교차 진단만 담당한다. 좌표/상태/정책 변경 뒤 출력물을 직접 확인한다.

출력 회귀 검사: 임시 자료에서 C만 가로3px, U만 세로5px 이동시켜 충돌/시험판은 각각 바뀐 좌표, 변경판은 기존 V를 쓰는지 검사한다. 이 수치는 도면 계층 분리 검사 입력이며 게임 수치가 아니다. 최종 자료는 원래 후보 좌표를 유지했다. 검사 실행에는 XML 모듈이 정상인 번들 Python을 사용했다.
