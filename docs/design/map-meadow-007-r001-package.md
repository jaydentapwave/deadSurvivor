## 요구와 근거

사용자 요구: 우선순위1~4 모두 레퍼런스에 의한 근거가 존재하도록 구축. 원작 이미지로 확인할 수 없는 충돌·몸체·시간 수치를 원작 사실로 만들지 않는다. 모든 정책과 측정 절차에 **출처 → 확인 내용 → 우리 적용 판단 → 검사 → 남은 불확실성**을 연결했다.

[근거대장 E01~16](map-meadow-007-r001-evidence.md)은 원문 위치, 지지하는 사실, 지지하지 않는 주장을 함께 기록한다. 공개 wiki 페이지 직접 접근은 현재403이므로 보유 원본의 직접 관찰을 근거로 삼았고 최신 원작 대조 완료로 표시하지 않았다. 공식 Steam 소개는 장르 배경만 지지한다. 각 화면/진형/실험 숫자를 모두 원작에서 가져왔다는 주장은 하지 않는다.

## 입력과 산출물

- E01: 보유 원본 PNG1195×1110, 직접 이미지 도구로 확인. 모든 도면의 배경/좌표 기준.
- E02/03: 005 CSV/006 계약과 정책, 과거 계획 보존. 원본에서 파생한 분석이며 독립된 게임 증거는 아님.
- E04~08/16: 이 프로젝트의 로컬 코드 직접 읽음. 실제 Unity 대상과 동기화 확인은 NOT_RUN.
- E09~11/14: 공개 공식 문서 조회. [근거대장](map-meadow-007-r001-evidence.md)에 URL·확인일·정확한 주장 범위 기록.
- [입력 지문 목록](map-meadow-007-r001-inputs.json): 원본·이전 등록부·코드·기존 규격 SHA-256. 출력/검사별 지문은 검증 기록에 포함.
- 도면:2400×1800, 원본 비례 보존, 같은 layout hash/같은 변환. SVG 네 판과 PNG 네 판. 정밀 원작 측량 도면은 아님.

## 검증과 인수

현재 G0/G1 준비 중. 네 판의 동일 원본, 좌표와 ID의 구조적 일관성을 검사하고 수작업 원본 대조를 수행한다. 이 결과로 G1 전체·G2·G3를 통과시키지 않는다. **전체 실측 윤곽·바닥 접합·최종 기준값·실제 입력열·실행 하네스는 아직 없다.** 실제 입력열은 보정 후보가 정해진 후 생성/동결할 수 있으며 현재는 그 생성과 판정 방법까지 명세했다.

계획: 기존372개 보존 + RT018 24조합 + 연속 원형24조합 + 아직 상세 조합 미전개 상태 시나리오8행. 현재 계획행을 실행 횟수로 합산하지 않는다. 모든 실행 NOT_RUN, 인수 준비 BLOCKED.

차단 목록:

1. C 후보와 실제 우리 모델 접지면/외곽 접합의 대응 확인. 원작 충돌을 알 수 없는 부분은 우리 적용 판단·시험으로 해소해야 함.
2. 신체 r_i, s/k, dt 지원 범위, 도착/정체/오차/가림 임계값의 보정·채택. 임의 수치 대입 금지.
3. 실제 상태 전환·입력·관찰 어댑터 및 FI01~10 구현/실행. 준비 도면 출력 도구는 맵 하네스가 아님.
4. 형성된 자유 지면 전체 연결과 실제 이동 검증. 후보 선의 연결은 파티의 통과 증명이 아님.
