# 후속 개선 A1~A8

이 문서의 주무기/직업 계약은 후속 사용자 요청으로 대체되었다. [병렬 실행](아이템-병렬실행.md)과 [현재 규칙](장비규칙.md)이 우선하며, 캐릭터별 범위 제안은 미적용 상태다.
상태: 로컬 구현·검증 완료 / L2 (계측·실험 경계 추가), 후속 입력 보완 L1. 실기기·사람 평가·최종 아트 제외. 사용자 승인 범위: 에이전트가 가능한 후속 구현·검증을 순차 진행. 로컬 기록만 사용.

## 구현 계약

- A1: 특수 개수 효과는 등급과 무관한 실제 유효 수치로 비교. 설명은 공통 유효값에서 수치/단위/조건 생성. 추천 테두리와 배치 칸/인접 기존 무기 강조 분리, 원래 상태 변경 없이 미리보기.
- A2: 기존 1600×900 논리 캔버스 유지. 화면 비율별 레터박스/안전 영역 내 조작 보장. 테스트 전용 해상도 변경은 원래 GameView 설정 복구. 텍스트 잘림/버튼 영역 캡처 검사.
- A3: 최초 런타임 초기화~첫 UI 프레임을 측정. 프로세스 시작 시간으로 오인하지 않도록 보고서에 측정 구간/Editor 여부 명시. 재시작해도 최초 값 유지. 미완료 -1.
- A4: Editor 전용 실험 도구에서 동일 시드·시뮬레이션 dt·결정된 이동 정책·파티·장비·기본 설정으로 반복. 실제시간과 자동 시뮬레이션 시간을 분리. 결과는 사용자가 지정한 로컬 출력 경로만. 검사 끝에 Config/RNG/VerificationRun 복원, 소유 플레이 세션만 정리. 인간 승률/재미 주장 금지.
- A5: 먼저 기본 장비/보상 통계를 측정. 보상은 기존 weight를 기반으로 초반(1~3) 현재 직업에 맞는 보조 2배, 후반(4~9) 현재 소지 동일 아이템 1.5배 시험. 주무기와 다른 후보 양의 확률 유지. 당시33개/9회 기준. 후속 사용자 요청으로 매회3~5개/9회로 변경(웨이브 설계 참고). 기존 weights 설정 유지하며 multiplier를 결과에 기록. 근거가 없으면 추가 전투 수치 조정 보류.
- A6: 동일 이동 입력과 장비·적 조건으로 3진형 비교. 가장자리/방향 전환/부활 좌표 확인. 자체 능력치 보너스 없음.
- A7: 원문 확정 규칙과 후보를 구분한 추적표 작성. 추가 투사체 같은 타겟 적중 허용, 동일 투사체 동일 적 재적중 금지, 화염탄 적중마다 폭발, 연쇄 재방문 금지의 실제 구현과 검증 대조.
- A8: 아트 명세·32종 대응표·로컬 벡터 시안 준비. 외부 생성/유료 API는 호출하지 않음. 최종 스타일 및 래스터 아트는 완료로 표시하지 않음.

## 검증

각 A의 변경 후 의미 있는 경계/입력 검사를 추가. Unity 컴파일·규칙·실제 프레임·입력·캡처·콘솔. 독립 설계/구현 리뷰. 실험은 복수 시드의 조건과 결과를 함께 저장. 물리 기기·사람 재미·최종 스타일은 별도 상태.

## 설계 리뷰 F1~F3 보완

- F1: 매 실험 시작 시 uid=0, 입력=0, 새 시드 RNG를 설정하고 StartRun으로 모든 전투/장비 타이머를 초기화한다. 적 RNG와 보상 RNG를 분리한다. 이동은 고정 dt=0.05초, 20초 사각 순환 입력, 파티0/2/4/5, 초기 장비 그대로, 보상 미장착/합성없음/부활없음. 최대10웨이브·9000스텝. 시드17/29/43으로 세 진형 비교, 같은 조건을 한 번 더 실행해 결과 JSON 일치 확인. 재배치 이벤트는 전투 결과에 의존하므로 초기 적 조건/정책이 같은 비교이며 적 궤적 전체 동일을 주장하지 않는다.
- F2: 실험 전체를 동기식 Editor 호출로 한정하여 일반 Update가 중간에 끼어들지 않음. 기존 하네스가 소유한 새 Play 세션에서만 실행하며 사용자 활성 Play/미저장 씬/리로드 비활성은 차단. finally 설정 복원 및 로비 정리, 외부 하네스가 소유 Play 종료와 background 복원. GameView를 바꾸는 검사는 별도 복구 포함.
- F3: 보상 생성 직전 생존자의 장착 장비만 스냅샷. 초반은 해당 생존자 직업/무기 대상 조건을 만족하는 보조(공간/인접은 배치 전이므로 보장하지 않음). 후반은 스냅샷의 일반등급 장비와 동일 ID만 합성 후보(드랍은 일반등급). 사망자·보관함·이번 보상 묶음 신규 아이템 제외. 각 배수는 한 번만, 원본 weight 불변, 0 제외·양수 유지. 현재는 시도할 시험안이며 결과에 따라 채택 여부 기록.

## 장비별 비교 확장

A5는 기존 초기장비 실험만으로 판단하지 않고 32종×3시드의 미장착/장착 쌍을 추가한다. 직업에 맞는 기존 파티원 1명에게 한 아이템만 첫 유효 위치에 배치, 주무기는 교체. 연쇄 보조의 경우 두 분기 모두 완드로 맞춘다. 두 분기 모두 시작 최대HP·쿨다운0이며 시작 장비/배치/수치를 결과에 기록한다. 진형은 균형, 뷰포트1180×748, 이후 보상 미장착 정책 유지. 같은 조건 반복 검증18회와 별도로 총96쌍192회의 장비별 자동 비교를 수행한다. 각 쌍을 재반복했다고 표시하지 않는다. 이는 고정 자동 정책의 파일럿이며 최종 순위나 인간 승률로 해석하지 않는다.

## A7 대조에서 확인한 해제 미리보기 보완 (L1)

보관함으로 장비를 해제할 때도 복사 상태의 능력치·직업·공유 회복을 표시한다. 해제 규칙을 EquipmentRules로 모아 미리보기/실제 적용이 공유하고, 탭 해제는 첫 탭 미리보기/두 번째 탭 적용으로 맞춘다. 드래그 해제는 놓을 때 적용한다. 주무기 해제에는 출발 불가 안내를 표시한다. 인접 이동·회전·합성·캐릭터 간 이동·해제 각각 복사 상태와 적용 후 장비/계산값/공유 제공자의 일치 및 원본 불변을 검사한다.

보관함 합성에도 같은 규칙을 적용한다. 공통 Merge 거래로 원본·대상 사망 잠금 및 등급 제한을 유지하고, 장착 장비를 보관함 장비에 합성할 때 원래 소유자의 효과 상실을 비교한다. 보관함 합성 첫 탭은 결과 등급/파티 변화 미리보기, 두 번째 탭 적용이다.
