# 036 — 원본 기반 대표 구역 지면과 잔해 단면 시험

2026-11-02 · L1 · [사전 원인 메모](../reviews/reference-drift-retrospective-20261102.md) · [035 기준](reference-reset-035.md).

## 이번 결과와 범위

새로운 격리 Unity 장면에서 원본 x100..520/y100..360의 풀밭·흙 흐름·연속 회청색 자갈길을 확인하고, 여섯 원본 윤곽에 얇은 석재 외곽/녹색 상부를 올린 낮은 잔해 단면 후보를 비교한다. 위쪽 동일 영역 캡처와 실제 게임 카메라 캡처, 실제 이동 입력 확인이 완료 조건이다. 이는 최종 미술 채택이나 전체 맵 인수가 아니다.

- 원본: `docs/art/maps/references/VerdantMeadowsFullMap.png`. 035 생성 그림은 스타일 참고일 뿐 좌표 원본이 아니다.
- 배치/충돌: `Assets/DeadSurvivor/Scenes/Map018_r001/Layout.json`을 그대로 참조한다. 기존 C·스케일·이동 코드·가림 코드를 변경하지 않는다.
- 새 산출물: `Assets/DeadSurvivor/Scenes/Map036_ReferenceGround_r003`, 제작 스크립트 `Tools/Art/build_reference_ground_036.cs`, 프로젝트 내부 결과 기록. 기존 씬/프리팹은 덮어쓰지 않는다.
- 지면 텍스처는 실제 원본을 입력으로 제작하며 입력·프롬프트·결과를 기록한다. 흙 형태와 자갈길은 원본 관찰 좌표/기존 RT-003 경로로 제작한다.
- 잔해 외곽은 기존 여섯 객체 OB-001..006 윤곽을 보존한다. 높이 0.22~0.36m, 얕은 회색 테두리와 녹색 상부는 이번 시험 제안이며 실측값이 아니다. 내부를 통과 가능한 방으로 만들지 않는다.
- Tripo 추가 생성·결제, N2 빌드/성능, 전체 맵 미술 교체는 이번 범위 밖이다.

## 최소 검사와 실제 연결

1. 변경 전 소스 지문·열린 씬·dirty·Play/배경 실행 상태를 기록하고 안전한 새 목적지에서 제작한다.
2. 새 씬을 열어 실제 게임의 정상 프레임/키보드 입력으로 지면·자갈길 구간 이동을 확인한다. 지면 장식은 Collider와 새 충돌/통행 규칙을 만들지 않는다.
3. 같은 원본 영역의 top view와 실제 55도 게임 화면을 캡처한다. 잔해 6개/녹색 상부/석재 테두리/흙·길의 구분 및 파티 가독성을 독립 검토한다.
4. 사용자 기존 씬과 상태를 복구하고 기존 파일 보존을 확인한다. 안정된 최종 자산에서 gate가 요구하는 `all --screens`를 한 번 수행한다. 실제 변경·실패가 있으면 그 영향만 재검사한다.
5. 최종 gate와 독립 증거 검토. 문서/자산 변경 이외에 기존 런타임 코드 변경이 생기면 범위와 검사를 재평가한다.

재생성 그림을 바닥 전체에 붙여 3D 구현처럼 보여주지 않는다. 타일 가능한 지면 재질, 실제 메시와 기존 게임 입력으로 확인한다. 정확한 원본 실측/최종 단면·사용자 미술 채택은 미정이다.

첫 r001 캡처에서 단색 흙 조각/규칙적인 자갈 배열이 드러나 r002로 보정한다. r001 파일은 보존한다. 제작 중 실패하면 소유 폴더와 부분 파일을 build-failure.json에 기록하고, 새 revision에서 재개한다. 기존 폴더를 자동 삭제하거나 덮어쓰지 않는다.

r002 직접 비교 후 원본 풀밭 세 지점의 색을 확인해 황록/명도를 낮추고, r003 자갈은 동일 RT-003 중심선에서 크기가 다른 비정렬 배치로 보정한다. 기존 C에는 영향이 없다. 높이 .22~.36m는 단면 기준값이며 녹색 면은 +.003m, 테두리 최고점은 기준값 +.07m 이하인 시험 제안이다.
