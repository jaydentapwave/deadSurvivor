# 아이템 병렬 실행

상태: L2 설계 독립 검토 PASS 후 구현·검증 완료. 사용자 요청: 주무기/보조 특성 제거, 여러 무기가 각각 쿨타임을 갖고 동시에 동작.

- 주무기 지정/한 개 제한/교체/무기 없는 출발 차단과 무기 기반 직업 전환을 제거한다. 모든 아이템은 같은4×4 배치/합성 규칙을 사용한다. 공격 없는 장비만으로도 출발 가능하다.
- 공격·직접 회복·패시브·주기 효과는 기존 아이템 고유 기능을 유지한다. 방어구에 새 공격을 만들지 않는다. 무기 형상/효과/수치의 실제 표현은 남긴다.
- weaponClass/matchClass를 데이터에서 제거한다. classEffect/classValue는 bonusEffect/bonusValue로 일반 추가 효과에 개명한다. 직업 조건을 제거하고 대상 공격 방식/인접 조건으로만 추가 효과가 활성화된다.
- 인접 공격 강화는 해당 아이템과 인접한 적합한 공격 아이템 각각에 적용한다. 하나가 인접했다고 다른 먼 무기까지 강화하지 않는다. 기본 효과와 조건 없는 능력치는 캐릭터 전체에 한 번 적용한다. 방어/HP/회복/보호막 등의 캐릭터 효과와 공격별 능력치 계산을 분리한다.
- 공격 아이템마다 Gear.cd를 독립 사용한다. 하나가 쿨타임/타깃없음/회복대상없음이어도 다른 무기는 계속 검사한다. 같은 타입도 각각 작동하며 합성은 같은 칸에 놓았을 때만 수행한다. 시작/부활 초기화, 정비중 정지, 해제 시 실행 제외를 유지한다.
- 주기 피해의 기존 Gear.cd, 캐릭터 자기회복/보호막/공유 타이머는 유지하되 현재 데이터에서 한 아이템에 공격과 주기피해가 동시에 존재하지 않음을 검사한다. 공격 없는 지속 스탯에 쿨타임을 만들지 않는다.
- 공유 회복은 직업 대신 공유 효과 아이템 보유자가 제공하며 최고 초당 회복량 한 명/자기 제외/사망 제외 규칙 유지.
- UI: 주무기/보조/직업 제한/자동 교체 문구 제거. 장착한 발동 아이템 목록과 개별 피해·간격·거리 비교, 추가 효과 활성 대상 강조를 다중 무기에 맞춘다.
- 보상3~5개 유지. 초반 추가효과의 대상 조건이 맞는 아이템 가중치, 후반 동일ID합성 후보를 유지. 실험 도구는 새 배치/능력치 API를 사용하도록 수정하고 과거 결과는 과거 정책으로 표시한다.
- 검증: 여러무기 공존/충돌 원상/독립 쿨타임/한 무기 타깃없어도 다른무기 발동/공격+회복 병행/동종 무기/해제·사망·정비 정지/인접 영향의 무기별 분리/공유/3~5보상/복사상태 비교/실제 입력. 기존 테스트 중 폐기된 직업/교체 계약만 교체하고 독립 회귀는 유지.

캐릭터별 사거리 제안은 미확정이므로 이번 변경에 포함하지 않는다.
