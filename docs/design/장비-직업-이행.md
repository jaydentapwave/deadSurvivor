# 장비와 직업 체계 이행

이 문서의 주무기/직업 계약은 후속 사용자 요청으로 대체되었다. [병렬 실행](아이템-병렬실행.md)과 [현재 규칙](장비규칙.md)이 우선하며, 캐릭터별 범위 제안은 미적용 상태다.
상태: 설계 검토 PASS 후 프로토타입 구현. L2. 원본 요구: 할일.md의 장비 세부 규칙, 32종 후보, 비교/추천 UI.

## 구조

DSGame은 상태 소유를 유지한다. DSGame.Inventory는 배치/교체/합성, Stats는 순수 효과 계산, EquipmentCombat은 신규 공격·회복 실행을 맡는다. ItemDef에 weaponClass, attackMode, baseEffect, baseValue, classEffect, classValue, requiresAdjacent, targetMode, spriteKey를 추가한다. 기존 필드는 새 콘텐츠에서도 필요한 피해·간격·사거리·모양 표현에 활용한다. Gear는 0~3 rotation을 가지며 이전 rotated 필드는 이전 데이터와 혼동하지 않도록 신규 기본값 0으로 이행한다. 영속 이어하기가 없으므로 이전 런 저장은 복원하지 않는다.

## 장비 계약

주무기 한 개가 현재 직업을 결정한다. 배치 계획에서 원래 소유자와 대상 주무기를 제외한 가상 점유로 검사 후 한 번만 적용한다. 실패는 상태 불변. 교체된 기존 주무기는 보관함으로, 원래 캐릭터는 무기 없음으로 남는다. 같은 ID/등급이면 합성 우선. 사망자 잠금. 회전은 선택 중 임시 모양으로만 표시하고 성공 시 저장한다.

효과 계산은 인수로 받은 Team/Gear 스냅샷만 읽는다. 미리보기는 복사한 팀/보관함에 같은 배치 함수를 적용해 비교한다. 체력/타이머/쿨다운 원본에 쓰지 않는다. 장착 후 최대 HP 증가는 현재 HP를 늘리지 않고 감소 시 clamp한다.

기본 효과는 모든 보조 장비에서 적용. 추가 효과는 직업/대상 무기/선택적 상하좌우 인접 조건 검사. 수치 합산, 방어 80%, 속도 +100%; 관통/추가발사/연쇄 수는 같은 효과 최댓값. 보호막 한도는 활성 효과 최댓값. 사제 보조 회복은 자기 장비에서만 계산한 3초 회복을 공유, 수신자별 최고 초당 회복 제공자 1명, 동률 슬롯 순서, 자기 제외. 제공자/주기가 바뀌면 수신자 타이머 초기화. 정비 타이머 정지.

## 32종과 첫 수치

원 후보 이름/모양은 유지하며 보조마다 기본 하나+직업 추가 하나로 정리한다. 기본값과 등급 배율은 JSON에 둔다. 숫돌/수정은 각각 전사/마법사 피해 추가, 장갑/화살통/반지는 대상 및 기본 수치 차이로 구분한다. 사제 6종 기본은 자기 회복, 추가는 파티 공유로 단순화한다. 기존 후보의 회복 사거리/보호막 효과는 이번 기본/추가 1개 기준에 맞춰 대체하고 이전 표와 변경표를 문서에 남긴다. 수정 구슬의 추가 효과는 주기 범위 피해, 마법 로브는 주기 보호막. 사제 직접 회복 주무기는 보조 공유 원천에서 제외한다.

전사 검/도끼는 근접/넓은 부채꼴, 궁수 활/쇠뇌는 단일 투사체, 마법사 지팡이/완드는 단발 폭발/연쇄, 사제 성물/향로는 최저 체력 비율 단일/주변 회복. 화염탄은 1회 폭발 후 소멸, 번개는 동일 발동에 재방문하지 않음, 여러 발은 각각 적중 가능. 특수 효과 대상 조건을 UI에도 표시한다.

## 검증과 후속

모든 모양 4회 회전/경계/겹침/인접, 교체 실패 보존, 빈 주무기 출전 차단, 직업 변경/죽음/부활/탈착 후 공유 제거, 여러 사제 최댓값/본인 중복 제외, 미리보기 원본 불변, 모든 무기 방식 실행, UI 실제 입력과 캡처. 변경 전 145회 결과를 보존하고 낡은 18종/거리 공유 기대는 기획 변경 근거와 함께 새 검사로 교체한다.

웨이브435초/정비당 무작위 보상3~5개와 진형 실험은 장비 검증 이후 별도 작업으로 진행한다. 밸런스와 실제 10분 플레이는 자동 규칙 검사의 통과와 구분한다.

## E2/E3 입력과 표시 계약 보완

자기 아이템 위 드롭은 자기 재배치로 판정한다. 다른 동일 타입/등급 위 드롭은 합성을 우선하며 대상 위치·회전을 보존한다. 다른 주무기 위 드롭은 기존 주무기의 시작 좌표에서 교체를 검사한다. 빈칸 드롭은 해당 좌표로 검사한다. 실패/취소 시 회전도 원본 그대로다.

비교는 원래 소유자, 대상, 모든 생존 수신자의 능력치와 공유 제공자를 포함한다. 위치 미선택 시 인접 효과를 확정하지 않고 '위치 선택 후 확정'을 표시한다. 실패는 이유만 표시하고 수치 예측을 숨긴다. 추가 효과의 활성/직업 불일치/인접 필요/대상 무기 불충족/더 강한 효과 상태는 실제 계산과 같은 판정 함수를 사용한다.

## E1 데이터 초안

[32종 데이터 초안](items-draft.json)은 당시 초기 수치를 보존한 과거 제안이다. 후속 조정을 반영한 현재 실행 원본은 [PrototypeData](../../UnityMigration/Data/PrototypeData.json)다. 밸런스 확정값이 아니라 플레이테스트용 선택이다. baseValue/classValue는 해당 효과 종류의 수치이고 effectInterval은 초, effectRadius는 기존 전투 픽셀 좌표다. 주무기 range는 42px 단위, damage는 공격 또는 직접 회복량이다. 등급 배율은 초안 gradeMultipliers를 적용하되 관통/추가발사/연쇄는 정수값 고정, 비율·공격·회복·HP는 배율을 적용한다.

shield는 8초마다 최대 한도 보충, startShield는 웨이브 시작 1회, pulse는 3초마다 100px 범위 피해. share는 자기 회복을 다른 생존 파티원에게 공유하도록 하는 표식이며 회복량의 추가 배수가 아니다. 회복 3초 기본 주기에 haste 상한을 적용한다. 보호막 주기는 haste 영향을 받지 않는다.

변경표: 수호 깃발은 범위 방어 후보에서 개인 주기 보호막으로 단순화. 사제 보조 6종은 기존 직접 회복 강화/속도/사거리/보호막 후보 대신 크기에 따른 자기 회복+사제 파티 공유로 통일. 이 선택은 첫 검증용이며 중복 장비의 선택 가치는 플레이테스트 후 재검토한다. 무기 직접 회복은 보조 공유와 합산하지 않는다.
