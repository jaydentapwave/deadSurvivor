# 전투 아이템 표시와 몬스터 감소

## 현재 적용 정책 (추가 요청)

몬스터 배수는0.7에서0.49로 변경해 직전보다30% 추가 감소한다. 캐릭터 옆 아이템·쿨타임 패널은 제거하고 하단 전체 아이템 목록과 실제 독립 쿨타임만 유지한다. 아래의 캐릭터 옆 패널/0.7 관련 내용은 이전 단계 기록이다. 이번 변경은 기존 표시 제거와 기본 수치 수정(L0)이며 하단 타이머 계산은 유지한다.

상태: L1 구현·Editor 검증 완료. [검증 기록](../reviews/전투-아이템표시-20261029.md). 사용자 요청: 몬스터 약30% 감소, 각 캐릭터 옆에 소지 아이템과 쿨타임/공격 시점 표시.

- 기본 countScale을1→0.7로 변경. 웨이브 기본수와 버닝 추가출현이 같은 배수를 사용하며 정수 반올림 오차만 허용한다. 테스트 설정은 계속 덮어쓰기 가능.
- 월드 렌더러에 장착 아이템의 개별ID별 아이콘 패널을 추가한다. 동일 타입도 각각 표시. 4×4 최대16개를 최대8열×2행으로 전부 표시한다. 파티 좌/우 바깥에 연결선과 이름을 붙이고 같은쪽 패널은 세로 간격을 확보한다. 캐릭터 이동과 진형을 따라가며 정비/로비에서는 숨긴다.
- 공격/직접회복/주기피해 아이템의 실제 Gear.cd를 원형 남은시간으로 표시. 준비상태와 대상없음은 남은시간0/준비 색상이고 발동 강조를 거짓으로 켜지 않는다. 지속효과 아이템은 고정 아이콘으로 표시하며 허구의 공격 타이머를 만들지 않는다.
- 실제 발동 시점에 Gear의 시각용 lastPeriod/activationFlash를 갱신한다. 쿨타임 계산/발동 순서는 그대로 유지. 시각용 값은 전투 시뮬레이션 시간으로 감소해 일시정지/정비/배속과 일치. 복사 미리보기도 시각용 상태를 복제하며 원본을 변경하지 않는다.
- 원형 표시는 캐시된32단계 이미지로 렌더해 프레임마다 새 텍스처를 만들지 않는다. 렌더링은 게임 상태를 변경하지 않는다. 장착/해제/합성/사망/부활/재시작에 낡은 아이콘/발동 표시가 남지 않도록 한다.
- 검증: 몬스터 배수, 두 무기의 서로다른 쿨타임/실제발동만 강조/타깃없음/일시정지/사망/부활/상태복사, 1~4인·3진형·최대16아이템 레이아웃, 전투 실제프레임/캡처/기존입력 회귀. 실기기 가독성은 별도.

## 하단 아이템 목록 확장 (L1)

사용자 첨부의 하단 캐릭터 패널에 전체 장착 아이템을4열로 표시한다. 아이콘·이름·남은 초·남은 쿨타임 막대, 준비/실제 발동/지속 효과/사망 상태를 구분한다. 최대16개는4행이며 캐릭터 옆 표시도 유지한다. 실제 Gear 타이머를 읽기만 하고 매 프레임 표시를 갱신한다. 장면 전환 시 참조를 정리하고 입력은 기존 이동 영역으로 전달한다.

하단 확장 구현·검증 완료: [733회 검사와 화면 확인](../reviews/하단-아이템목록-20261029.md).

하단 위치와 이동 입력 높이는 실제 안전 영역 높이를 기준으로 계산한다. 화면 비율 변경 시 UI를 다시 배치한다.
