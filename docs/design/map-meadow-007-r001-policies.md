## MP04 계산 책임과 한계

DSGame이 상태를 소유하고 이동 계산을 호출하는 안이다. 하네스가 위치를 직접 덮어써 통과시키지 않는다. 각 dt에서 입력은 기존 ClampMagnitude 범위로 제한한다. 기존 무장애 이동 후보 `Center + input*140*dt`, 각 생존자 추종 후보 `Lerp(oldPos, candidateCenter+Offset, min(1,12dt))`를 계산한다. 예약 슬롯은 oldCenter+Offset → candidateCenter+Offset 구간으로 검사한다. 각 캐릭터 반경과 지면 경계/C를 사용하며 몸체 크기를 C에 중복 팽창하지 않는다.

이동 해결기는 모든 실제/예약 구간이 안전한 α만 채택한다. **α=0에서도 Lerp가 움직일 수 있으므로** 그 추종 구간마저 안전하지 않으면 해당 프레임 중심과 모든 생존자 위치를 함께 유지하고 원인을 기록한다. 안전 시작 상태에서 0비율 보류가 언제나 가능한지 정상/실패 도형으로 확인한다. 단순 이분탐색의 단조성을 가정하지 않는다. 오목 장애물에서 안전 α 집합이 단순 구간이라는 근거가 없으므로 구간 충돌 또는 보수적 탐색법의 별도 구현 검토가 필요하다.

현재 실제 위치가 이미 장애물 안인 오염/잘못된 초기화 상태는 정상 벽 충돌과 구분한다. 자동 밀어내기·워프를 하지 않고 실행 오류로 중단, 최초 좌표와 C/상태 지문을 남긴다. 이 기준안은 기존 추종 감각과 차이가 생길 수 있으며 MP04 자체의 재미/조작감은 검증 전이다.

## 적용 경계

E04~08은 이 프로젝트 로컬 코드의 확인 결과다. 실제 Unity 폴더와 동기화된 최신 코드라고 보장하지 않는다. 구현 착수 시 두 폴더 차이와 대상 버전을 확인해야 한다. 원작 고정 진형 근거는 없으므로 MP03~09를 The Spell Brigade에서 가져온 검증된 시스템이라고 부르지 않는다.
