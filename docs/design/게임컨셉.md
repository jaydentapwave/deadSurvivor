# 배낭 원정대 게임 컨셉

상태: 장기 컨셉. 현재 실행 프로젝트 이름은 데드 서바이버이며 이름 변경은 아직 적용하지 않았다.

## 중심 경험

소원의 샘을 찾아 떠나는 여행자들이 함께 이동하며 몰려오는 몬스터를 뚫고, 가방 속 장비 배치로 성장한다. 자동 공격 생존 전투와 백팩 분배를 결합한다. 각자 소박한 소원을 가진 동료와 같은 목적지로 향하는 따뜻한 동화풍 모험이다.

전사·궁수·마법사·사제의 역할과 장비 조합이 빌드 방향을 만든다. 최신 프로토타입은 주무기/보조와 장비 기반 직업 구분을 제거하고 여러 무기가 독립적으로 실행된다. 역할 명칭은 장기 컨셉의 표현이다. 기존 컨셉의 출발 직업 선택은 시작 무기 선택의 방향으로 해석하며 이후 장비 교체를 막지 않는다.

## 장기 범위

동료 구출과 야영 대화, 관계 성장, 마을 성장, 장별 지역 및 조명 변화, 소원의 샘까지의 여정은 장기 기획이다. 이번 1스테이지/10웨이브 프로토타입에 구현됐다고 표시하지 않는다. 컨셉의 런 패배 후 가방 상실과 현재 런 중 정비 무료 부활은 다른 시점의 규칙이다.

그래픽 방향은 쿼터뷰 2D 도트와 SD 캐릭터, 낮에서 밤으로 이어지는 조명이다. 기존 추출 PNG는 임시 프로토타입 아트이며 최종 컨셉 아트 구현 완료가 아니다. 원본 문서의 컨셉 이미지는 참고 자료로 보존한다.
