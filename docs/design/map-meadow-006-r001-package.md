# MAP-MEADOW-006 / r001 — 충돌·좌표·통로 정책 설계

2026-10-30 KST. 문서 검토중 / 게임 적용 미구현. [005 등록부](map-meadow-005-r001-package.md)의 후속 설계. 원본·005의 위치를 변경하지 않는다.

## 사전 브리핑

- 규모 L1: 기존 등록 워크플로우에 윤곽 작성·좌표 변환·통로 인수 계약을 추가하는 문서 작업. 런타임 스키마·상태 소유권 변경 없음. 실제 구현은 별도 재분류한다.
- 요구/제외: 제작 전 설계 계속. 충돌 후보의 작성 기준, 이미지→게임 좌표 대응, RT별 필수 조건을 결정안으로 만든다. 실제 충돌 도형·Unity·게임·하네스 구현 제외.
- 관련 기획: [03](3D배경-VerdantMeadows-구조분석-03.md)의 공간 특징, [04](3D배경-우리맵-적용설계-04.md)의 적용 제안, [005](map-meadow-005-r001-register.md)의 OB/RT/P01 참조. 사용자 요구와 이번 에이전트 제안을 구분한다.
- 기존 소유처: DSGame의 논리 좌표·진형·이동·공격 규칙은 그대로 둔다. 원본 PNG와005 CSV는 읽기만 한다. 이번 CSV는 작성 지시서이며 게임이 읽는 데이터가 아니다.
- 변경할 파일: 본 묶음·설계 결정안·객체별 윤곽 작성표·통로 정책표·변환 검산 벡터·검토 기록과 기존 입구 연결. 전부 미정이던 항목에서 작성 방법과 적용 조건을 명시한다.
- 재사용/신설: 기존 OB/RT/MC, D01~06을 유지. 단위 혼동과 bbox의 충돌 승격을 막기 위해 별도 규칙을 작성한다.
- 실패/취소/생사/전환: 윤곽·크기 미확정이면 실행 준비 BLOCKED, 실제 시험 NOT_RUN. 죽은 슬롯·부활·예정 진형과 동적 추종을 포함한 판정 요구를 유지한다.
- 호환성과 복구: 005 입력·372계획 행을 덮어쓰지 않는다. 006은 정책 해석을 추가하며, 사례 재편성은 새 개정으로 수행한다. 기존 게임의 축/속도/피격반경을 변경하지 않는다.
- 검증 계획: 원본/등록부 대조→전 항목 정책 배정→수학적 불변식/검산 예시 확인→local→algorithm-tester 및 validator-client 독립 검토. 계산 검산을 게임 검증으로 확대하지 않는다.
- 미정: 실제 충돌 점, 월드 스케일 s/k, 몸체 반경·동적 여유·임계값·카메라. 이번에 값을 추정 확정하지 않는다.
- 검토 결과: [기록](../reviews/map-meadow-006-r001-review.md).
