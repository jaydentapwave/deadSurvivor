## 4. 실행을 막는 결정과 구현 순서

1. **B01 자료 채택**: 64개 C 후보·외곽·U 처리와 좌표 변환을 ‘우리 시험 지형’ 개정으로 명시한다. s4/55도/ortho6/반경8은 개발 기본값이며 최종 채택으로 올리지 않는다.
2. **B02 사례 기준**: 각 초기 실제/예약 위치, 입력열·dt·도착 영역·정지/정체·시간 한계·화면 조건을 실행 전에 고정한다. 진단에서 관측한 값을 같은 실행 합격 기준으로 소급 사용하지 않는다.
3. **B03 실행 통합**: full map v1 자료 어댑터, 상태 명령 큐/관찰, 사례 분할과 누락 없는 상위 집계, 외부 감시/복구 계약의 L2 브리핑을 작성한다. design-reviewer 검토 뒤 메인이 구현한다. 기존 fixture의 scope를 이름만 바꾸지 않는다.
4. **B04 기대 결과**: 통과 필수/의도적 차단/진단을 구분하고 MC/RF/OB/RT를 연결한다. 후보 경로가 막히면 자료·로직·실행기 문제를 분류하고 CH/새 개정으로 남긴다.
5. 정상 대조와 FI를 검증한 유효 G2 증거 후 전체 사례를 실행한다. N1 완료는 원본 G3 필수 목록 전부와 유효 G2이며, 708건 재고 작성이나 대표 경로 PASS로 대체하지 않는다.

## 5. 변경·결과 경계

CH-025-01: 새 준비 문서/경로 조합 재고를 추가하고 상태 진입점을 연결했다. 구조·충돌·표현·원본 도면 변경은 없다. 따라서 새 도면 네 판은 생성하지 않으며 준비/문제 표시는 기존 007 원본을 참조한다. 실제 실행 후 동일 배치의 시험/문제판을 별도 개정으로 만든다.

입력 지문·작성 시각은 JSON에 보존한다. 재고 입력 변경 시 이전 결과로 실행 동결을 주장하지 않는다. N2 대상 환경·성능 기준과 N3 미술/유료 생성은 이번 준비 범위 밖이다. 독립 검토와 실제 검사 결과는 [025 기록](../reviews/map-n1-025-review.md)에 남긴다.
