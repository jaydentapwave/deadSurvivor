# EFFICIENCY-013: 검증을 유지하는 실행 효율 개선

2026-10-31 · L2. 사용자 요구는 ① 도구 출력 요약 ② 검증 순서 정리 ③ 단계별 결과 재사용이다. 강제 검사와 독립 검토는 유지한다. 모델/전역 설정·hook/baseline·게임 규칙은 바꾸지 않는다.

## 변경 계약

1. `Tools/Verify/run.py` 기본 stdout은 전체 결과 대신 상태·단계별 상태·실패 건수/첫 원인·보고서 경로를 반환한다. 전체 JSON은 기존 경로와 구조로 계속 저장한다. `--verbose`는 기존 상세 출력을 복원한다. `Tools/Verify/report.py`는 저장된 보고서의 요약과 지정된 실패 항목만 읽는 CLI다. 요약은 상태를 재판정하지 않고 FAIL/BLOCKED/NOT_RUN 및 생략 개수를 드러낸다. 기존 gate가 기대하는 최상위 status/report와 종료 코드를 유지한다.
2. 개발 순서: L2 사전 설계 검토 → 구현·작은 시험 → 독립 코드 검토·수정 → 영향 단계 통합 시험 → 필요한 최종 all --screens → 독립 증거 확인 → 문서/local/gate. 마지막 전체 검사는 변경과 선행 지적을 정리한 뒤 실행한다. 이후 실제 영향 변경/실패가 있으면 관련 검사를 다시 실행한다. 횟수 제한으로 필수 검사를 생략하지 않는다. 명령 순서 자체를 강제하는 새 대형 스케줄러는 만들지 않는다.
3. 자산 job schema2를 추가한다. 원본/spec/산출물의 기존 완전성·해시·계약 재검사는 그대로 유지한다. 처리 결과의 의존성은 `pipeline.py`, `process_blender.py`, 설치된 Blender 실행 파일의 경로/바이트 지문 및 동결 spec이다. Unity 코드와 보고서 표시 코드는 처리 의존성에서 제외한다. Unity 실행마다 `UnityAsset.cs`, `unity_asset.py` 및 공통 판정기/pipeline 지문을 별도로 기록하고 끝에서도 확인한다. Unity 실행/검증 결과를 자동 재사용하지 않는다.
4. `init --reuse-from <job>`은 원본 job을 읽기 전용으로 확인하고 새 job에 원본/처리본을 검증 복사한다. 원본 출처/역할/파일 지문이 맞으면 raw를 재사용한다. spec·처리 코드·Blender 지문까지 같고 처리 완료와 모든 파일/계약이 유효해야 처리본을 재사용한다. 처리 의존성만 달라지면 raw만 재사용하고 SOURCE_READY로 남겨 처리 재실행을 요구한다. 손상/누락된 원본 job을 성공 캐시로 덮어쓰거나 조용히 재생성하지 않는다. 신규 job에 원본 job 경로/해시와 재사용 범위를 기록한다. 원본·도구·산출물의 변경 중 복사도 차단한다.
5. schema1 job은 과거 원본/지문을 수정하지 않는다. 기존 strict verify는 기존 전체 도구 지문을 요구한다. 명시적 reuse-from에서 무결성 검증 후 raw만 승계할 수 있고 처리본은 의존성 분리 근거가 없어 새로 처리한다. schema2 이후부터 처리 재사용의 절약 효과를 얻는다.

## 검증과 완료 기준

- 정상/실패 요약·상세 보고서 동일성, 실패 생략 표시·종료 코드·실패 상세 조회를 시험한다.
- 처리 재사용 시 Blender 호출0, Unity/출력 코드 변경 시 처리 재사용, 처리 코드/Blender/spec 변경 시 재처리 필요, 손상/빈 완료/잘못된 schema/복사 도중 변경/잠금은 차단한다. 기존 27개 자산 시험도 유지한다.
- 기존 바위로 schema2 첫 처리 후 새 job에서 실제 파일 재사용·지문 일치·외부 호출0을 검증한다. 추가 생성/공개는 없다.
- 변경된 Verify 실행기 때문에 최종 현재 지문의 기존 게임 `all --screens`를 한 번 실행한다. Unity 실제 자산 가져오기 코드는 의미를 바꾸지 않으며 이번 캐시 시험 자체를 새 Unity 자산 승인으로 보고하지 않는다.
- 독립 validator가 코드와 실제 증거를 확인한다. 변경 문서 링크/local 및 최종 gate PASS. 토큰 절감률은 측정하지 않았으므로 stdout 바이트 감소와 실제 처리 호출 수만 보고한다.
