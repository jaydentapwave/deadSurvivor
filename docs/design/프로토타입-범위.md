# 프로토타입 범위와 규칙 우선순위

## 유지할 핵심 루프

최대 4명 선발 → 자동 공격과 스쿼드 이동 → 웨이브 종료 → 전리품 분배/장비 정비 → 10웨이브 승리 또는 전멸 패배. 모바일 가로 화면과 터치 드래그/조이스틱을 지원한다.

## 이전 문서와 최신 결정

| 항목 | 이전 v0.3 | 현재 구현 기준 / 변경 목표 |
|---|---|---|
| 웨이브 | 최대 1분 | 총435초 구현, 정비 제한 없음 |
| 직업 | 캐릭터 역할 | 주무기 기반 직업 제거, 모든 장착 무기가 독립 발동 |
| 장비 | 생활 무기 등 | 32종 판타지 장비 데이터 구현 |
| 인벤토리 | 확장 기반 이전 설계 | 고정 4×4, 확장 키트 제외는 기존 구현 완료 |
| 부활 | 유료/광고 부활 제외 | 정비 중 무료 부활 유지, 사망 장비 잠금 |
| 아트/메타 | 최종 아트/메타 제외 | 컨셉 방향은 별도 보존, 이번 기능 개발과 구분 |

현재 코드 사실과 목표 기획은 혼합하지 않는다. 자동 검사 통과는 밸런스/재미 검증을 의미하지 않는다. 실제 플레이 시간, 진형의 체감 차이, 최종 아트 적합성은 별도 플레이테스트 결과가 필요하다.

## 추가 기획: 종료 보상과 캐릭터 성장

경험치·공용 골드 및 아웃게임 캐릭터 성장은 [후속 기획](종료보상과-캐릭터성장.md)으로 추가했다. 기존 표의 메타 제외는 현재 구현 범위를 뜻하며, 이 추가 기획을 취소하는 의미가 아니다. 수치 확정과 기능 구현은 미완료다.
