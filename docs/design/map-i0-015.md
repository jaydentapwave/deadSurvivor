## I0 편집 상태 정리 계약

사용자가 미저장 변경을 확인하고 저장했다고 응답했다. 이 응답과 I0 진행 요청을 근거로 현재 확인한 내용의 **Unity 원래 Save Project 기능을 통한 정상 저장**을 진행할 수 있다. 사용자에게 같은 저장 확인을 반복 요청하지 않는다. 초기 BLOCKED 이력은 보존한다.

1. 동일 PID/프로젝트·재생 정지·씬 clean·선택 상태와 Assets/ProjectSettings dirty 객체를 재조회한다. 사용자 확인 이후 새로운 미확인 객체/씬 변경이 생기면 보존하고 BLOCKED다. Shader 컴파일 플래그는 별도 기록한다. 타입/이름이나 디스크 지문만으로 변경 소유를 추정하지 않는다.
2. 저장 전 Assets/DeadSurvivor·Assets/TextMesh Pro·ProjectSettings·Packages의 바이트/해시·편집 상태를 백업한다. 메모리 JSON은 진단 관측이며 검증된 복원본으로 취급하지 않는다. 실제 파일이 만들어지지 않은 SaveToSerializedFileAndForget 시도는 실패 이력으로 보존하고 백업 성공으로 보고하지 않는다.
3. Unity의 File/Save Project를 실행하고 호출 성공·dirty 객체·씬/프로젝트 상태·파일 차이를 재조회한다. 저장 후 파일도 별도로 보존하며 사용자 확인 이전 해시로 자동 복원하지 않는다. **저장 실패·새로운 미확인 객체 또는 편집 가능한 미저장 변경이 남으면 종료/재시작은 BLOCKED**다. 사용자 확인을 dirty 검사 생략 근거로 쓰지 않는다.
4. 저장 후 상태가 깨끗하고 나머지 전제도 만족하면, 재시작이 필요하지 않을 경우 현재 세션을 유지한다. 정상 재시작이 필요한 경우에만 강제 종료/임의 ClearDirty 없이 같은 개인 프로젝트를 종료/재열기한다. 종료 후 예상 밖 파일 차이는 자동 덮어쓰지 않고 현재/백업을 모두 보존한다.
5. 재시작 시 원래 씬/선택/background/tick(현재/세션 저장값)을 복구한다. 이미 같은 값은 불필요하게 다시 대입하지 않는다. 새 PID는 따로 기록한다. 충돌하는 사용자 상태가 있으면 보존하고 중단한다.
6. 편집 가능한 dirty Assets/ProjectSettings0·정지·씬/선택/background/tick과 패키지·양쪽 코드 비교를 확인해야 쓰기 전제 PASS다. 현재 두 고정 경로의 `.ttf` Font Texture는 **NotEditable·subAsset·mainType Font·dynamic Font·실제 Font.material.mainTexture 소유 참조·원본 바이트 불변**을 모두 재확인한 경우에만 현재 세션의 파생 캐시로 분류한다. raw dirty 기록2개는 남기고, 속성/소유 참조/원본이 바뀌거나 다른 객체가 생기면 제외하지 않는다. 삭제/ClearDirty/재시작/재생성 시험은 수행하지 않는다. 저장으로 런타임 지문이 바뀌면 기존 all을 현재 증거로 사용하지 않고 필요한 최종 회귀를 새로 수행한다. 이 절차 자체는 맵 동작 검증이 아니다.

### 사용자 저장 확인 후 재검사

사용자 저장 완료 응답 후에도 raw dirty 표시는4개였다. 원본327파일과 저장 전후를 보존하고 File/Save Project를 정상 실행하여 PlayerSettings와PrototypeFont.asset의 미저장 변경을 저장했다. 변경 파일은PrototypeFont.asset1개이며 이전 해시로 되돌리지 않았다. 현재 남은 Font Texture2개는 위 전제에 따라 파생 캐시로 독립 검토받았고 편집 가능한 dirty는0이다. 저장/속성 원자료는 `output/map-i0-015/resume-saved/`에 보존한다. 원래 세션에서 새 전체 회귀를 통과했다. 검사 후 전체 저장으로 추가된 글리프 캐시 변경은 별도 보존하고 사용자 저장 직후 체크포인트 한 파일로 복구·동기 재임포트했다. 그 결과 전체 런타임 지문이 새 all의 gate_after와 정확히 일치하고 편집 가능한 dirty는0이다. 이 복구는 독립 설계 검토를 거쳤으며 저장 확인 전 파일로 되돌리거나 baseline을 갱신하지 않았다. 초기 BLOCKED/실패한 진단 시도도 보존한다.
