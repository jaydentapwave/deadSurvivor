# 046 — 전체 맵 구축

- 상태: **전체 맵 장면 생성, 짧은 Play PASS, 사용자 직접 플레이 대기.** 빌드 첫 장면은 바꾸지 않았다(`Proto044_Main` 유지).
- 장면: `Assets/DeadSurvivor/Scenes/Map046/Map046_Full.unity`
- 사용자 요청(2026-11-02): "전체 맵을 구축하는걸 원하는데, 지금 뭔가 계속해서 검증이랑 이상한 테스트?를 하는느낌", "1-5번까지하는데 구역 하나씩 만들지말고 전체 맵을 래퍼런스 기준으로 만들어줘".
- 진행 방식: 배치 설계 → 맵 데이터 고정 검사 해제 → 전체 맵 자산 배치 → 게임 연결(적 생성) → 사용자 확인. 검증은 컴파일, 짧은 Play, 사용자 직접 플레이만 했다. 독립 검토와 전체 Play는 하지 않았다.
