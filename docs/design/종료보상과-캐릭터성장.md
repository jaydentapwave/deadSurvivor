# 6. 게임 종료 보상과 캐릭터 성장

추가 기획: 한 판 종료 후 편성 캐릭터의 경험치와 공용 골드를 지급하고, 아웃게임에서 캐릭터를 성장시킨다. 본 장은 개발할 방향과 첫 구현 기준안이며 현재 구현 완료 기능이 아니다. 지급량과 성장 수치는 별도로 확정한다.

## 6.1 종료 보상

### 성장 루프

한 판 종료 → 편성 캐릭터 경험치 및 공용 골드 획득 → 아웃게임에서 레벨과 능력치 확인 및 골드 강화 → 성장한 원정대로 재도전.

| 보상 | 지급 기준 |
| --- | --- |
| 캐릭터 경험치 | 해당 판에 편성한 최대 4명에게 각각 지급한다. 1~3명 편성 시에도 실제 편성한 캐릭터가 대상이다. |
| 공용 골드 | 플레이어 공용 재화로 지급하며, 아웃게임의 캐릭터 강화에 사용한다. |
| 승리 | 진행 보상에 클리어 보너스를 추가한다. |
| 패배 | 완료한 웨이브까지의 진행도에 따라 보상한다. 구체적인 지급량은 미정이다. |

### 경험치 배분과 결과 화면

편성 캐릭터는 전투 중 사망했더라도 동일한 기본 경험치를 받는 것을 첫 구현 기준으로 한다. 처치량이나 피해량으로 경험치를 나누지 않아 회복 역할과 낮은 레벨 캐릭터도 성장할 수 있게 한다.

결과 화면에는 획득 골드와 캐릭터별 획득 경험치, 경험치 진행도, 레벨 상승 여부를 표시한다. 웨이브 사이에 지급하는 인벤토리 아이템 보상과 한 판 종료 후의 경험치·골드 보상은 별도로 운영한다.

## 6.2 기본 능력치

캐릭터의 기본 능력치는 최대 HP·공격력·방어력·회복력 4종으로 구성한다. 현재 최대 HP·공격 배수·방어율 중심의 규칙을 바탕으로 성장용 능력치 체계를 설계한다.

| 능력치 | 역할과 적용 범위 |
| --- | --- |
| 최대 HP | 버틸 수 있는 피해량의 기반이다. 전방 캐릭터의 생존력을 높인다. |
| 공격력 | 장착한 공격 무기의 피해를 높인다. 근접·원거리·마법 공격 모두에 적용한다. |
| 방어력 | 받는 피해를 줄인다. 방어력 수치를 피해 감소율로 환산한다. |
| 회복력 | 회복 아이템으로 주는 회복량을 높인다. 우선 직접 회복 아이템에 적용한다. |

### 장착 아이템에 적용

성장한 능력치는 장착한 모든 아이템 중 해당 능력치를 사용하는 아이템에 적용한다. 공격력은 모든 공격 무기에, 회복력은 직접 회복 아이템에 적용한다. 각 무기의 독립 쿨타임과 병렬 발동은 유지한다.

지속 회복과 공유 회복에 회복력을 적용할지는 별도로 정한다. 직접 회복량에 성장 능력치를 반영하는 구체적인 계산식도 미정이다.

### 방어력 계산

레벨마다 방어율을 일정하게 더하는 대신, 방어력 수치를 피해 감소율로 환산한다. 방어력이 높아질수록 추가 투자 효율이 완만해지는 방식을 첫 구현 기준으로 한다. 성장 후 피해를 거의 받지 않는 상태를 방지하기 위한 방향이다.

환산식·계수·피해 감소 상한과 현재 장비 방어 효과의 결합 방식은 미정이다. 기존 전투 규칙의 방어율 상한 80%를 새 성장 체계의 확정 수치로 자동 승계하지 않는다.

### 장비 효과와 공통 능력치

공격 속도·치명타·사거리 등은 기본 성장 능력치에 넣지 않고 장비의 추가 효과로 두는 방향이다. 가방 배치와 장비 조합의 선택 가치를 유지한다. 치명타의 실제 도입과 수치는 후속 설계 대상이다.

이동 속도는 원정대가 함께 움직이는 구조에 맞춰 공통값으로 유지한다. 캐릭터별 이동 속도 성장은 첫 구현 범위에 넣지 않는다.

## 6.3 아웃게임 성장

### 레벨업과 골드 강화

캐릭터별 경험치를 누적하여 레벨을 올린다. 레벨업 시 네 기본 능력치가 캐릭터별 성장 비율에 따라 자동 상승한다. 아웃게임에서는 캐릭터의 레벨·경험치·현재 능력치와 성장 결과를 확인한다.

골드는 레벨업과 별도로 캐릭터의 추가 강화에 투자한다. 초기에는 능력치별 구매 항목을 여러 개 두기보다 캐릭터 단위 강화로 운영하여 선택 부담을 줄인다. 강화가 올리는 능력치의 조합과 비용은 별도 확정한다.

### 캐릭터별 성장 특징

| 성장 성향 | 우선 성장 능력치 |
| --- | --- |
| 전방형 | 최대 HP와 방어력이 더 크게 성장한다. |
| 공격형 | 공격력이 더 크게 성장한다. |
| 지원형 | 회복력이 더 크게 성장한다. |

성장 성향은 캐릭터의 특징을 만드는 기준이며 장비 착용 제한을 뜻하지 않는다. 실제 6명 캐릭터의 성장 성향 배정과 능력치별 증가량은 후속 밸런스 설계에서 정한다.

## 6.4 미정 수치와 후속 설계

| 항목 | 확정할 내용 |
| --- | --- |
| 종료 보상 | 웨이브별 경험치·골드, 클리어 보너스, 첫 웨이브 미완료 시 보상 기준 |
| 캐릭터 레벨 | 레벨 상한, 레벨별 필요 경험치, 캐릭터별 기본 수치와 레벨 상승량 |
| 골드 강화 | 강화 단계·상한·비용·능력치 상승량과 레벨업 성장의 결합 방식 |
| 전투 반영 | 공격력·회복력 계산식, 방어력 환산식·상한, 장비 보너스와의 결합 |
| 회복 적용 | 지속 회복·공유 회복의 회복력 적용 여부와 중복 증폭 방지 규칙 |

추가 기획의 수치 확정과 기능 구현·저장은 후속 개발 범위다. 본 문서 추가만으로 종료 보상 지급이나 영구 성장이 게임에 적용된 것으로 보지 않는다.
