- 프로젝트: 개인 Git `main`, 사용자 지정 원격 [deadSurvivor](https://github.com/jaydentapwave/deadSurvivor). 공개 저장소로의 이번 커밋·업로드는 사용자 명시 요청 범위다. 외부 문서/회사 서비스 연동 없음.

최신 [추가 몬스터 감소 검증](reviews/추가-몬스터감소-20261029.md)은 695회 규칙과 실제 입력·프레임·콘솔·정리, 3개 화면 비율24화면 검사 PASS다. 최신 일반16:9·최대 장착4:3 전투 화면을 직접 시각 확인했다. 이전 18회 반복 재현 및96쌍192회 장비 비교는 몬스터 수 감소 전 기록으로 구분한다.

[자동 비교 결과](reviews/장비-자동비교-20261029.md)는 이전 보상 수량 정책의 초기 장비·고정 이동·추가 보상 미장착 조건이다. 새 수량 정책의 밸런스 실험으로 재사용하지 않는다. 이를 최종 밸런스나 인간 클리어율로 해석하지 않는다. [할일](../할일.md)에 사람 플레이·물리 기기·최종 아트를 미완료로 유지한다. Git 작성자는 연결된 `jaydentapwave` 계정과 GitHub noreply 이메일로 이 프로젝트에만 설정했다. 현재 Editor에는 Mac 빌드 모듈만 설치되어 있다.

최신 입력 수정: [인벤토리 꺼내기](reviews/인벤토리-꺼내기-20261029.md). 합성 불가능한 전리품 위에도 장착 장비를 해제하도록 보완. 컴파일·695규칙·탭/드래그 입력 PASS.
