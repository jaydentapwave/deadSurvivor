# 첫 맵 자산 목록 조사·문서 검증

2026-11-01 · L0 · [제작 준비안](../art/environment-preproduction/first-map-asset-inventory.md).

사용자 명시 요청으로 /root/asset_inventory_planner를 GPT-6.1 Sol / medium 설정으로 호출했다. 서브에이전트는 읽기 전용으로 조사·원고를 제출했고 메인이 입력 지문과 주요 객체 관계를 대조해 문서를 저장했다. 새 작업 절차·검사 의무·런타임·데이터 schema를 도입하지 않았다.

## 결과

- 환경 표현 9개 기능 묶음과 제작 방법·우선순위·미정을 정리했다. 신규 모델 9개나 발주 확정 목록이 아니다.
- 64개 군집과 재사용 모듈, 4개 외곽 조사 영역·비충돌 부모의 차이를 명시했다.
- 첫 Tripo 후보는 낮은 직선 돌벽 1개 제안이며 곡선 잔해·전맵 구조를 대체하지 않는다.
- 기존 바위·028/r004 비교 기준을 유지하고 큰 나무·상호작용·신규 랜드마크 등은 보류했다.
- 계정·모델·비용·예산·공개 허용 조건은 미확인으로 유지한다. 생성·업로드·Unity 조작·커밋/게시를 하지 않았다.

## 검증과 보존

원본·028 화면·007 layout의 SHA-256은 제작 준비안에 기록했다. 메인이 재대조했으며 실제 시각 관찰은 서브에이전트의 조사 근거다. 기존 파일을 수정하지 않고 준비안과 이 리뷰만 추가한다.

| 검사 | 상태/근거 | 한계 |
|---|---|---|
| 로컬 근거·주요 OB/RF/RT·입력 지문 | PASS | 원작 충돌·정밀 치수나 새 자산 채택 검증 아님 |
| 계획 작성 | 완료 | GPT-6.1 Sol medium 서브에이전트 결과를 메인이 정리. 별도 L1/L2 validator 검토로 표시하지 않음 |
| local / 최종 gate | [마감 기록](../../output/first-map-asset-inventory-20261101/final-checks.json)의 실제 상태 참조 | 문서 저장 후 실행 시각·원자료·지문 기록 |
| Tripo 생성·다운로드·Unity·빌드·성능 | NOT_RUN | 이번은 조사·계획 범위 |

시작 지문과 새 문서 지문, local/gate 결과는 위 마감 JSON에 연결한다. 문서 PASS는 실제 게임/자산 PASS가 아니다. gate가 기존 회귀 증거를 현재 의존 지문으로 인수하더라도 이번 새 Unity 실행으로 보고하지 않는다.
