## 후속

- 구현 검토 후속에서 반영한 것: 예산이 나열한 자산만 그 승인을 쓴다(`budgets.*.assets`, 새 에셋은 새 예산), `stone045` 설명 정정(맵 빌더가 시험 폴더에서 읽어 메시로 굽는다 → `Art/Environment/Props`로 옮기기 후속), 바닥 원 그림자는 다시 만드는 도구가 없음을 문서화, `ai-3d-assets.md`의 승인 원문 위치.
- 구현 검토 후속(남음): 검사가 `Assets/DeadSurvivor` 밖 재질·`Art/` 밖 텍스처는 보지 않음, 카탈로그에서 자산을 지우면 그 지출이 상한 합계에서 빠짐, 맵 전체 `Build()`를 다시 돌린 뒤에는 `check`를 다시 실행.
- 사용자 화면 확인: 캐릭터가 공용 셰이더로 바뀐 모습(게임 안, 밤 화면 포함). 색이 원본과 거의 같으므로 차이는 주로 음영(감싸는 확산광·테두리 빛 0.2)이다.
- 새 에셋 1종을 `gen`부터 끝까지 실제로 만들어 시간·크레딧 기록(크레딧 승인 필요). 이번에는 기존 원본으로 `prep → unity → check`만 끝까지 검증했다.
- 7웨이브 렌더 시간 차이의 원인 분리(같은 조건 교대 측정 여러 번 또는 Frame Debugger). 부하 set-pass 초과(049 후속)와 함께 본다.
- 실기기에서 ASTC 텍스처 확인.
- 커밋 전 gate는 파일 추가·삭제가 있어 `all --screens`가 필요하다(설계 검토 후속 7).
