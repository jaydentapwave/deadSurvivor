## 독립 검토와 실패 수정

설계/로직/구현 독립 서브에이전트가 관련 로컬 파일을 읽기 전용으로 검토했다. 실험 설계F1~F3, 특수 개수 비교, 로딩 시작/종료, 미리보기 전체 상태 보존, 무기 없음 전환 수치, 진형 검사 범위, 기존18종 대응표 지적을 반영했다. 최신 장비/해제/보관함 합성 정적 재검토 PASS. 최종 독립 문서 검토에서 이전18종 원본의 바이트/지문 일치, 원문137행 문구/번호 일치, 최신 런타임 지문과 증거 범위의 일치를 확인했다. 실행 결과는 위 실제 보고서와 구분한다.

초기 다중 해상도 검사는 GameView 선택 인덱스만 바꾸어 실제 렌더 크기가 달라 FAIL했다. Unity의 크기 선택 경로로 변경하고 실제RT·Canvas를 확인하도록 수정했다. 임시 크기 삭제의 전체 인덱스와 DeviceSimulator 복구를 수정했으며 원래 선택/목록·주요뷰·포커스·Simulator상태를 복구한다. 이후 화면 검사 및cleanup PASS. 과거 실패를 성공으로 덮어쓰지 않고 실행별 output에 보존했다.

## 남은 범위
