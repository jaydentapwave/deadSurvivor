# 구현 전 요구사항 대조표

이 표는 병렬 실행 이전 요구의 이행 기록이다. 후속 사용자 요청으로 주무기/보조 구분, 자동 교체, 주무기 없는 출발 차단, 장비 기반 직업/사제 조건은 폐기됐다. 최신 상태는 [병렬 실행 검증](병렬-아이템-20261029.md)과 [현재 규칙](../design/장비규칙.md)을 따른다.

[구현 전 원문](../sources/할일-구현전-20261029.md)의 체크 항목을 행 번호로 연결한다. 원문은 수정하지 않았다. `구현·대표검사`는 관련 코드와 대표 경계/입력 검사가 있다는 뜻이며 모든 조합의 완전 검증을 뜻하지 않는다. 검사 근거는 [후속 검증](후속개선-20261029.md), 수치 분석은 [자동 비교](장비-자동비교-20261029.md)다.

코드 약칭: R=EquipmentRules, G=DSGame 역할별 파일, U=DSUI/DSUI.Equipment, F=DSGame.Formation/DSUI.Formation, V=DSVerification/InteractionCheck, S=DSScreenVerification, E=DSExperiments. 실제 위치는 [코드 구조](../구조.md)를 따른다.
