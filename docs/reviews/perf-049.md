# 049 성능 — 모바일 기준 측정, 몬스터 바닥 그림자, 인스턴싱 시험

- 사용자 요청(2026-11-03 11시대): "이것도 워크플로우에 녹여줄수있도록해줘, 그리고 1-4번까지 작업을 진행해줘". 1 모바일 기준 재측정, 2 몬스터 그림자 끄고 바닥 원형 그림자, 3 인스턴싱, 4 필요하면 Blender로 삼각형 감량.
- 워크플로우: [성능 예산과 최적화 절차](../workflows/performance.md)(새 문서).
- 장면: `Map046_Full`. 측정 도구: `Tools/Harness/play_probe.py --mobile`(모바일 렌더 설정, 20초 중앙값).

## 결과

| 단계 | 결과 |
|---|---|
| 1 모바일 기준 측정 | `play_probe`에 `--mobile`(측정 중 `Mobile_RPAsset`), `--count-scale`(적 수 배율), `--assets`(자산 구성 출력) 추가. PC 설정 값(7웨이브 401)은 그림자 단계 4개 때문에 부풀려진 값이었고 모바일 기준은 167이다 |
| 2 바닥 원형 그림자 | **채택.** 몬스터는 실제 그림자를 그리지 않고 발밑에 부드러운 원(검정, 불투명도 0.42, 몬스터 높이의 1.15배)을 깐다. 렌더 시간 7웨이브 3.95 → 2.49ms, 부하 12.9 → 9.2ms |
| 3 인스턴싱 | **시험 후 끔.** 그리기 호출은 크게 줄었지만(부하 628 → 239) 렌더 시간이 늘었다(9.2 → 12.1ms). 옵션(`MonsterInstanced`)은 남기고 꺼 둠. 시험 때 켰던 공용 재질 6개의 인스턴싱 설정은 되돌림 |
| 4 Blender 감량 | **필요 없음.** 바닥 그림자 뒤 적 1마리당 삼각형 약 350개(예산 1,000), 부하에서도 23.5만(적 약 550) |
