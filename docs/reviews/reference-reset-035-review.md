## 원본과 선정 범위

원본은1195×1110 PNG, SHA-256 84bb8b2502061af81a620b18f158479d963eed7070e1779c97f4dc059b5da5e9다. 출처는 [03 원본 기록](../design/3D배경-VerdantMeadows-구조분석-03.md)이며 이번 작업에서 별도 웹 검색/다운로드는 하지 않았다.

선정 범위는 왼쪽 위 내부의 x100..520/y100..360이다. 큰 둥근 잔해1개, 굽은 잔해3개, 작은 둥근 잔해2개, 하부 가로 자갈길과 왼쪽 마른 흙 흐름을 함께 볼 수 있다. 기존028 구역보다 좌우 범위를 넓혔다.

비교 보기의 왼쪽은 원본 PNG의 해당 좌표를 SVG viewport로 표시한다. AI로 재그린 원본이나 보정된 색상이 아니다. 오른쪽은1593×987의 생성 시안이다. 전체 원본에는 선택 사각형을 별도 겹쳐 표시하며 원본 파일 자체는 수정하지 않았다. 기존 Unity 캡처는 카메라55도/다른 화면 범위라 미술 형태의 정성 비교용으로만 별도 표시한다.

## 생성·수정과 독립 검토

native image_gen을 사용했다. 첫 생성에는 원본 전체 이미지 한 장을 직접 입력하고 선택 범위를 지정했다. r001은 녹색 상부/석재림 방향은 개선됐지만 선택 범위 밖의 상단·좌측 외곽 벽을 추가했고 군집을 작게 배치해 미술 기준 최종 후보에서 제외했다.

두 번째 호출은 원본을 배치 기준, 첫 시안을 재질/표현 참고로 역할을 분리해 입력했다. 외곽 벽 제거와 각 군집의 중심·폭·높이·곡률 및 길 위치를 보정했다. 위치/폭 수치는 프롬프트용 시각 근사이며 원본 실측이나 구현 계약값이 아니다.

GPT-6.1 Sol high 독립 검토자가 원본, 기존 Unity 화면, r001/r002를 직접 확인했다. **현재 범위의 핵심 형태·재질 기준 후보 PASS**, 필수 재생성 지적 없음. r002의 외곽 벽 오삽입과 과도한 군집 축소는 해소됐으며, 일부 하부 군집/길의 상향 편차와 식생 밀도 차이를 남겼다.

**정밀 배치 일치는 미달**이다. 생성 그림에서 좌표·C·치수·경로를 다시 추출하지 않고 기존 layout/원본 관찰을 유지한다. 녹색 내부를 빈 방/구멍/통과 가능한 지면으로 확정하지 않는다. 실제3D 단면·높이·충돌과 사용자 최종 미술 채택은 후속이다.

## 다음 제작에 적용할 순서

1. 원본과 연결되는 지면·마른 흙·연속 자갈길 표현을 먼저 준비한다.
2. 녹색 상부/얇은 석재림이 있는 둥근 잔해와 곡선 잔해의 단면을 정한다. 기존 회색 돌줄의 크기·두께·비율을 자동 승계하지 않는다.
3. 원본 배치 데이터를 유지한 대표 구역에 적용하고 같은 영역/카메라로 다시 비교한다.
4. 추가 3D 생성이 필요한 품목만 개별 입력 이미지·단면·크기·비용 범위를 확정해 진행한다. 현재 시안 전체를 Tripo에 넣어 한 덩어리 맵으로 만들지 않는다.

현재 결과는 원본에 다시 맞춘 **기준 이미지 후보와 비교 자료**다. 사용자 최종 채택이나 새 Unity 구현 완료로 표시하지 않는다.
