# 원본과 결과가 달라진 이유 — 2026-11-02

사용자 요청에 따라 다음 제작을 시작하기 전에 기록한다. 원본과 [035 직접 비교](reference-reset-035-review.md), [028 미술 시험](map-art-028-review.md), [첫 돌벽 생성](env-s01-first-generation-20261101.md)에 근거한다.

## 무엇이 잘못됐나

1. **제작 입력이 원본에서 멀어졌다.** 원본 Verdant Meadows에는 넓은 녹색 상부와 얇고 불규칙한 회색 외곽이 보이는데, 028에서는 내부를 큰 회색 다면체로 채웠다. 이후 ENV-S01에는 이 단순화된 Unity 화면을 입력해 잘못된 해석을 다시 강화했다. Tripo 자체의 생성 능력을 원인으로 단정할 근거는 없다.
2. **보이는 면적보다 단일 소품을 먼저 다듬었다.** 화면 대부분을 차지하는 풀밭·베이지 흙·연속 자갈길 표현을 충분히 준비하지 않은 상태에서 돌벽 하나의 제작과 배치에 집중했다. 자산 하나가 동작해도 전체 화면의 분위기는 회복되지 않았다.
3. **형태를 너무 일찍 확정했다.** 원본에서 높이와 단면을 확실히 알 수 없는 부분을 큰 돌 덩어리로 구현했다. 그 시험 치수와 회색 돌줄 형태가 다음 제작의 기준처럼 이어졌다. 관찰, 구현 제안, 사용자 채택을 분리했어야 했다.
4. **시각 비교의 조건이 달랐다.** 원본의 위쪽 시점·선정 영역과 Unity의 55도 카메라·근접 화면을 같은 조건으로 맞추지 않아 형태·밀도·열린 공간의 차이를 늦게 발견했다.
5. **기능 검증이 미술 판단을 가렸다.** 컴파일·이동·충돌·캐릭터 가림 검사에는 가치가 있지만, 통과가 원본의 형태와 분위기까지 충족했다는 뜻은 아니다. 문서상 미완료 표시만으로는 부족했고 실제 원본을 옆에 둔 시각 판정을 더 일찍 했어야 했다.

## 다음 작업에 바로 적용하는 약속

- 매 제작의 입력에 실제 원본 경로와 선정 범위를 연결한다. 생성 시안은 스타일 참고이며 배치 좌표의 원본이 아니다.
- 지면·흙·자갈길을 먼저 구현하고 원본의 여섯 잔해 실루엣을 같은 영역에서 비교한다. 기존 배치/충돌 데이터는 유지한다.
- 위에서 본 동일 영역 비교와 실제 게임 카메라 화면을 함께 남긴다. 원본의 높이·조명·정밀 실측이 미정인 부분은 명시한다.
- 이전 028/ENV-S01은 기능 시험·실패 비교 기록으로 보존한다. 새 자산의 형태나 재질 입력으로 되돌려 쓰지 않는다.
- 검사는 이번 변경에 필요한 컴파일·프레임/입력·화면·복구와 독립 시각 검토에 집중한다. 지면 변경 때문에 전체 경로 조합이나 새 검증 도구를 추가하지 않는다.
- 기능 PASS, 시각 기준 후보 PASS, 사용자 채택을 따로 기록한다. 새 Unity 화면을 직접 보여주고 남은 차이를 적는다.

이번 원인은 도구를 적게 썼기 때문이 아니라 **잘못된 기준으로 제작을 이어가고 핵심 화면 비교를 늦게 한 것**이다. 메인이 제작 입력과 검토 순서를 바로잡는다.
