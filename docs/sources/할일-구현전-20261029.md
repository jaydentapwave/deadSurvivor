# 데드 서바이버 할 일

## 장비 기본 효과·직업 일치 추가 효과

업데이트: 2026-10-29 · 상태: 사용자 방향 확정 / 아래 세부 구현 기준안으로 시험 / 구현 예정

이 규칙은 기존의 ‘다른 직업도 장비의 모든 효과를 그대로 사용’하는 후보안보다 우선한다. 전사·궁수·마법사·사제 체계와 주무기에 따른 직업 결정은 유지한다. 탱커·서포트 직업을 다시 추가하지 않는다.

| 조건 | 적용 방식 |
|---|---|
| 아이템과 현재 직업 불일치 | 장비의 기본 능력치만 착용자에게 적용 |
| 아이템과 현재 직업 일치 | 기본 능력치에 해당 직업용 추가 효과 적용 |
| 회복 아이템을 일반 직업이 착용 | 착용자 본인에게만 회복 효과 적용 |
| 회복 아이템을 사제가 착용 | 기본 자기 회복에 더해 다른 생존 파티원에게도 회복 효과 공유. 착용자에게 이중 적용하지 않음 |

파티 전체 공유는 현재 파티의 생존자 전체를 대상으로 설계한다. 기존 거리 168 이내 공유 제한을 그대로 계승하지 않는다. 사망자를 회복으로 자동 부활시키지 않으며 정비 중 무료 부활 규칙을 유지한다. 다른 공격·방어 장비까지 자동으로 파티 전체에 공유하는 것은 아니며, 각 직업의 추가 효과로 따로 정의한다.

### 아이템 효과 재설계 예시 — 수치 미정

| 아이템 계열 | 누구나 받는 기본 효과 예시 | 일치 직업의 추가 효과 예시 |
|---|---|---|
| 전사 장비 | 개인 공격력·방어력·체력 | 전사 착용 시 추가 방어 또는 보호 효과 |
| 궁수 장비 | 개인 공격력·공격속도 | 궁수 착용 시 관통·추가 투사체 |
| 마법사 장비 | 개인 공격력·공격속도 | 마법사 착용 시 폭발 반경·연쇄 대상 증가 |
| 사제 회복 장비 | 주기적인 자기 회복 | 사제 착용 시 생존 파티원 전체에 회복 공유 |

위 표는 세부 구현 후보이며, 확정된 것은 기본 효과/직업 추가 효과 구분과 사제의 회복 공유 방향이다. 회복량 증가·회복 주기 단축·회복 사거리만 있던 보조 장비도 다른 직업에게 실제 기본 효과가 있도록 재설계한다.

### 구현할 항목

- [ ] 32종 아이템의 효과를 기본 능력치, 일치 직업, 직업 추가 효과로 나누어 다시 작성한다. 이전 후보 표를 그대로 구현하지 않는다.
- [ ] 아이템 데이터에 기본 효과와 추가 효과의 수치·발동 주기·대상·인접 조건을 별도로 정의한다. 범용 장비가 필요하면 직업 추가 효과가 없는 항목으로 명시한다.
- [ ] 기본 능력치는 장착만으로 적용하고, 인접 조건은 해당 추가 효과에 명시한 경우에만 사용한다. 공통 규칙은 기존 4개 안에서 정리한다.
- [ ] 주무기에서 현재 직업을 먼저 결정한 다음 기본 효과와 직업 추가 효과를 계산한다. 주무기 자체는 장착하면 직업을 결정하므로 보조 장비와 판정 순서를 구분한다.
- [ ] 사제의 회복 공유를 구현하고, 본인에게 기본 회복과 공유 회복이 중복 적용되지 않게 한다.
- [ ] 아래 세부 기준안에 따라 자기 회복과 같은 양을 공유하고, 여러 사제에게서 받는 공유 회복은 최댓값 하나만 적용한다.
- [ ] 주무기 교체·탈착·직업 변경 시 이전 직업 추가 효과와 파티 공유를 즉시 해제·재계산한다.
- [ ] 사망 시 해당 캐릭터가 제공하던 공유 효과를 중단하고 무료 부활 후 정상 복구한다.
- [ ] 아이템 설명을 `기본 효과`와 `직업 추가 효과`로 나누고 현재 추가 효과의 활성 여부를 표시한다.
- [ ] 아이템 선택 시 일치 직업 캐릭터를 우선 강조한다. 불일치 캐릭터에는 `기본 효과만 적용`, 사제에게는 `파티 회복 공유`처럼 차이를 안내한다.

### 검증할 항목

- [ ] 같은 회복 아이템을 전사에게 주면 본인만 회복하고, 사제에게 주면 생존 파티원 전체가 회복한다.
- [ ] 사제 본인이 이중 회복되지 않고, 사망자는 회복 공유로 부활하지 않는다.
- [ ] 불일치 직업도 장착과 기본 능력치 적용은 가능하며 직업 추가 효과만 비활성화된다.
- [ ] 직업을 바꾸거나 장비를 빼면 파티원에게 이전 공유 효과가 남지 않는다.
- [ ] 중복 장비·합성 등급·여러 사제·사망·부활에서 확정된 합산 규칙이 일관되게 적용된다.
- [ ] 실제 효과, 추천 캐릭터 강조, 설명의 활성 표시가 서로 일치한다.

## 장비 세부 규칙과 장착 전후 비교 구현

작성일: 2026-10-29 · 상태: 구현 기준안 / 게임 반영 전

사용자가 요청한 추가 개선 1번(장비 세부 규칙), 3번(장착 전후 비교)을 구체화한다. 아래 수치와 중첩 방식은 첫 프로토타입용 설계 선택이며 밸런스 검증 결과에 따라 조정한다. 기존 32종 후보 표보다 이 절의 적용 규칙을 우선한다.

### 1. 장비 효과 계산 기준

| 항목 | 첫 구현 기준안 |
|---|---|
| 기본 효과 | 장착한 모든 보조 장비의 기본 수치를 착용자에게 적용. 직업·인접 여부와 무관 |
| 직업 추가 효과 | 현재 주무기로 결정된 직업이 장비의 일치 직업과 같을 때 활성화 |
| 인접 조건 | 추가 효과에 인접 조건이 명시된 경우만 검사. 상하좌우 실제 점유 칸 접촉이며 같은 두 장비 간 한 번만 적용 |
| 수치 합산 | 개인 공격·방어·회복 등 같은 능력치는 더한다. 비율 증가도 합산 후 한 번 적용하며 곱연산으로 반복 증폭하지 않음 |
| 동일 특수 효과 | 관통·추가 투사체·연쇄 대상 증가 등 같은 종류의 추가 효과는 가장 큰 값 하나만 적용. 서로 다른 종류는 함께 적용 가능 |
| 방어율 | 캐릭터 기본값·장비·추가 효과를 합한 뒤 최대 80% |
| 공격·회복 속도 | 증가율을 합한 뒤 최대 +100%. 기본 주기를 (1+증가율)로 나누며 최소 주기는 기본의 절반 |
| 회복 한도 | 회복은 최대 체력을 넘지 않으며 넘친 양은 버림. 공유 회복을 다시 공유하는 연쇄 증폭 금지 |
| 보호막 | 같은 대상에 같은 보호막 효과가 재발동하면 더하지 않고 해당 효과의 한도까지 보충. 여러 보호막 효과의 통합 한도는 활성 효과 중 최댓값 |
| 합성 | 같은 아이템·등급 2개를 소비/강화하는 기존 방식 유지. 대상 위치·모양 유지, 전설 이상 합성 불가. 효과 수치는 등급 데이터로 계산 |

아이템 하나에는 기본 효과 1개와 직업 추가 효과 1개를 우선 배정해 설명을 짧게 유지한다. 특수 효과가 맞지 않는 무기에는 기본 효과만 적용하며 `대상 무기 조건 불충족`으로 표시한다. 공격·회복량과 특수 효과의 구체적인 등급 수치는 별도 아이템 데이터 작성 작업으로 남긴다.

### 2. 회복·사제 공유 기준

- 모든 회복 보조 장비의 기본 효과는 착용자의 자기 회복으로 정의한다. 기본 주기는 3초로 통일하고 등급은 회복량을 강화한다.
- 사제가 착용하면 해당 자기 회복량과 같은 양을 다른 생존 파티원 전체에 공유한다. 거리와 인벤토리 인접 조건 없이 적용한다.
- 착용자 자신의 회복은 한 번만 적용한다. 같은 사제가 가진 여러 회복 장비의 회복량은 먼저 합산한다.
- 여러 사제의 공유는 수신자별로 자기 자신을 제외한 제공자 중 초당 회복량이 가장 큰 한 명만 적용한다. 동률은 파티 슬롯 순서로 선택한다. 본인의 자기 회복과 다른 사제 한 명의 공유는 함께 받을 수 있다.
- 공유 주기는 선택된 제공자의 주기를 따른다. 제공자가 바뀌면 수신자의 공유 타이머를 재시작하여 즉시 추가 회복이 발생하지 않게 한다.
- 사제 주무기의 직접 회복은 보조 장비의 공유 원천에 포함하지 않는다. 주무기 자체의 단일/주변 회복 행동은 별도로 실행하며 두 흐름을 설명에서도 구분한다.
- 직업 변경·장비 탈착·제공자 사망 시 공유를 해제한다. 부활 후 정상 재계산하며, 회복으로 사망자를 부활시키지 않는다.
- 정비 중에는 주기 회복·보호막 충전 타이머를 진행하지 않는다. 장비를 갈아 끼우거나 기다려서 무료 회복을 얻지 못하게 한다.

### 3. 주무기 교체·직업 변경 기준

- 캐릭터당 활성 주무기는 1개이다. 주무기 교체 시 현재 직업과 장비 추가 효과를 함께 갱신한다.
- 새 주무기를 유효한 위치에 놓을 때 기존 주무기를 임시로 제외한 상태로 공간을 검사한다. 성공하면 기존 주무기는 중앙 보관함으로 이동하고 새 무기가 장착된다.
- 기존 주무기 위에 놓은 경우 같은 아이템·등급이면 합성을 우선한다. 그렇지 않으면 기존 무기의 시작 칸을 기준으로 교체 배치를 검사한다.
- 다른 생존 캐릭터에게서 주무기를 가져올 수도 있다. 성공하면 원래 캐릭터는 주무기 없음 상태가 되며 해당 캐릭터와 파티 효과도 함께 갱신한다.
- 실패하면 소유자·위치·등급·직업·효과를 모두 원래 상태로 유지한다. 사망자 장비 잠금 규칙은 그대로 적용한다.
- 정비 중 주무기 없는 상태는 허용하되, 살아 있는 캐릭터 중 주무기 없는 사람이 있으면 다음 웨이브 시작을 막고 이름과 빈 주무기 상태를 안내한다.
- 주무기가 없으면 직업 추가 효과는 비활성화되고 보조 장비의 기본 효과만 유지된다.
- 최대 체력 장비를 추가해도 현재 체력은 늘리지 않는다. 해제하여 현재 체력이 새 최대치를 넘으면 새 최대치로 제한한다.

### 4. 장착 전후 비교 표시

상시 능력치 표를 늘리지 않고, 아이템 선택·드래그 중에만 중앙 전리품 영역에 작은 비교 패널을 표시한다. 캐릭터 이름 중심의 기존 화면은 유지한다.

| 상태 | 보여줄 내용 |
|---|---|
| 아이템만 선택 | 기본 효과 / 직업 추가 효과 / 적용 조건, 추천 캐릭터 강조 |
| 대상 캐릭터 지정·인벤토리 위 드래그 | 해당 캐릭터의 현재 값 → 적용 후 값, 추가 효과 활성 여부 |
| 배치 위치까지 지정 | 실제 인접·겹침·교체·합성 판정을 반영한 최종 변화 |
| 주무기 교체 | 현재 직업 → 변경 직업, 기존 무기의 보관함 이동, 얻거나 잃는 추가 효과 |
| 파티 공유 변화 | 파티원별 회복 변화와 공유 제공자 변경. 본인 변화와 분리 |
| 적용 불가 | 실패 원인만 표시하고 가짜 장착 후 수치를 표시하지 않음 |
| 장착 완료·취소 | 비교 패널과 미리보기 정리. 성공 시 장착 아이템만 짧게 강조 |

- [ ] 패널에 실제로 바뀌는 능력치만 표시한다. 기본은 중요한 변화 3개와 `상세 보기`로 구성한다.
- [ ] 공격 피해, 공격 간격(초), 사거리, 방어율, 최대 체력, 회복량/주기, 보호막을 각각 명확한 단위로 표시한다. 서로 다른 무기 간 비교를 검증되지 않은 단일 DPS로 요약하지 않는다.
- [ ] 기본 효과 / 직업 추가 효과 / 인접 조건을 구분하고 `활성`, `직업 불일치`, `인접 필요`, `대상 무기 조건 불충족`, `더 강한 효과 적용 중`을 구별한다.
- [ ] 증가·감소 화살표와 설명을 함께 사용한다. 공격 간격 감소처럼 수치가 줄어도 유리한 경우는 개선으로 표시한다.
- [ ] 사제 공유는 실제 수신자별 변화량을 계산한다. 이미 더 강한 사제의 공유를 받고 있다면 `공유 회복 변화 없음`으로 안내한다.
- [ ] 캐릭터 간 이동은 받는 캐릭터뿐 아니라 원래 캐릭터가 잃는 효과와 파티 공유 변화도 표시한다.
- [ ] 단순 아이템 수치 차이가 아니라 기본 능력치·모든 장비·직업·인접·중첩·상한까지 계산한 결과를 비교한다.
- [ ] 실제 효과 계산과 미리보기 계산을 같은 로직으로 연결한다. 미리보기는 복사한 상태에서 계산하여 실제 체력·아이템·타이머를 변경하지 않는다.
- [ ] 기본 효과 적용 → 주무기 직업 판정 및 추가 효과 → 공유 효과 → 상한 적용 순서를 일관되게 유지한다. 공유량은 외부에서 받은 공유를 제외한 제공자 자신의 장비로 계산한다.
- [ ] 탭으로 아이템과 대상 캐릭터를 선택해도 비교를 볼 수 있게 한다. 인접 위치를 정하지 않았다면 `위치 선택 후 확정`을 표시한다.

### 5. 완료 확인

- [ ] 같은 장비를 일치/불일치 직업에게 장착해 기본 효과는 같고 추가 효과만 달라지는지 확인한다.
- [ ] 사제 0명·1명·2명과 회복 장비 여러 개에서 자기 회복·공유량·중복 제외·제공자 변경을 확인한다.
- [ ] 주무기 교체 전후 파티 전체 효과와 패널 값이 일치하고 실패 시 아무 상태도 바뀌지 않는지 확인한다.
- [ ] 주무기 없는 생존 캐릭터의 출전 방지, 사망자 장비 잠금, 무료 부활 후 상태 갱신을 확인한다.
- [ ] 방어·속도 상한, 특수 효과 최댓값, 보호막 보충, 체력 장비 반복 교체를 검증한다.
- [ ] 인접 배치·회전·합성·캐릭터 간 이동·탈착 각각에서 미리보기 값과 실제 적용 결과를 비교한다.
- [ ] 여러 번 미리보기를 바꿔도 실제 능력치·체력·회복 타이머에 영향이 없는지 확인한다.
- [ ] 작은 화면에서 비교 패널이 전리품 드래그와 인벤토리를 가리지 않고 설명을 읽을 수 있는지 확인한다.

## 한 판 시간·웨이브 설계

등록일: 2026-10-29 · 상태: 구현 예정 / 시간 배분 시험안

사용자 목표는 전투 7분~7분 30초, 아이템 분배 2분 30초~3분이다. 정상 클리어 시 약 10분을 기준으로 설계한다. 첫 시험은 10웨이브와 중간 분배 9회를 유지하고, 전투 7분 15초 + 분배 목표 2분 45초로 진행한다. 전멸에 따른 패배는 더 일찍 끝날 수 있다.

| 비교안 | 전투 | 분배 목표 | 합계 |
|---|---|---|---|
| 분배 여유형 | 7분 | 3분 | 10분 |
| 첫 시험 기준안 | 7분 15초 | 2분 45초 | 10분 |
| 전투 집중형 | 7분 30초 | 2분 30초 | 10분 |

### 웨이브별 기준안

| 웨이브 | 전투 시간 | 이후 분배 목표 | 종료 보상 개수 제안 | 구간 목적 |
|---|---:|---:|---:|---|
| 1 | 30초 | 15초 | 3개 | 기본 공격·이동과 첫 장비 선택 |
| 2 | 30초 | 15초 | 3개 | 주무기와 보조 장비 연결 |
| 3 | 35초 | 15초 | 3개 | 첫 합성·인접 효과 경험 |
| 4 | 40초 | 20초 | 4개 | 공격·생존 투자 방향 선택 |
| 5 | 40초 | 20초 | 4개 | 부족한 역할 보완 |
| 6 | 45초 | 20초 | 4개 | 공간 부족에 따른 교체·재배치 |
| 7 | 45초 | 20초 | 4개 | 후반 조합 정리 |
| 8 | 50초 | 20초 | 4개 | 강화한 조합 성능 확인 |
| 9 | 55초 | 20초 | 4개 | 최종 전투 준비·무료 부활 |
| 10 | 65초 | 없음 | 분배 없음 | 최종 생존 시험 후 결과 화면 |
| 합계 | 435초 · 7분 15초 | 165초 · 2분 45초 | 중간 전리품 총 33개 | 전투+분배 목표 10분 |

분배 시간은 강제 제한이 아닌 플레이테스트 목표다. 자동 진행이나 제한시간을 추가하지 않는다. 실제 분배가 길어지면 총 시간이 10분을 넘을 수 있으므로, 이 단계에서 최대 10분을 보장하는 것으로 취급하지 않는다.

### 흐름·측정 기준

- 웨이브는 정해진 시간이 끝나면 종료한다. 남은 적을 전부 처치하기 위한 추가 시간을 요구하지 않는다.
- 정비 중에는 전투 시간과 전투 동작을 멈춘다. 장비 확인·이동·회전·합성·무료 부활·진형 선택은 분배 시간에 포함한다.
- 보상 표시와 다음 웨이브 카운트다운 등 중간 전환에 실제 시간이 든다면 분배 예산에 포함하며, 세부 전환 시간도 따로 기록한다. 전투+분배 합계에 중복 계산하지 않는다.
- 캐릭터 선택·초기 로딩·결과 화면 체류는 위 10분에서 제외하고 별도 기록한다. 일시정지와 테스트용 배속·웨이브 건너뛰기도 기록해 정상 플레이와 구분한다.
- 몬스터 체력·공격력·등장 수·등장 간격은 정해진 전투 시간 안의 압박을 조절하는 데 사용한다. 몬스터 강화만으로 한 판 시간을 맞추지 않는다.
- 32종 전체를 한 판에 모두 보여주지 않는다. 초반은 현재 주무기와 연결되는 보조 장비를 접할 수 있도록 보상 구성을 검토하고, 후반은 합성·교체 선택을 제공한다.

### 구현 체크리스트

- [ ] 현재 첫 웨이브 60초 + 이후 10초씩 증가하는 계산을 위의 웨이브별 시간 데이터로 교체한다.
- [ ] 설정 데이터에 웨이브별 전투 시간과 보상 개수를 추가하고, 기존 설정 로드·테스트 설정 화면도 함께 갱신한다.
- [ ] 1~3웨이브 종료 보상 3개, 4~9웨이브 종료 보상 4개를 시험 설정으로 연결한다. 마지막 웨이브 뒤에는 중간 분배 화면을 열지 않는다.
- [ ] 초반 사용 가능한 보조 장비와 후반 합성 후보의 등장 비율을 정한다. 직업 변경용 주무기가 나올 여지도 남긴다.
- [ ] 각 웨이브의 전투·분배·전환 시간, 전체 유효 플레이 시간과 실제 경과 시간을 구분해 기록한다.
- [ ] 시간 종료 시 남은 적·투사체·효과를 정리하고 정비로 전환하며, 최종 웨이브는 결과 화면으로 연결한다.
- [ ] 전멸 시 즉시 패배 처리하고, 시간 종료와 전멸이 동시에 발생할 때의 판정 우선순위를 확정한다.
- [ ] 기존 규칙 검증의 웨이브 시간·보상 개수 기대값을 새 설정에 맞춰 갱신한다.

### 검증 및 조정

- [ ] 기본 배속·건너뛰기 없는 정상 클리어에서 전투 합계가 435초를 목표로 동작하는지 확인한다.
- [ ] 중간 분배가 정확히 9회이고 총 전리품이 시험 설정대로 33개 생성되는지 확인한다.
- [ ] 실제 플레이에서 분배 합계가 150~180초 안에 들어오는지 측정한다. 초보·반복 플레이 결과를 구분한다.
- [ ] 아이템 설명 읽기, 회전·재배치, 무료 부활, 진형 선택이 분배 시간에 미치는 영향을 확인한다.
- [ ] 분배가 길면 보상 개수·설명 길이·추천 표시·조작 과정을 먼저 개선한다. 강제 제한시간은 별도 결정 없이 도입하지 않는다.
- [ ] 초반 학습, 중반 생존 압박, 후반 조합 검증이 이루어지는지 확인하고 적의 수치·등장 간격을 조정한다.
- [ ] 목표 달성 여부를 측정한 뒤 전투 7분/분배 3분 또는 전투 7분 30초/분배 2분 30초 비교안 적용을 검토한다.

## 3종 진형 선택 실험

등록일: 2026-10-28 · 상태: 구현 예정 / 플레이 차이 검증용

진형이 주는 재미는 아직 검증되지 않았다. 사용자가 균형형·쐐기형·횡대형을 직접 선택하여 비교할 수 있도록 구현한다. 아래 특징은 기대 효과이며 실제 전투상 이점이 확인된 것은 아니다. 현재 함께 이동하는 파티 조작을 유지한다.

### 진형 후보 — 4인 기준

그림의 위쪽은 비교를 위한 전방 표기이다. 실제 전방 기준과 회전 여부는 구현 전에 결정한다. 숫자는 캐릭터가 들어가는 자리이다.

| 진형 | 자리 배치 | 비교할 경험 |
|---|---|---|
| 균형형 | `① ② / ③ ④` | 2열 배치에서 앞뒤 역할과 공격·회복 범위가 구분되는가 |
| 쐐기형 | `· ① · / ② · ③ / · ④ ·` | 한 명이 앞장서는 마름모 배치가 생존·공격에 차이를 만드는가 |
| 횡대형 | `① ② ③ ④` | 넓게 퍼진 일렬 배치가 공격 범위와 피격·지원 범위에 차이를 만드는가 |

### 첫 구현 범위

- [ ] 정비 화면에서 세 진형을 버튼으로 선택할 수 있게 한다. 기본값은 균형형으로 제안한다.
- [ ] 선택한 진형을 강조하고 캐릭터 이름·주무기 아이콘을 넣은 작은 배치 미리보기를 제공한다.
- [ ] 선택 결과는 다음 웨이브 시작에 적용한다. 전투 중 진형 변경과 자유 위치 편집은 첫 구현 범위에서 제외한다.
- [ ] 동일한 캐릭터 순서와 장비로 진형을 비교할 수 있도록 자리 번호와 캐릭터의 대응을 일정하게 유지한다. 수동 자리 교환은 별도 후속 검토로 둔다.
- [ ] 각 캐릭터가 파티 중심에 대한 진형별 목표 위치를 따라 이동하도록 하고, 겹침·떨림·과도한 뒤처짐을 확인한다.
- [ ] 진형 자체에 공격력·방어력 등의 추가 보너스를 부여하지 않는다. 실제 위치와 공격·지원 범위에서 생기는 차이를 관찰한다.
- [ ] 세 진형을 비교할 때 캐릭터 능력치·장비·적 조건을 동일하게 유지한다.

### 구현 전 결정할 항목

- [ ] 전방을 화면 기준으로 고정할지, 이동 방향을 따를지 결정한다. 이동 방향에 따라 자동 회전하는 기능은 확정하지 않는다. 첫 비교는 고정 방향으로 단순화하는 안을 우선 검토한다.
- [ ] 진형별 간격을 정하고, 화면 경계·적과의 충돌·이동 시 자리 추종 방식을 정한다.
- [ ] 초기 파티가 1~3명일 때 사용할 자리와 간격을 정한다. 네 명을 전제로 한 빈 슬롯 참조 오류를 방지한다.
- [ ] 사망 시 전투 중 빈자리를 유지하고, 현재 방식으로 부활하면 기존 자리에 복귀하는 안을 검토한다. 사망자 장비 이동 금지와 무료 부활 확정 규칙은 유지한다.
- [ ] 적이 전열을 통과하는지, 누구를 공격 대상으로 선택하는지 확인한다. 앞에 서는 것만으로 후열 보호가 가능하다고 가정하지 않는다.

### 검증 및 유지 여부 판단

- [ ] Unity 에디터에서 각 진형 선택 → 정비 미리보기 → 다음 웨이브 적용 흐름을 확인한다.
- [ ] 이동·정지·방향 전환·화면 가장자리에서 캐릭터가 겹치거나 순간이동하거나 계속 흔들리지 않는지 확인한다.
- [ ] 사망·무료 부활 및 다음 웨이브 진입 후 자리와 생존 상태가 일치하는지 확인한다.
- [ ] 같은 적·장비 조건에서 캐릭터별 피해량·회복량·생존 시간을 비교한다.
- [ ] 플레이어가 진형을 고른 이유와 체감 차이를 설명할 수 있는지 확인한다.
- [ ] 정비 시간이 늘거나 회피 조작이 불편해지는지 확인한다.
- [ ] 차이가 없다면 진형 보너스를 즉시 추가하지 않고, 선택 기능 유지·단순화·제거 여부를 다시 판단한다.

## 사망 후 장비·부활 규칙 확정

확정일: 2026-10-28 · 상태: 기존 동작 유지 / 향후 변경 시 검증

사용자 확정 사항으로, 이전 개선안의 사망자 장비 회수 제안보다 아래 규칙을 우선한다.

- 사망한 캐릭터의 장비는 해당 캐릭터에게 남으며 생존자에게 옮길 수 없다. 정비 단계에서도 사망 상태라면 이동할 수 없다.
- 부활은 현재 방식대로 유지한다. 정비 화면에서 사망한 캐릭터의 이름 버튼을 누르면 무료로 부활하고, 체력을 최대치로 회복하며 기존 장비를 유지한다.
- 부활 후에는 생존 캐릭터의 일반 장비 조작 규칙을 적용한다. 전투 중 부활이나 새로운 부활 비용·횟수 제한은 추가하지 않는다.

### 유지·검증할 항목

- [ ] 사망자 장비를 생존자에게 직접 드래그하거나 공용 보관함을 거쳐 옮길 수 없는지 확인한다.

## 인벤토리 아이템 32종 구현 계획

등록일: 2026-10-28 · 상태: 기획 후보 정리 / 게임 반영 전

직업별 주무기 2종과 보조 장비 6종, 총 32종을 후보로 관리한다. 아래 효과와 크기는 참고 게임의 원본 수치가 아니라 4×4 인벤토리에 맞춘 자체 설계안이다. 직업 분류는 해당 장비의 추가 효과가 활성화되는 일치 직업이며 착용 제한은 아니다. 다른 직업은 기본 능력치만 받는다. 아래 32종 표의 효과는 이전 후보 효과로 보존하며, 2026-10-29 직업 일치 규칙에 따라 기본/추가 효과로 재분류한 뒤 구현한다. 수치와 중복 후보는 구현 전에 확정한다.

### 공통 규칙안 — 최대 4개

1. 캐릭터당 주무기 하나가 직업을 결정한다. 주무기별 공격·회복 방식은 다르다.
2. 아이템은 4×4 안에 겹치지 않게 배치하며 90도 회전할 수 있다.
3. 보조 장비는 누구나 기본 능력치를 받지만, 일치 직업만 추가 효과를 받는다. 회복 아이템은 기본적으로 본인에게만 적용하고 사제 착용 시 파티 전체에 공유한다. 위치 조건은 같은 인벤토리의 상하좌우 인접만 인정하고, 같은 두 아이템이 여러 면에서 접해도 효과는 한 번만 적용한다. 효과 대상은 아이템 설명에 명시한다.
4. 동일 아이템·동일 등급 2개를 합성한다. 크기·모양은 유지한다.

아이템 하나당 최대 4칸은 별도의 제작 기준안이다. 대각선·특정 행·빈칸 수 조건, 복잡한 제작 조합, 별도 마나·탄약 자원은 첫 구현 범위에 넣지 않는다. 인벤토리의 인접 판정과 전투 중 아군의 거리 판정은 구분한다.

- [ ] `DSUI.cs`에 회전 조작, 드래그 미리보기, 효과가 적용되는 인접 대상 강조, 효과 설명을 연결한다.
- [ ] 크기·모양이 읽히는 판타지 아이콘과 전투 표현을 준비한다. 정비 화면의 캐릭터 이름만 표시하는 구성을 유지한다.

## 아이템 선택·배치 시 추천 캐릭터 알림

등록일: 2026-10-28 · 상태: 구현 예정 / 시각 표현 제안

아이템을 선택했을 때 누구에게 주면 효과적인지 알려주고, 드래그 중에는 실제 배치 가능 여부를 별도로 표시한다. 추천받지 않은 캐릭터도 조건에 맞는 장비를 사용할 수 있다. 기존 이름 중심 화면과 좌우 4×4 인벤토리 구성을 유지한다.

### 상태별 시각 표현

| 상태 | 표시 방법 | 의미 |
|---|---|---|
| 아이템 선택 | 추천 캐릭터 이름 옆 ✦, 금빛 인벤토리 테두리의 느리고 부드러운 밝기 변화 | 장비 효과가 잘 맞는 캐릭터 |
| 추천 근거 표시 | 선택 중에만 이름 아래 `회복 강화` 같은 짧은 문구, 효과를 받을 기존 장비에도 금빛 테두리 | 왜 추천되는지 안내 |
| 인벤토리 위로 드래그 | 현재 대상 인벤토리의 테두리를 선명하게 강조 | 지금 배치하려는 캐릭터 |
| 배치 가능 위치 | 아이템 점유 모양 그대로 반투명 초록색 미리보기 | 해당 위치에 장착 가능 |
| 배치 불가 위치 | 반투명 붉은색 미리보기와 × 표시 | 겹침·경계 초과 등으로 배치 불가 |
| 장착 완료 | 장착된 아이템만 한 번 짧게 빛남 | 장착 성공 |
| 선택 해제·드래그 취소 | 추천·대상·칸 미리보기와 임시 문구 제거 | 기본 화면으로 복귀 |

금빛 추천과 초록/빨강 배치 가능 여부는 다른 의미로 사용한다. 색상 외에 ✦, ×, 설명을 함께 제공한다. 빠른 반복 점멸이나 화면 전체를 어둡게 하는 효과는 사용하지 않는다.

### 추천 대상 판정안

주무기로 결정된 현재 직업과 아이템의 일치 직업을 우선 비교해 추가 효과를 받을 캐릭터를 추천한다. 기존 효과 연결 여부만으로 추천하던 기준은 이 기준으로 변경한다. 실제 대상·인접 조건도 함께 검사한다. 여러 캐릭터가 조건에 맞으면 모두 강조한다. 추천은 시너지 안내이며 빈 공간이나 현재 위치의 배치 성공을 보장하지 않는다.

| 선택 아이템 예시 | 추천 대상 | 임시 안내 예시 |
|---|---|---|
| 숫돌 | 전사이며 효과 대상 조건을 충족하는 캐릭터 | 전사 추가 효과 |
| 관통 화살촉 | 궁수이며 투사체 조건을 충족하는 캐릭터 | 관통 강화 |
| 성전 | 사제 | 파티 회복 공유 |
| 마법사 모자 | 마법사이며 연쇄 공격 조건을 충족하는 캐릭터 | 연쇄 강화 |
| 방패·갑옷 | 전사 전용 추가 효과를 정의했다면 전사 추천 | 기본 방어 / 전사 추가 효과 |
| 다른 직업의 주무기 | 모든 캐릭터를 추천 표시하지 않음 | 드래그 대상에만 `마법사로 변경` 등 교체 결과 표시 |

인접 배치가 필요한 장비는 추천 문구에 `주무기 옆에 배치`를 함께 안내한다. 드래그 중 실제 효과 연결 강조는 현재 미리보기 위치의 인접 판정에 따라 갱신한다. 사망 등으로 장착이 제한된 캐릭터는 추천에서 제외하고 대상 위에 올렸을 때 제한 사유를 표시하는 방향으로 구현한다.

### 구현 체크리스트

- [ ] 아이템 선택·드래그 시작·대상 변경·회전·장착·취소·선택 해제 상태를 연결한다. 클릭 선택과 드래그 선택 모두 지원한다.
- [ ] 효과 계산에 사용하는 아이템 대상 조건을 추천 판정에서도 공유해 실제 효과와 안내가 어긋나지 않게 한다.
- [ ] 추천 캐릭터, 드래그 대상, 실제 배치 가능 위치를 별도로 계산하고 표시한다.
- [ ] `DSUI.cs`에 이름 옆 ✦, 추천 테두리, 임시 추천 이유, 기존 장비의 효과 연결 강조를 추가한다.
- [ ] `DSPointer.cs`와 드래그 처리에 대상 변경·취소·해제 이벤트를 연결한다. 터치에서도 포인터 올리기 없이 선택만으로 추천을 볼 수 있게 한다.
- [ ] 현재 회전 상태와 점유 모양을 반영한 칸 미리보기를 구현한다. 모양 안의 빈칸은 칠하지 않는다.
- [ ] 배치·합성·주무기 교체의 실제 판정 결과를 미리보기에 연결한다. 정상 합성 가능한 겹침을 단순한 배치 실패로 표시하지 않는다.
- [ ] 범위 초과·다른 장비와 충돌·사망 캐릭터 등 실패 사유를 짧게 안내한다.
- [ ] 성공적으로 장착했을 때만 한 번 빛나게 하고, 실패·취소 시에는 성공 효과를 재생하지 않는다.
- [ ] 화면 전환·다음 웨이브·아이템 합성으로 선택 대상이 사라질 때 모든 임시 표시를 정리한다.
- [ ] 강조 표시가 클릭이나 드래그 입력을 가로막지 않도록 한다.

### 완료 확인

- [ ] 숫돌·관통 화살촉·성전·마법사 모자 선택 시 실제 효과 대상 캐릭터와 장비만 추천된다.
- [ ] 직업 추가 효과가 없는 공용 장비와 주무기는 불필요하게 모든 인벤토리를 깜빡이게 하지 않는다.
- [ ] 추천 캐릭터에 공간이 없어도 추천과 배치 불가 안내가 구분되어 보인다.
- [ ] 추천받지 않은 캐릭터에도 규칙상 가능한 장비를 정상 배치할 수 있다.
- [ ] 드래그·회전 중 칸 미리보기와 실제 장착 결과가 일치한다.
- [ ] 인접 조건 충족·해제에 따라 실제 효과 연결 강조가 즉시 바뀐다.
- [ ] 장착·합성·교체·취소·선택 해제·화면 전환 뒤 낡은 강조가 남지 않는다.
- [ ] 작은 화면에서도 이름·아이템 모양·추천 이유가 겹치지 않고 색상 외 표시로 상태를 구분할 수 있다.
- [ ] Unity CLI로 에디터에서 선택 → 추천 → 드래그 → 장착/취소 흐름을 검증하고 캡처를 남긴다.
