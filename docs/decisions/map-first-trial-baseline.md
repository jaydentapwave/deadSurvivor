# 첫 맵 시험 기준 선택

- 날짜·상태: 2026-10-31 KST, 에이전트의 첫 시험 기준 선택. 사용자 개별 정책 최종 채택·실제 게임 적용은 별도.
- 문제와 제약: 원작 이미지로 접지면·충돌·치수를 알 수 없고 현재 파티 이동에는 지형 충돌이 없다. 최종 원작 정보나 최종 아트를 기다리면 하네스와 맵 보정이 서로 막힌다.
- 검토한 대안: 원작 충돌 정보 추가 확보를 선행 조건으로 두기 / 007 후보와 독립 시험 도형으로 우리 규칙을 시험하기. 이동은 자동 축소·회전·개별 우회 추가 / 기존 고정 슬롯을 보존하는 MP03~04 비교.
- 선택과 이유: [착수 명세](../design/map-first-implementation-spec.md)의 I0~I5를 사용한다. 알려진 정상/실패 도형으로 G2를 검증한 뒤, 007 외피를 우리 기본 도형 후보로 시험한다. MP01~09는 기존 슬롯/상태 경로를 보존하는 첫 비교 기준이며 MP10에 따라 공격 정책은 G4에서 별도로 결정한다.
- 영향: 007 근거·배치·과거 사례는 보존하고 최신 문서 입구와 할일을 통합한다. 미래 구현에는 이동 공통 안전성, 부활/정비/출발 사전 검사, 독립 관찰과 복구가 필요하다.
- 재검토 조건: 필수 연결 불가능, 입력0/반전에서 정체·떨림, 진형 유지로 인한 조작감 문제, 외피와 실제 기본 도형의 불일치, RF 핵심 구조 손실. 정책/C/스케일 중 원인을 분리해 CH와 기준 버전을 개정하며 실패 결과를 재해석하지 않는다.
- 검증: [008 준비 검토 기록](../reviews/map-prep-008-review.md). 문서 검토·정적 PASS와 실제 맵 PASS는 별도다.
