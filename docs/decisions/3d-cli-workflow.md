# 외부 3D 생성은 CLI/API를 기본으로 사용

2026-10-31 · 사용자 선택 반영

사용자가 웹 방식과 CLI/API의 토큰 효율을 비교한 뒤 CLI 방식으로 진행하기로 선택했다. Tripo Studio의 바위 전송 시험은 [기존 기록](../reviews/tripo-studio-transfer-20261031.md)에 보존한다.

- 반복 생성은 설치된 프로젝트 로컬 Tripo CLI의 명시적 생성/상태/다운로드 명령으로 구성한다. 별도 자연어 계획 기능을 매번 중첩하지 않는다.
- 반복 대기·파일 검사·Unity 가져오기·검증은 재사용 가능한 로컬 실행 절차에 두고, 에이전트에는 요약/오류/최종 화면을 전달한다. 필수 검사 자체를 생략해 토큰을 줄이지 않는다.
- 인증 상태는 유지한다. 자격 증명은 보고서·소스·터미널 출력에 복사하지 않는다. 전역 설정은 변경하지 않는다.
- 이번 API 잔액 재조회: 사용 가능0, 예약0. Studio 잔액160과 별개다. CLI 선택을 새 결제나 무제한 생성 승인으로 해석하지 않는다.
- 앞선 공개 예외는 일반 바위1개에 한정된다. 프로젝트 이름·지도·원본 자료 공개나 추가 공개 생성을 승인한 것으로 확대하지 않는다.
- 실제 유료 생성 자동화의 비용 상한/모델/공개 범위는 생성 요청 전에 구체화한다. 현재는 비용이 없는 맵 코드·검증기 구현을 진행한다.

이 결정은 도구 선택이다. CLI 생성 성공·최종 맵 제작·아트 품질 승인·상업 이용 권한 확인은 별도의 실제 증거가 필요하다.

2026-10-31 설계 보충: [세 프로젝트의 채택 근거](../design/ai-3d-reference-adoption.md)를 바탕으로 [A0~A5 자산 워크플로우](../workflows/ai-3d-assets.md)를 정했다. Tripo CLI/API와 기존 Unity CLI를 유지하고, Blender 후처리·작업 재개·후보 프리팹 인수·채택 등록을 연결한다. 참고한 Unity MCP의 CLI는 현재 Unity CLI와 별개다. 외부 프레임워크 설치/교체와 새 과금은 이번 결정에 포함하지 않는다. 유료 POST 재시도 미확인/제출 결과 불명은 차단하며 API 잔액은 실제 요청 전에 새로 확인한다.
