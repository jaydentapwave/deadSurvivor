# 첫 원정 학습 설계

근거는 사용자 제공 「배낭 원정대 게임스펙 261116 (1)」의 3.1~3.4절과 8절이다. 프로젝트의 11-16 튜토리얼 초안에서 브루노·볼트 출발과 2·3웨이브 레나·미라 구출 순서를 가져왔다. 설명과 일시정지 중심의 연출은 플레이어가 직접 만나는 상황과 반응으로 바꾼다.

| 구간 | 화면에서 일어나는 일 | 진행 조건 |
|---|---|---|
| 첫 출발 | 브루노·볼트가 들판에서 출발한다. 앞에 슬라임과 작은 빛의 흔적이 보인다. | 접근해 기존 자동 공격으로 슬라임을 잡으면 1웨이브 시간이 흐른다. 첫 웨이브의 적 밀도를 낮춘다. |
| 첫 야영 | 숫돌, 성전, 방어 전리품을 지급한다. 숫돌과 장검 옆에 실제로 놓을 수 있는 한 칸이 같은 색으로 깜박인다. | 장착은 선택이며 성공 여부는 기존 미리보기와 장비 효과가 보여 준다. |
| 다음 두 웨이브 | 레나와 미라가 차례로 슬라임에 둘러싸여 있다. | 슬라임을 처치하면 현장에서 시작 무기를 들고 합류하고 웨이브가 시작된다. 이후 정비에서 각자의 가방을 쓴다. |
| 다시 야영 | 두 번째 숫돌로 합성 기회를 만든다. 같으며 합성 가능한 실제 아이템 쌍은 같은 빛으로 표시한다. 쓰러진 동료가 있으면 기존 부활 버튼에 빛을 준다. | 합성과 부활은 기존 입력과 규칙으로 처리한다. |
| 4웨이브부터 | 네 명이 모이고 정규 출현 패턴과 전리품을 따른다. | 3웨이브 정비에 도달하면 기기에 첫 원정 완료를 저장한다. 그 전에 전멸하면 다음 출발에서 다시 시도한다. |

기존 몬스터의 예고 표시와 3~6웨이브 출현 순서를 사용한다. 이번 단계 판정 범위는 첫 출발부터 네 명의 3웨이브 정비, 기존 일반 원정 경로다. 이후 웨이브 밸런스, 별도 스토리 연출과 레거시 3D 빌드 구성을 범위 밖으로 둔다.
