## 놓친 점과 보완

- 첫 Play 실행 도중 에디터 명령 이름을 잘못 조회해 그 자체가 콘솔 오류로 기록됐다. T2a FAIL을 보존하고 유효한 명령으로 재검증해 14/14를 확인했다. 후보 반영 완료. 명령 스키마 확인을 Play 전에 끝내고 Play 동안 같은 에디터에 별도 제어 명령을 보내지 않는다. [개발 환경](../../개발환경.md#에이전트-도구-연결)에 확인한 조회 방법을 기록했다.
- 16:9 캡처에서 첫 정비의 추천 칸 강조가 어두웠다. 기존 그림에 입히는 외곽선의 알파와 두께를 조정했으나 빈 칸의 테두리가 여전히 어두웠다. 빈 칸과 전리품 위에 금색 선을 직접 그리는 방식으로 바꿨다. 후보 반영 완료. 텍스트 대신 쓰는 단서는 실제 프레임에서 화면과 나란히 보는 기존 절차를 유지한다.
- 미라 조우에서는 상단 진형과 장검·활 사거리 때문에 접근 전에 슬라임 일부가 처치됐다. 조우의 대기 상태를 공격 대상에도 적용했고, 미라를 만나러 가지 않고 2초 버텨도 세 마리가 남는 검사와 Play 조건을 추가했다. 후보 반영 완료. 기존 통합 테스트 안에서 첫 프레임과 입력 전 유예를 검사하며 새 하네스나 추가 전체 플레이는 추가하지 않는다.
- CLI 재컴파일이 먼저 반환되고 에디터가 도메인 전환 중이라 상태에 `playMode`가 빠진 1회는 BLOCKED였다. 준비 복귀 후 확인을 재실행했다. 후보 반영 완료. [개발 환경](../../개발환경.md#에이전트-도구-연결)에 도메인 전환 대기 명령을 기록했다.
