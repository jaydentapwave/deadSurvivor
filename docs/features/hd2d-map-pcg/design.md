### 2.2 층(순서대로, 각 층은 위 층만 읽는다) — `map_pcg/generate.py`

1. **길**: 서로 마주 보는 두 변(SW↔NE 또는 NW↔SE)의 L1 33.5 점을 잇는 곡선. 조종점 3개를 고르게 놓고 번갈아 옆으로 2~6.5m 민 뒤, 원점에서 가장 가까운 거리가 2~5.5m가 되게 곡선 전체를 민다(시작 화면을 지나는 유도선). 꺾임·땅 밖 검사에 걸리면 다시 뽑는다(최대 400번, 시드 8개 모두 첫 번째에 통과 — 측정).
2. **물**: 연못 자리는 L1 8.5~17, 시작 화면에 걸치고, 원점에서 6m+, 길에서 반지름×1.3+3m. 모양 = 극좌표 반지름 함수 + 잡음 SDF. 섬은 반지름 0.7~1.2m. 개울은 먼 두 변(안 되면 네 변)의 L1 34 점에서 연못으로, **길 옆을 바꾸는 횟수 = 1**인 것만(길 접선 기준 부호, 길 가까이만 셈). 건너는 점이 보이는 팔각형 안·L1 9 밖이어야 한다.
3. **턱**: 연못 SDF 0~(0.6~1.5m) 띠를 먼 쪽 150° 호로 자르고 열기(침식·팽창 3칸)로 실 같은 조각을 지운다. 섬 = 턱. 폭포가 있으면 폭포 위 개울 둘레 골짜기 둑. 먼 두 변 L1 25±2 바깥 띠(가장자리 단). 길 위(+2칸)는 턱을 비운다(길이 턱을 가르는 경사 틈).
4. **야영지**: L1 13~25, 보이는 팔각형 안(반지름 3m까지), 길에서 4.5~9m, 물·턱·다리에서 떨어진 자리. 길 가장 가까운 점에서 한 번 굽는 갈래길(반폭 0.45m).
5. **땅 구역**: 0.125m 격자 위 연속 값(색조 −1~1, 닳음, 꽃밭, 자갈)을 두고, 내보낼 때 쌍선형 보간 + 텍셀 단위 잡음으로 문턱을 잘라 경계가 도트 계단이 되게 한다.
6. **배치**: 다리·야영지·표지판 → 울타리 줄 → 숲 + 숲 가장자리 → 테 나무 → 바위 무리 → 물가 돌 줄 → 돌담 → 꽃밭 → 길가 풀포기 → 채우기(돌·풀포기 조금) 순. 모든 자리는 같은 판정(`Placer.ok`)을 지난다: 들판·꼭짓점 상자·보이는 팔각형, 가운데 비움, 노란 꽃, 물 여유, 길 여유(유클리드, 길 반폭 포함), 발자리 간격, 이동 띠 키 큰 것 상한. 마지막에 밀도 창 상한을 넘는 무리는 그 창 안에서 고정 시드로 솎는다.
7. **검사·점수**: `constraints.py`(3절).

### 2.3 결정성

- 모든 무작위는 `numpy.random.default_rng(seed)` 하나와 좌표 해시(`hash01`, 정수 해시)에서 나온다. 잡음은 해시 기반 값 잡음이라 좌표만 같으면 같은 값이다. 같은 시드 → `field_layout.json`·`ground_path.json`·마스크 4장이 바이트까지 같다(시험, 측정).
- `--best-of K`는 하위 시드 `seed×1000+i` K개를 만들어 점수 최고를 고른다(이것도 결정적).

### 2.5 검사·점수 (`constraints.py`)

|---|---|---|

## 5. studio-kit 스킬로 만들기

- 이름 제안: **`field-pcg`**(전투장·들판 지도 절차 생성). 2D·2.5D 공통으로 art 팩 옆 새 팩 또는 2.5D 팩(메모리 "kit 2.5D pack")의 도구로.
- SKILL.md 개요(안):
  1. 언제 쓰나: "맵이 단조로워", "지도 자동으로 만들어줘", "시드 여러 개 뽑아 비교해줘". 안 쓰는 곳: 손으로 정한 이야기 지도, 3D 지형 조각.
  2. 준비: 프로젝트 설정 `.ai/field-pcg/config.json`(2.1절 칸) — 땅 모양·보이는 범위·가운데 비움·소품 목록을 프로젝트 데이터에서 채운다(카메라·이동 한계는 화면 설계 문서에서).
  3. 실행: `seeds` → `selftest`(반례 포함, 실패면 멈춤) → 미리보기 시트 → **사람이 고름**(art-core 6절 "사용자가 먼저 본다") → 고른 시드 `export`.
  4. 넣기: 프로젝트 어댑터(이 게임은 6절 표)가 출력 형식을 게임 데이터로 옮긴다.
  5. 판정: 게임 캡처 1장을 직접 열고, 시작 화면 랜드마크·가운데 비움을 다시 잰다.
- 일반 / 게임 전용 나누기:

## 8. 확인 못 한 것

- **미확인**: 유니티 실제 화면(배경 도트화 패스·3단 툰·외곽선·Bloom을 거친 모습). 미리보기는 근사다 — 특히 다리·천막·울타리·표지판은 색 상자.
- **미확인**: `FieldZoneMask` 셰이더 연결 후 색(K20 밝기 ±0.03 안인지 실제 화면에서 재지 않음). 미리보기에서는 색조 이동이 밝기 보존(가중 합 ≈ 0)으로 설계됨(계산).
- **미확인**: 새 배치의 성능(그리기 호출·세운 판 수). 꽃·풀 판 수는 시드당 430~610(측정)으로 prep 4.4 목표 450~600과 비슷.
- **추정**: 점수 가중치, 숲·꽃밭 밀도, 닳은 흙 문턱. 사용자 선택으로 맞출 값.
- **추정**: seed 6에서 길과 원정대 거리 1.5m(그림에서 눈대중).
- 다른 화면비(2340·2520×1080, 2048×1536)의 시작 화면은 그리지 않았다. 보이는 팔각형 검사는 1920×1080 기준이다.
