## y 뒤집기 (FA1)
F1 바닥 평면은 x = 화면 오른쪽, y = 화면 위다(F1 기획서 E절). 예전은 y = 화면 아래였으므로 (x, y) → (x, −y). 균형형은 대칭이라 모양은 같지만 대원 배치가 위아래로 바뀐다(예전 브루노 = 왼쪽 위 = 새 (−24, 24)). F1 임시 `memberSpots`는 예전 좌표를 뒤집지 않고 옮겨 브루노가 왼쪽 아래였다.

## 화면 방향 → 바닥 방향 (FA2)
F1: 화면 x = x × `unitScale`, 화면 y = y × `unitScale` × 0.5. 바닥 이동 (dx, dy)는 화면에서 (dx, 0.5·dy)로 보인다. 화면에서 (sx, sy) 방향으로 보이려면 (dx, dy) ∝ (sx, 2·sy). 예: 오른쪽 위 45° → 바닥 (1, 2)/√5, 화면에서 (1, 1) 방향. 입력을 그대로 바닥에 쓰면(dx, dy) ∝ (sx, sy) 45°로 민 것이 화면에서 약 26.6°로 보여 "위로 밀면 화면 위로"(A4)는 맞아도 대각선이 어긋난다. 게임 기획서 10절 "아이소 화면에서 방향이 헷갈리지 않는가"를 위해 역변환을 고른다.

## 들판 경계 수치 (FA3)
- 아이소 칸 = 월드 (1, 0.5). 바닥 단위로 칸 하나의 반대각선은 x: 0.5 ÷ 0.0113 ≈ 44.25, y: 0.25 ÷ (0.0113 × 0.5) ≈ 44.25. 64 × 64칸 들판은 바닥 평면에서 반대각선 R = 64 × 44.25 ≈ 2832인 마름모다(가로·세로 같음).
- 보이는 바닥 영역(Pixel Perfect 640×360 기준, 정수 배율): 16:9 = 640×360px → 반폭 590·반높이 664 → R′ = 2832 − 1254 = 1578. 21:9(2520×1080, 3배) = 840×360px → 774 + 664 → R′ 1394. 4:3(2048×1536, 3배) = 683×512px → 630 + 944 → R′ 1258. 모두 0보다 크다.
- 중심에서 경계까지 속도 140으로 약 9~11초. 봇 원 반지름 600은 4:3에서도 원 전체가 R′/√2 ≈ 890 안에 든다.
- 마름모 위 가장 가까운 점: 사분면 부호를 떼고 |x| + |y| > R′이면 t = clamp((|x| − |y| + R′) ÷ 2, 0, R′), 점 = (부호x·t, 부호y·(R′ − t)).

## 따라가기 수치 (AC16)
걸음 1/30초, 비율 0.4(= 12 × 1/30). 일정 속도 v에서 걸음당 a = v·dt = 4.67. 자리 오차 e는 e′ = 0.6·(e + a)라 정상 상태 e = 7, 대원 이동 = 0.4·(e + a) = a. 방향을 뒤집어도 이동은 a를 넘지 않는다. 네 대원의 오차가 같은 식이라 대원 사이 거리는 자리 간격 그대로다. 멈추면 오차가 걸음마다 0.6배(1초 뒤 7 × 0.6³⁰ ≈ 1.5e−6).

## 화면에서 본 진형 간격 (FA8)
`unitScale` 0.5424px/바닥 단위(F1 FA4). 균형형 48 간격 → 가로 26px, 세로 48 × 0.5424 × 0.5 = 13px. 횡대형 끝과 끝 144 → 78px. 캐릭터 그림 48px(아트 기준서 K1)이면 균형형은 많이 겹친다. 예전 판은 1180단위를 캔버스 1600에 그려 1.36px/단위였다(48 간격 = 65px).
