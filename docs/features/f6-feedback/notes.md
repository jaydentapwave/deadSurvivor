기획서: [plan.md](plan.md). 예전 판 코드는 읽기 전용 참고다(규칙만 옮김).

## 예전 판에서 본 것 (관찰)
- `Assets/DeadSurvivor/Runtime/DSGame.Combat.cs` `Hit`: 적이 맞으면 `Effects`에 `text = RoundToInt(n)`, `life = .65f`, 자리 = 적 좌표 + (0, −18)(예전 좌표는 y가 아래로 +라 "위"), 색 `#fff2cc`. 적 `flash = .12f`.
- 같은 파일 `Damage`: 대원 피해는 숫자 없이 `flash = .15f`. 받음 = 피해 × (1 − 방어), 보호막 먼저 흡수.
- `DSWorld.cs` 190행대: 다친 적 모두 HP 막대, 높이 −27(중장갑 × 1.4).
- 흔들림·진동·HP 깎인 구간 강조 코드는 없다(`grep -i "shake\|haptic\|Vibrat"` 0건, 2026-11-15).

## 새 스펙에서 온 것
- `docs/game/2d-전환-계획.md` 44·76행: 몬스터 HP는 "강한 적이나 지금 공격 중인 적만"(예전과 다름).
- 같은 문서 163행: 피격 연출 = 빨간 구간·햅틱·흔들림.
- 게임 기획서 A7: 강한 적 = 중장갑형. P3 하지 않는 것: 모든 몬스터 HP 바, 화면을 덮는 연출.
- 아트 기준서 K15: 피해 숫자 흰 글자 + 검은 테두리. 2.4절 겹: 효과 → 피해 숫자 → UI.

## 정한 값의 이유 (추정)
- 숫자 상한 40: 가상 해상도 640×360에서 한 번에 읽을 수 있는 숫자 수를 넉넉히 잡은 출발값. 부하 판정(`LOAD`)과 사람 판정으로 조정.
- 흔들림 2px·0.15초: "약한 흔들림"(S9). 640×360 기준 2px는 화면 높이의 0.6%.
- 빨간 구간 머무름 0.4초 + 줄어듦 0.35초: 접촉 대기 1초(F4)보다 짧아 연속 피격이 한 구간으로 이어지지 않고 끊겨 보인다.
