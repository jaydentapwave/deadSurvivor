### 임시 그림과 용도

- `PlaceholderSpriteFactory`: 원(대원 대체), 마름모(적 대체), 상자(상태/임시 표시), 타일. 정상 본 게임에서 대체 그림이 켜진 경우를 8·9단계 FAIL로 기록.
- `EffectSpriteCache`: Ring(heal/pulse/boom/blast), Dash(32방향), Chain(발동별 시드). 바닥·연결선의 길이·반지름은 게임 값. 9단계가 새 원근 래스터 품질을 확인.
- `SpriteAtlasService`: 잘린 그림의 피벗을 바꾸는 Sprite.Create와 아틀라스 픽셀 읽어오기. 그림 키 증식을 신규 원화 수로 세지 않음.
- `UprightFootShadow`, `UprightContactShadow`: 그림자용 읽어오기(7단계). `PlayableProbe`: 관측 자르기/읽어오기(5단계 투영 소비처), 게임 그림 아님.
- 적 탄 spore는 EnemyShotView의 3프레임 그림이다. 파일 검색에 임시 원이 없다고 적 탄 행을 빼지 않음.
