## 3. 구현 계획 — 리뷰 PASS 뒤 실행

### U1. 표면·질감과 이행 틀

새 메뉴 `DeadSurvivor/DQ/Apply Main background` (`MainSceneDQBackgroundMigration.Apply`)를 추가한다. 기존 MainSceneBuilder 전체 재생성은 하지 않는다. 저장 전 Edit/컴파일 상태·열린 장면 dirty를 검사하고, 선언한 자산만 저장한다. 자산/메타 원본을 보관해 중간 예외에 복원하고 새로 생성한 대상만 정리한다. 비대상 dirty는 보존한다. 저장 후 재열어 참조·GUID·메뉴2회 bytes 동일을 검사한다. 의도한 재적용 순서는 **Apply Main screen → Apply Main background**다. 화면 메뉴가 apron을 덮더라도 배경 메뉴 재실행으로 복원된다.

생성물은 `Art/HD2D/DQMainBackground/`, `Materials/HD2D/DQMainBackground/`, `Models/HD2D/DQMainBackground/` 아래로 분리한다. 그림은 게임에서 실제 참조하는 최종본만 커밋하고 시도별 그림·수치·감사는 `output/hd2d-dq/apply/6/`에 둔다. 기존 시안/원본 소품 메시·UV 변경0.

풀·흙·돌길·구역 혼합 마스크는 고정 seed의 생성기로 만든다. 풀은 넓고 옅은 색 얼룩, 길 경계는 연속 혼합으로 처리한다. 격자 좌표 floor/낱개 점 디더/배경 외곽선/Point 샘플을 새 표면에 쓰지 않는다. 색은 기준서 K37·K38/3.5절, 필터는 Trilinear+밉, 대원 깊이 질감 밀도는3.1절 기준을 따른다. 배경 저해상 패스는 다시 켜지 않는다.

DQ 표면 셰이더는 실제 높이와 지형 참조 깊이를 구분하고 기존 `_FlatDepth` 역할(다리·길·수면 통과)을 보존한다. 가림 창은 대원 주위만, 그림자 패스에는 화면 창을 넣지 않는다. 정상/가림 변형의 색·알베도·필터는 동일하고 가림 속성만 달라야 한다. URP Lit로 일괄 치환하면 이 계약을 잃으므로 사용하지 않는다. 광원·그림자 길이·흐림 보정은 추가하지 않는다.

### U2. 지형·배치

`TerrainHeightGrid` 형식·보간을 재사용해 시각 높이를 굽는다. 중앙 통행 구역 peak-to-peak ≤0.5m, 가장자리/먼 언덕1.5~3m를 목표로 한다(K39 추정값 표시). 기존 물 윤곽과 다리 연결에서는 수면/바닥 접속을 고정해 높이 갱신으로 수면이 풀밭을 뚫지 않게 한다. 능선은 넓고 완만하게 이어지며 원형 단일 봉우리 반복을 피한다. 높이를 게임 좌표나 이동 한계에 넣지 않는다.

seed8의 길·물·캠프를 유지하며 식생/바위 군집을 가장자리로 재배치한다. 시작점과 가운데 전투 구역에는 나무·덤불0. 길·다리·야영지에는 실제 모델 bounds를 기준으로 통행 여유를 확보한다. 충돌을 추가해 숨기지 않는다. 배치 여유는 기존 배치 시험의 수치·데이터에서 읽어 적용하고 검사 쪽 수치를 바꾸지 않는다. C9는 개수가 아니라 렌더 마스크에서 보이는 땅 대비 숲10~27%와 가운데0을 잰다.

DQ 나무 키는 새 대원 기준 키 `56/48m` 대비0.9~1.6배로 균일 축척한다(기준서 K50과 K40의 관계). 원본 프리팹의 렌더 bounds·바닥 피벗·삼각형 수를 먼저 읽어 감사표로 고정한다. 바위는 실제 화면에서 실루엣이 읽히도록 크기·큰 명암 대비를 올리고 과도한 잔무늬는 피한다. 작은 풀2·꽃3은 기존3D 모양을 보존하고 매끈한 새 재질로 바꾼다. 새 모델에 collider0, 기존 이동 영역 변경0.

### U3. 잎·물·6종 소품·먼 배경

잎 결 시도1: 채택 수관의 알베도에 잎 뭉치 단위 밝고 어두운 패턴을 넣는다. 윗면 방향의 큰 덩어리를 따르며 무작위 위장 얼룩을 피한다. 게임 크기와 정수배 근접에서 E1과 나란히 연다. 미달이면 시도2는 방법을 바꿔 수관 가장자리의 잎 카드/알파 실루엣을 보강한다. 줄기/원본 메시를 덮지 않고 새 프리팹 자식으로 붙인다. 두 시도 모두 실패하면 남은 결함·수치·직접 본 결과를 적고 반복 중단, 다른 단위를 계속한다. 유료 도구·이미지 생성 서비스 호출0.

다리·천막·울타리·표지판·깃발·돌담의 기존 메시·UV를 그대로 두고 재질 **모든 슬롯**에 새 연속 질감을 연결한다. 현재 돌담 배치0도 카탈로그의 두 변형/전체 슬롯 감사에서 제외하지 않는다. UV 밀도가 부족한 모델은 재질의 월드 좌표 연속 샘플로 보완하며 모양을 다시 만들지 않는다. 정상/가림 변형을 함께 저장한다. 기존 sprite 근거 축척을 DQ 식생에만 끊고 소품 크기는 유지한다.

물은 별도 투명 DQ 수면 재질에서 K42 청록/거품/반짝임을 구현한다. 물 구멍 마스크·물가 경사·수면 높이 접속과 실제 투명 정렬을 확인한다. 통행 판정은 그대로다. 원래 불투명 셰이더를 투명으로 억지 변경하지 않는다. 반짝임은 환경 수면 표현이며 전투 FX의 발광/UI는9단계다.

먼 배경은 장면의 렌더 전용 루트에 언덕 메시+숲 띠로 둔다. 북쪽 요구는 `north-spawn-mask-plan.json` 그대로: NE/NW 마름모 변 바깥0.5~3m, 기존 지형 위 높이1.5~3m, collider0. 장면/리소스에 게임 상태를 저장하지 않는다. 대원 가림 창이 몬스터 스폰 발까지 드러내는 문제를 피하도록 이 띠를 대원 창 가리개와 구분한다. 일반 근경의 registry/대원창은 유지한다. 카메라가 보는 실제 먼 경계 제약 구간을 방향명과 별개로 확인하고, 띠의 xz 범위·높이·가리지 못한 경계의 m구간과 발/몸 가시 건수를 기록한다. 외곽 배경은 apron과 겹침/빈틈 없이 연결한다.

### U4. 마감

단위별 컴파일0+바뀐 범위 시험 후 커밋. 단계 마감에 관련 EditMode 묶음1회, 기본 playable1회, 아래 캡처·측정. N9의 기존 FAIL은 바꾸지 않고 전용 경로가 필요하면1회만 실행하여 현재값을 남긴다. 마감 리뷰 spec-reviewer·validator-client·algorithm-tester를 요청하며 구현/명령/커밋 뒤 멈춘다. FAIL만 한 번 수정·수정 확인. 성능은 재지 않는다. 120분 상한,20분마다 시간 기록,마감 여유를 남기며 새 단위를 시작하지 않는다.
