## 3. 구현 계획 — 리뷰 PASS 뒤 실행

### U1. 표면·질감과 이행 틀

새 메뉴 `DeadSurvivor/DQ/Apply Main background` (`MainSceneDQBackgroundMigration.Apply`)를 추가한다. 기존 MainSceneBuilder 전체 재생성은 하지 않는다. 저장 전 Edit/컴파일 상태·열린 장면 dirty를 검사하고, 선언한 자산만 저장한다. 자산/메타 원본을 보관해 중간 예외에 복원하고 새로 생성한 대상만 정리한다. 비대상 dirty는 보존한다. 저장 후 재열어 참조·GUID·메뉴2회 bytes 동일을 검사한다. 의도한 재적용 순서는 **Apply Main screen → Apply Main background**다. 화면 메뉴가 apron을 덮더라도 배경 메뉴 재실행으로 복원된다.

생성물은 `Art/HD2D/DQMainBackground/`, `Materials/HD2D/DQMainBackground/`, `Models/HD2D/DQMainBackground/` 아래로 분리한다. 그림은 게임에서 실제 참조하는 최종본만 커밋하고 시도별 그림·수치·감사는 `output/hd2d-dq/apply/6/`에 둔다. 기존 시안/원본 소품 메시·UV 변경0.

풀·흙·돌길·구역 혼합 마스크는 고정 seed의 생성기로 만든다. 풀은 넓고 옅은 색 얼룩, 길 경계는 연속 혼합으로 처리한다. 격자 좌표 floor/낱개 점 디더/배경 외곽선/Point 샘플을 새 표면에 쓰지 않는다. 색은 기준서 K37·K38/3.5절, 필터는 Trilinear+밉, 대원 깊이 질감 밀도는3.1절 기준을 따른다. 배경 저해상 패스는 다시 켜지 않는다.

DQ 표면 셰이더는 실제 높이와 지형 참조 깊이를 구분하고 기존 `_FlatDepth` 역할(다리·길·수면 통과)을 보존한다. 가림 창은 대원 주위만, 그림자 패스에는 화면 창을 넣지 않는다. 정상/가림 변형의 색·알베도·필터는 동일하고 가림 속성만 달라야 한다. URP Lit로 일괄 치환하면 이 계약을 잃으므로 사용하지 않는다. 광원·그림자 길이·흐림 보정은 추가하지 않는다.

**D-01 — 높이 설정의 실제 연결도 U1에 포함한다.** 현재 `FieldView.ConfigureTerrainMaterial`의 옛 셰이더 이름 단독 필터를 옛 표면·새 DQ 표면·새 DQ 수면의 명시적 지원 목록으로 확장한다. 아무 셰이더나 속성 유무만으로 받지는 않는다. 정상 재질뿐 아니라 등록 시 선택되는 가림 변형, 카탈로그 전 슬롯, 외곽 apron 재질을 같은 높이 설정 경로에 포함한다. apron이 ground와 재질을 공유하면 중복 초기 상태 저장 없이 한 번만 관리한다. 다른 재질이면 명시적으로 설정·복구 목록에 등록한다. `BuildLandscape`가 `_terrain`을 정한 뒤, 최초 렌더/가림 전환 전에 설정하며, 비평탄은 `_TERRAIN_HEIGHT` on·평탄은 off다. `_terrainKeywordStateDict`에 각 재질의 최초 상태를 보관하고 `OnDestroy`와 중간 초기화 실패 정리에서 정확히 돌려놓는다. 이행 메뉴는 저장된 material 키워드를 영구 초기화하는 것으로 런타임 설정을 대신하지 않는다.

지형 메시·길·수면·apron에는 기존 TEXCOORD1의 참조 높이를 유지한다. 모델처럼 높이 UV가 없는 입력은 뷰에서 해당 footprint의 바닥 참조 높이를 명시적으로 전달하는 DQ 모델 경로로 구분하여, 기본0을 실제 지형 높이로 오인하지 않는다. normal/faded 전환에도 같은 참조 높이를 사용한다. B-07/B-08에서 비영 높이의 평탄면과 비평탄 경사, 정상/가림/apron의 실제 깊이를 확인하고, Y=0 참조와 구별되는 표본을 포함한다. 시작 전 키워드 on/off 두 상태 각각에 대해 진입→가림→해제→종료/실패 뒤 최초값 복구를 확인한다.

**D-02 — 수면 큐 보존도 U1에 포함한다.** `BuildLandscape`의 비평탄 재질 큐1990 강제 목록에서 새 DQ 투명 수면을 제외한다(옛 불투명 수면의 기존 경로는 유지). 역할은 새 수면 셰이더의 명시적 식별자로 정하고 큐 숫자로 추측하지 않는다. DQ 수면은 Transparent 큐3000, `Blend SrcAlpha OneMinusSrcAlpha`, `ZWrite Off`, `ZTest LEqual`을 사용하고 지형/다리 등 불투명 표면 뒤에 그린다. 실제 수면 깊이로 지형/다리에 가려지며 `_FlatDepth`로 Y=0 깊이를 강제하지 않는다. 배우는 기존 불투명/알파클립 패스와 높이/바닥깊이 계약 그대로다. 수면이 기존 바닥 표현보다 높은 지점에서는 배우 발의 수중 부분이 투명수면 색을 받는 것은 허용하되, 수면 뒤 몸 전체나 다리 상판을 덮는 정렬 오류는 허용하지 않는다. 물 구멍/상판/배우 전후·교차를 B-05/B-07에서 실제 GPU로 확인한다.

새 수면의 `rawRenderQueue`는 생성된 재질의 저장값 그대로 보존하며 런타임에서1990 또는 다른 값으로 바꾸지 않는다. 기존 재질 중 큐를 바꾸는 것만 최초 raw값(-1 포함)을 사전에 저장해 종료·중간 실패에 복구한다. B-08에서 수면 큐는 진입전/비평탄 Build후/재시작/종료에 동일하고, 다른 표면 큐는 원래값으로 복구되는지 검사한다. 투명 수면과 불투명 바닥을 동일한 큐 관리 분기에 넣지 않는다.

### U2. 지형·배치

`TerrainHeightGrid` 형식·보간을 재사용해 시각 높이를 굽는다. **F-01 — 영역 경계:** 공유 높이 격자의 게임 영역은 `abs(x)+abs(z) ≤ 32m`다. 그 안의 기복은K39의0.5m 상한과 현재 깊이 계약의 `ReliefWithin(32) ≤ (terrainDepthPad - 1/(48·sin18°))·tan18°` 양쪽을 만족시킨다(현재 약0.2730215m). `terrainDepthPad=0.907692`·카메라·배우·스폰 변경으로 여유를 늘리지 않는다. 공유 격자 전체의 MaxSlope≤0.2·MaxVertexCurvature≤0.08도 기존시험 그대로 보존한다. 높은 언덕은 공유격자에 넣지 않고 `abs(x)+abs(z)>32`인 별도 render-only 메시로 만든다. 북쪽 띠는 north-spawn-mask-plan의 변 바깥 수직거리0.5~3m, 기존지형 위1.5~3m다. 언덕의 지면 투영삼각형이 게임영역 안으로 넘어오지 않게 경계를 자르고, 외곽 apron과 연속 접속한다. 따라서 게임 영역의 시각 높이는 공유하고 바깥 높은언덕은 규칙/배우 샘플에서 제외한다.

기존 물 윤곽과 다리 연결에서는 수면/바닥 접속을 고정해 높이 갱신으로 수면이 풀밭을 뚫지 않게 한다. `TW1WaterAndBridgeSurroundingsRemainFlat`의 기존 표본/허용차 그대로 해당 주변 높이0을 유지한다. 능선은 넓고 완만하게 이어지며 원형 단일 봉우리 반복을 피한다. 높이를 게임 좌표나 이동 한계에 넣지 않는다. 구현 전 `TerrainDataContractTests`를 먼저 실행해 현재상태를 기록하고, 이행 뒤 같은시험을 다시 실행한다. 현재 높이데이터 정적계산상 기존 깊이여유 위반이 예상되므로 그 실패를 새성공으로 숨기지 않고 공유높이 생성에서 해소한다(8절). 검사문턱이나 기대식은 변경하지 않는다.

seed8의 길·물·캠프를 유지하며 식생/바위 군집을 가장자리로 재배치한다. 시작점과 가운데 전투 구역에는 나무·덤불0. 길·다리·야영지에는 실제 모델 bounds를 기준으로 통행 여유를 확보한다. 충돌을 추가해 숨기지 않는다. 배치 여유는 기존 배치 시험의 수치·데이터에서 읽어 적용하고 검사 쪽 수치를 바꾸지 않는다. C9는 개수가 아니라 렌더 마스크에서 보이는 땅 대비 숲10~27%와 가운데0을 잰다.

DQ 나무 키는 새 대원 기준 키 `56/48m` 대비0.9~1.6배로 균일 축척한다(기준서 K50과 K40의 관계). 원본 프리팹의 렌더 bounds·바닥 피벗·삼각형 수를 먼저 읽어 감사표로 고정한다. 바위는 실제 화면에서 실루엣이 읽히도록 크기·큰 명암 대비를 올리고 과도한 잔무늬는 피한다. 작은 풀2·꽃3은 기존3D 모양을 보존하고 매끈한 새 재질로 바꾼다. 새 모델에 collider0, 기존 이동 영역 변경0.

### U3. 잎·물·6종 소품·먼 배경

잎 결 시도1: 채택 수관의 알베도에 잎 뭉치 단위 밝고 어두운 패턴을 넣는다. 윗면 방향의 큰 덩어리를 따르며 무작위 위장 얼룩을 피한다. 게임 크기와 정수배 근접에서 E1과 나란히 연다. 미달이면 시도2는 방법을 바꿔 수관 가장자리의 잎 카드/알파 실루엣을 보강한다. 줄기/원본 메시를 덮지 않고 새 프리팹 자식으로 붙인다. 두 시도 모두 실패하면 남은 결함·수치·직접 본 결과를 적고 반복 중단, 다른 단위를 계속한다. 유료 도구·이미지 생성 서비스 호출0.

다리·천막·울타리·표지판·깃발·돌담의 기존 메시·UV를 그대로 두고 재질 **모든 슬롯**에 새 연속 질감을 연결한다. 현재 돌담 배치0도 카탈로그의 두 변형/전체 슬롯 감사에서 제외하지 않는다. UV 밀도가 부족한 모델은 재질의 월드 좌표 연속 샘플로 보완하며 모양을 다시 만들지 않는다. 정상/가림 변형을 함께 저장한다. 기존 sprite 근거 축척을 DQ 식생에만 끊고 소품 크기는 유지한다.
