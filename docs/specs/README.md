# 게임 컨셉과 현재 스펙

[배낭 원정대 게임 컨셉 + 프로토타입 기능 스펙](배낭원정대_현재게임사양_20261029.docx)

2026-10-29 갱신. 총 22페이지. 게임 컨셉 원본 9페이지와 기존 프로토타입 양식을 유지하고, 6장에 종료 보상과 캐릭터 성장 기획을 추가했다.

- 종료 보상: 편성 캐릭터 경험치·공용 골드, 승리·패배 기준, 사망 캐릭터의 기본 경험치, 결과 화면.
- 기본 능력치: 최대 HP·공격력·방어력·회복력. 병렬 무기 적용, 방어력 효율 완화, 회복 적용 범위.
- 아웃게임: 자동 레벨 성장·캐릭터 단위 골드 강화·성장 성향·미정 수치.

추가 기획은 미구현이며 보상량·성장 수치·비용은 미정이다. [로컬 기획 원문](../design/종료보상과-캐릭터성장.md)과 [할일](../../할일.md)에 연결했다. 원본 DOCX와 게임 코드는 변경하지 않았다.

검증: 컨셉 원본 XML과 9페이지 렌더 일치 PASS. 기존 스펙 10~19페이지 본문 화면 일치 PASS, 갱신 20~22페이지 시각 검사 PASS. 실행 시각·소스 지문·근거는 output/growth-spec/artifact.md에 기록했다.
