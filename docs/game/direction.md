## 1. 정해진 것

다섯 칸 모두 사용자가 준 스펙과 11-15 결정에서 나왔다. 대화로 새로 정한 것은 레퍼런스 모드뿐이다(4절).

| 번호 | 정할 것 | 값 | 출처 |
|---|---|---|---|
| D1 | 한 판에서 하는 일 | 전투 중에는 손가락 하나로 원정대 4명을 끌고 다니며 몬스터를 피하고 모으면, 가방에 든 무기들이 저마다 쿨타임대로 자동 공격한다. 웨이브 사이 정비에서는 전리품을 캐릭터별 4×4 가방에 배치·회전·합성하고 진형을 고른다 | 사용자 — 스펙 1.2 "아이템 분배와 배치", "병렬 자동 전투", "수많은 몬스터들을 쓸어담는 죽이는 시각적 쾌감", 1.3 루프 |
| D2 | 이기고 지는 조건 | 10웨이브를 모두 버티면 승리, 원정대가 전멸하면 즉시 패배. 웨이브는 시간이 끝나야 끝난다. 마지막 웨이브 종료와 전멸이 겹치면 패배 | 사용자 — 스펙 3.1·3.2 "승리 및 패배" |
| D3 | 시점과 조작 | 아이소메트릭 2D 도트(하이비트) + SD 캐릭터, 모바일 가로 화면. 화면을 누르면 나타나는 가상 조이스틱(PC는 WASD), 손을 떼면 멈춤. 정비는 드래그·탭 | 사용자 — 스펙 엔진/플랫폼 "모바일 가로 화면", 3.2 "이동과 진형", 그래픽 컨셉. 시점은 11-15 "2 아이소매트리" |

그 밖에 정해진 것:

- 다시 켜는 이유: 실패 원인(가한 피해·받은 피해·사망 순서)을 보고 다음 판에 이동·장비·편성을 바꾼다 — 사용자(스펙 3.1 "실패와 재도전")
- 분위기: 따뜻한 낮에서 해가 뜨지 않는 밤까지, 어두워질수록 원정대의 빛이 또렷해지는 화면 — 사용자(스펙 그래픽 컨셉)
- 예전 시스템을 옮긴다. 수치는 예전 값(10-29판, `PrototypeData.json`)으로 시작 — 사용자(11-15 "5 예")
- 첫 판 범위: 4명 고정 편성·피격 연출·몬스터 HP 규칙은 첫 판, 패배 원인 화면·원정대 저장은 첫 판 직후, 튜토리얼·성장은 나중 — 사용자(11-15 "4 너말대로")
- 캐릭터 도트 크기: 36px·48px 시안을 게임 크기로 보고 고른다 — 사용자(11-15 "보고 결정하자")
- 그림 도구: Codex로 생성 — 사용자(11-15 "6 codex를 활용해")
