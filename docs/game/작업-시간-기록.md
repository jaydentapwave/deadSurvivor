사용자 요청(2026-11-17 19:31): "전체 시간들을 모두 기록을해주고". 검증 방식을 바꾼 효과를 이 표로 판단한다. 방식 이야기는 [검증 개선안](검증-개선안.md)에 있다.

- 재는 법: 실행 단계는 시작 기록(`.director/runs/<id>/logs/<n>-<k>.before`)부터 결과 파일(`.json`)이 생길 때까지다. 대기열 항목은 러너의 `logs/events.jsonl`에 남은 시작·끝 시각이다. 분 단위로 반올림했다.

- 여러 실행이 동시에 돈 때가 많다. 그래서 합계 시간은 걸린 시간(벽시계)이 아니라 실행 시간의 합이다.
- 다시 계산하는 스크립트(레포 밖): 세션 scratchpad의 `run_times.py`, `queue_times.py`. 새 실행이 끝나면 아래 표에 줄을 더한다.
