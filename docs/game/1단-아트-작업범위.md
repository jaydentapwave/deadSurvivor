## 1. 목표

> 컨셉 그림 1번(들판길 낮 전투) 옆에 게임 캡처를 놓아도 같은 게임으로 보이고, 화면에 임시 도형이 하나도 남지 않은 한 판

끝났다고 볼 기준은 네 가지다.

1. 한 판 자동 판정(로비 → 10웨이브 → 결과 → 다시 시작)을 그대로 통과한다.
2. 로비·전투·정비·결과 네 화면에 임시 그림이 0개다.
3. 몬스터 400마리 장면에서 프레임 16.7ms 이하, 그리기 호출 50 이하다.
4. 컨셉 그림과 나란히 놓은 비교 캡처를 사용자가 보고 판정한다.

## 4. 게임에 넣는 작업

그림 만들기는 여러 개를 나란히 돌리고, 게임에 넣는 일은 하나씩 넣은 뒤 짧은 Play와 캡처로 확인한다.

| 묶음 | 넣을 때 하는 일 | 다 됐다고 볼 기준 |
|---|---|---|
| 바닥 | 임시 두 색 마름모를 풀 타일로 바꾸고, 흙길이 들판을 대각선으로 지나게 깐다 | 이웃 타일 맞닿은 변이 1px 넘게 어긋나지 않음 |
| 걷기 | 움직이면 걷기, 멈추면 지금의 숨쉬기 | 다리가 번갈아 나오고 발 미끄러짐 1px 이하 |
| 공격 | 무기가 발동할 때 그 대원이 공격 동작을 한다. 타격 프레임에 피해가 들어간다 | 무기가 몸 안으로 2px 넘게 파고들지 않음 |
| 효과 | 아이템 발동과 피격 순간에 띄운다. 지금의 피해 숫자·흔들림은 그대로 둔다 | 몬스터 400마리에서 프레임 16.7ms 이하 |
| 쓰러짐·예고 | 사망 시 쓰러진 그림으로 바꾸고, 돌진·자폭 직전에 예고 그림과 흔들림을 넣는다 | 예고가 0.5초 동안 보임 |
| 장식·그림자 | 장식은 들판 가장자리에, 그림자는 대원과 몬스터 발밑에 둔다 | 대원이 장식 앞뒤를 지날 때 겹침 순서가 맞음 |
| 아이콘 | 가방, 전리품 선택, 합성 화면의 임시 표시를 바꾼다 | 32종 모두 칸 모양과 일치 |
| UI | 로비·전투·정비·결과 네 화면의 임시 판넬과 버튼을 바꾼다 | 네 화면에 임시 도형 0개 |

## 5. 함께 고칠 화면 문제

| 문제 | 고치는 방법 |
|---|---|
| 대원 4명이 서로 크게 겹쳐 보인다 | 진형 간격을 넓힌다 |
| 아래 대원 판넬이 전투 화면의 약 20%를 덮고 몬스터가 비친다 | 높이를 줄이거나 불투명하게 한다 |
| 몬스터 HP 막대가 대원 HP의 빨간 구간과 같은 색이다 | 색을 바꾼다 |
| 정비 화면에서 들판의 대원이 가방 사이로 보인다 | 정비 바탕을 어둡게 한다 |
| HP 막대·피해 숫자가 그림 몸통과 겹친다 | 높이를 조정한다 |
| 그리기 호출이 기준 50을 넘는다(지금 약 62) | 비슷한 그림을 묶어 그리도록 고친다. 바닥을 넣을 때 함께 잰다 |
