## 1. 지금 있는 것

### 1.1 정해진 방법 (사용자 판정)

|---|---|---|---|

### 2.2 그 답 뒤에 할 일

1. 지적받은 클립 고치기(같은 지적은 2회 실패하면 멈추고 보인다).
2. 다른 모델 계열 독립 판독 한 번(지금까지 NOT_RUN).
3. 몬스터 5종의 동작(지금은 방향·상태 그림만 있다). 멧돼지 발밑 예고 라인 효과를 다듬는다(사용자 2026-11-22 "멧돼지는 밑에 예고 라인 이미지를 더 디벨롭하면 될것 같아").
4. 아트 기준서 개정: 3.10절 동작 표(지금은 대기 2프레임·피격 변환만·사망 1장), K17 "Aether로 (손질 포함)", K12 몬스터, 3.14 얼굴.
5. 채택된 프레임을 `Assets/Game/03.Resources/Art/`로 옮기고 본 게임에 넣기(`/25d-art-apply` — 새 카메라 판 A 18°, 새 배경, 새 캐릭터·동작).
