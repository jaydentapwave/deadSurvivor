# 보관: HD-2D 전환 계획 (옥토패스·정사영 전제)

- 2026-11-21 보관. 전환 계획, 완성 실행 계획, 전환 교체 목록은 배경 레퍼런스 옥토패스 들판형 + 시안 F(정사영 30°)를 전제로 짠 순서다. 사용자가 배경·시점 기준을 드래곤 퀘스트 HD-2D로 다시 잡아 현재 계획이 아니다.
- 현재 계획: [현재 상태](../../현재상태.md) 맨 위 "다음 세션 시작점".
- 읽는 경우: 이미 끝난 단계(화면 기반, 8방향, UI, 효과, PCG 맵, 높낮이, 빛)의 진행 기록과 사용자 결정 원문 확인.
- 옮긴 뒤 문서 안의 상대 링크는 깨져 있다(고치지 않음). 원래 위치는 `docs/game/`.
