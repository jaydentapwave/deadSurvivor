# 코드 구조와 원본

| 책임 | 파일 |
|---|---|
| 상태·초기화·프레임 입력 | Assets/DeadSurvivor/Runtime/DSGame.cs |
| 런 시작/웨이브/결과/기록 | DSGame.Run.cs |
| 장비 상태 변경 | DSGame.Inventory.cs |
| 순수 배치·효과·공유 제공자 판정 | EquipmentRules.cs |
| 장비 능력치/제공자 타이머 갱신 | DSGame.Stats.cs |
| 무기별 공격·직접 회복·주기 효과 | DSGame.EquipmentCombat.cs |
| 적/피격/투사체/시뮬레이션 | DSGame.Combat.cs |
| 진형과 구간 시간 | DSGame.Formation.cs |
| 화면/입력 | DSUI.cs, DSUI.Equipment.cs, DSUI.Formation.cs, DSPointer.cs |
| 월드 표현 | DSWorld.cs, DSWorld.Equipment.cs (하단 UI용 실제 쿨타임 비율 계산) |

DSGame은 런 상태의 단일 소유자다. partial 분리는 같은 객체의 책임을 파일로 나눈 것이다. EquipmentRules는 전달된 데이터/팀을 계산하며 미리보기는 복사한 상태를 사용한다. UI가 별도 효과 공식을 소유하지 않도록 무기 계산도 공유한다.

C#/JSON·씬·프리팹·.meta·임포트 설정의 단일 원본은 이 저장소의 Assets/DeadSurvivor다. 콘텐츠 JSON은 Assets/DeadSurvivor/Resources/DeadSurvivor/PrototypeData.json이다. Git 작업 폴더와 실제 Unity 프로젝트가 같으며, 별도 사본으로 동기화하지 않는다. UnityMigration에는 직접 실행 검증 템플릿과 아트/폰트 저작 원본만 남긴다.

## 후속 검증·시안

- `Assets/DeadSurvivor/Editor/DSExperiments.cs`: 소유 세션에서 고정 조건 재현 실험과 32종 초기 장비 쌍 비교.
- `Assets/DeadSurvivor/Editor/DSScreenVerification.cs`: 실제 GameView 렌더·UI·캔버스 크기 확인, 임시 해상도/시뮬레이터 복구.
- `Assets/DeadSurvivor/Runtime/DSIconArt.cs`: 32종 로컬 벡터 경로와 임시 아이콘 생성. DSWorld가 캐시/해제를 담당.
- `Tools/Verify/balance_audit.py`: 실험 데이터 지문 확인 후 정적 효과·칸 수·확률과 대조군 분석.
- `Tools/Verify/export_catalog.py`: 동일 아이콘 경로에서 로컬 SVG 목록 재생성.

병렬 실행: EquipmentRules.Actions가 모든 발동 아이템을 열거하고 DSGame.TickAction이 Gear.cd별로 실행한다. Stats(c)는 캐릭터 공통 효과, Stats(c, action)는 해당 발동 아이템의 인접/대상 추가 효과를 포함한다. DSParallelVerification은 독립 타이머와 효과 누출 경계를 검사한다.
