# 컨셉 그림 관찰 (PE-G001~G004)

- 대상: 사용자가 준 게임 스펙 11-12판의 컨셉 그림 4장. 목록과 해시는 [manifest.json](manifest.json). 우리 게임의 컨셉이며 다른 게임 화면이 아니다.
- 모드: **follow**(2026-11-15 "컨셉 그림을 따름 (추천)"). 스펙 레퍼런스 게임 7개는 study — 5절.
- 관찰자: Claude(메인)가 PE-G001·G002·G003을 직접 열어 봤다. PE-G004는 이번에 다시 열지 않았고, 2D 전환 계획 4.1의 관찰(같은 날 메인이 본 것)을 옮겼다.
- 표기: **측정** = 파일에서 잰 값(영역 대표색은 그 영역을 색 4~8개로 줄였을 때 비율이 큰 색), **추정** = 눈대중. 영역 좌표는 원본 픽셀 (x1,y1,x2,y2).

## 1. 시점과 화면 구성

관찰:
- PE-G001: 비스듬히 내려다보는 시점. 흙길·울타리·돌담·다리가 화면 대각선(왼쪽 위 → 오른쪽 아래, 오른쪽 아래의 다리)을 따라 놓였다. 바닥은 마름모 격자가 보이지 않고 그림처럼 이어진 풀밭·흙길이다. 캐릭터는 3/4 정면.
- PE-G001: 원정대(검사·기사)가 화면 가운데, 적은 사방에서 둘러싼다. 화면 가운데는 비어 있고 지형 장식은 가장자리에 몰려 있다.
- PE-G002: 같은 높이의 시점. 원정대 4명이 가운데 뭉쳐 있고 적이 원을 그리며 둘러싼다.

해석/제안:
- 사용자는 시점을 **아이소메트릭**으로 정했다(11-15). 컨셉의 "비스듬한 대각선 배치"는 아이소 2:1 격자와 잘 맞는다. 컨셉에 마름모 이음이 보이지 않으므로, 바닥은 마름모 타일이되 이음이 눈에 띄지 않게 그린다(이음 판정은 시범에서 따로 본다).
- 화면 가운데를 비우고 장식은 가장자리 — 전투 가독성(P3)과 맞다. 기준서에 배치 규칙으로 옮긴다.

## 2. 캐릭터 비율과 크기

관찰:
- PE-G003: 약 3등신(전사: 축소본에서 머리 약 80 / 전체 약 247, 2026-11-15 재관찰 r001과 같은 값으로 고침. 처음엔 2.5로 적었다), 머리가 크고 눈이 크다. 네 명 모두 갈색 큰 배낭(침낭 말이·주머니)을 멨다. 배낭이 몸통만 하다.
- 직업 구분(PE-G003): 전사 = 빨간 머리, 은 갑옷, 빨간 망토·목도리, 둥근 나무 방패, 장검 / 궁수 = 초록 후드, 뾰족 귀, 활, 화살통 / 마법사 = 은발, 파란 고깔모자(금 장식), 파란 로브, 파란 구슬 지팡이, 배낭에 책·물약 / 사제 = 흰·금 로브와 두건, 금발, 손에 등불, 배낭 옆 촛불.
- 화면 속 캐릭터 키(추정): PE-G001 검사 약 150px·기사 약 163px(화면 높이 941의 16~17%), PE-G002 4명 약 105~112px(11~12%). 평균 약 13%.
- 도트 격자(측정, `pixelize.py grid`): PE-G003은 블록 약 5.5px(격자 282×144, 점수 0.19 LOW = 고르지 않음). PE-G001·G002는 블록을 찾지 못함(NOT_ESTIMATED). 컨셉 그림은 진짜 도트 격자가 아니라 "도트풍" 그림이다.

해석/제안:
- 화면 높이의 약 13%를 가상 해상도로 바꾸면: 270줄이면 약 36px, 360줄이면 약 48px(2D 전환 계획 4.3과 같은 계산). 크기는 시범 비교로 사용자가 고른다.
- 컨셉 자체에 격자가 없으므로 "격자 값"은 레퍼런스에서 오지 않는다. 기준서에서 `[방법]`으로 정한다.

- PE-G003 외곽선: 캐릭터 영역마다 짙은 고동색(#2f1108~#39190f)이 많은 비율로 나온다 — 검정이 아니라 **진한 갈색 외곽선**(추정: 영역 색 비율과 눈으로 본 것이 같다).

해석/제안:
- 낮 바닥은 따뜻한 노랑 풀(#c2ad5f 부근)과 밝은 황토 흙(#e4b87d·#cfa36c), 적은 보라·청록 — 바닥과 적을 색상으로 가르는 규칙을 기준서에 둔다.
- 밤은 "어두운 바탕 + 원정대의 빛 하나 + 적 눈·공격만 강조". 2D 조명(전역 빛을 남색으로 낮추고 등불은 원형 빛)으로 만든다(`[방법]`).

## 4. 효과와 UI

관찰:
- PE-G001: 검사의 금색 베기 궤적(호), 맞은 적에 흰·노랑 별 터짐, 피해 숫자(흰 글자 검은 테두리, 12·13). 땅에 노랑·파랑 보석.
- PE-G002: 마법 구체와 궤적은 보라·청록, 화살은 주황 궤적.
- PE-G004(2D 전환 계획 4.1에서 옮김): 노을 협곡, 모닥불. 오른쪽에 가죽 테두리·양피지 칸의 가방 UI와 아이템 아이콘(검·방패·물약·화살통·활).

해석/제안:
- 피해 숫자 모양(흰 글자 + 검은 테두리)은 S9에 쓴다. 보석은 넣지 않는다(기획서 P2).
- 가방 UI는 질감(가죽 테두리·양피지 칸)만 가져오고 구조는 캐릭터별 4×4(기획서 S5).
