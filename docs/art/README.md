> 최신: [Verdant Meadows 구조 분석도 03](maps/verdant-meadows-plan-03.png) · [분석과 원본 비교](../design/3D배경-VerdantMeadows-구조분석-03.md). 원본 직접 입력. 아래 01·02안은 과거 시안이다.

상태: 아이콘 로컬 시안·표시 연결 완료 / 최종 아트 미확정. 기존 아이콘은 외부 생성·업로드·유료 API 없이 제작했다. 2026-10-30 맵 평면도는 사용자 요청에 따라 이미지 생성 도구로 제작했다.

## 맵 설계 이미지

이전 시안: [숲 유적 평면도 02](maps/forest-ruins-plan-02.png) · [설계 설명](../design/3D배경-첫맵-평면설계-02.md). 내부 이동 장애물 배치 시안이며 실제 통로·충돌 검증 전이다.

[숲 공터 평면도 01](maps/forest-clearing-plan-01.png) · [설계 설명](../design/3D배경-첫맵-평면설계-01.md). 준비 단계의 비례 개념도이며 정확한 축척 도면이나 게임 적용 완료 자산이 아니다.

[32종 시안 목록](items/catalog.svg)은 런타임 [DSIconArt](../../UnityMigration/Runtime/DSIconArt.cs)의 동일 벡터 경로에서 내보낸다. `python3 Tools/Verify/export_catalog.py`로 다시 생성한다. 각 ID의 SVG가 items 폴더에 있고 데이터 ID 32개와 일치 여부를 검사한다. 런타임은 64×64 투명 텍스처로 생성해 캐시하고 종료 시 해제한다. 인벤토리 원점 칸·전리품·진형 미리보기에 연결했다. 아이콘은 외형 식별용이며 실제 점유 칸은 별도 모양 표시가 기준이다.

## 제작 기준

- 아이콘: 원본 64×64 또는 배수, 투명 배경, 32×32 축소에서 주요 실루엣 구분. 무기/방어구/보조 구분을 색에만 의존하지 않는다.
- 현재 선화는 임시 시안이다. 짧은 이름·등급 선·점유 모양과 함께 사용한다. 32종 모두 비어 있지 않은 이미지 생성 검사를 수행한다.
- 최종 제작물은 같은 데이터 ID로 교체하고 전체 목록 및 3화면 비율에서 판독성 재검증. 선화 확인을 최종 래스터·애니메이션 완성으로 표시하지 않는다.

## 캐릭터 4직업 외형 명세

| 직업 | 실루엣/도구 | 전투 식별 | 유지할 기준 |
|---|---|---|---|
| 전사 | 짧은 망토, 큰 검/도끼, 각진 방패 | 전방 베기/넓은 부채꼴 | 캐릭터 이름·개인 정체성 유지, 주무기 변경에 따라 역할 표현 |
| 궁수 | 가벼운 옷, 활/쇠뇌, 화살통 | 화살·볼트와 관통/추가발사 | 투사체 진행 방향이 작게 보아도 읽혀야 함 |
| 마법사 | 긴 로브, 지팡이/완드 | 화염 폭발·연쇄 번개·주기 구슬 | 폭발 범위와 연쇄 연결 구분 |
| 사제 | 성물/향로, 밝은 의복 | 단일/주변 회복과 공유 회복 | 회복 대상과 보호막을 공격 피해와 구분 |

현 캐릭터 스프라이트는 기존 임시 자산을 유지한다. 위 명세는 신규 캐릭터 아트 제작 완료가 아니다.

## 전투 효과 교체 목록

| 효과 | 필요한 표현 | 현재 상태 |
|---|---|---|
| 검/도끼 | 짧은 전방 호 / 넓은 부채꼴 | 기존 범위 표현, 최종 모션 미제작 |
| 활/쇠뇌 | 구분 가능한 화살/볼트, 관통 후 잔상 | 기존 투사체 임시 자산 |
| 화염탄 | 이동 화염탄 + 1회 폭발 | 기능 검증, 최종 아트 미제작 |
| 번개 | 재방문 없는 연쇄 연결 | 기능 검증, 임시 타격 표현 |
| 직접 회복/공유 | 받는 대상 표시, 공유 출처를 구별할 작은 빛 | 기능 검증, 최종 표현 미제작 |
| 보호막/구슬 | 보호막 남음/보충, 주기 피해 반경 | 기능 검증, 최종 표현 미제작 |

최종 스타일 선택과 실제 모바일에서의 시인성 평가는 사용자 확인이 필요하다. 제작 명세·아이템 시안·표시 연결을 준비 완료로 관리하고, 캐릭터/전투 최종 아트는 할일에 남긴다.
