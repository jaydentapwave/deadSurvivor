# 장식 그림체 견본 — 출처·측정 (대기열 20261117-art-samples 항목 sample-decor, 시도 1, 2026-11-17)

- 무엇: 장식 종류(기준서 3.3 장식 행, 3.4 장식·소품 8~40px·외곽선 1px #34140e(K5)·형태 단순)의 그림체 견본, 강도 3단계.
  단계마다 꽃 1(꽃 덤불), 나무 1, 돌 1을 만들었다. 양산이 아니다. 사용자가 식물(꽃·나무)과 소품(돌)을 각각 단계 하나로 고른다.
- 상태: **그림체 견본 — 사용자 선택 대기.** identity가 없는 종류라 measure.py 판정이 없다. 시트는 `--unverified "그림체 견본 — 사용자 선택"`.
  PASS는 "기준과 어긋나지 않음"이라는 뜻이다. 자연스러움은 판독과 사용자 판정으로 정한다.
- 회차: 1/2(이 종류의 상한 2회). 생성은 Codex 3건을 동시에 돌려 약 6분 걸렸다. 전체 작업은 약 40분이다.

## 다른 계열 판독 (Claude 하위 에이전트 Opus 5.5 medium. 생성은 GPT 계열)
이름을 가렸다. ref = 컨셉 조각 3장, A = 단계 3, B = 단계 1, C = 단계 2. 낱장 ×6과 합성 ×2를 보여 주었다.
| 단계 | 무엇으로 읽히는가(꽃 / 나무 / 돌) | 같은 게임처럼 보이는가(1~5) | 게임 화면에서 캐릭터와 | 가장 약한 것 |
|---|---|---|---|---|
| 1 (B) | 흰 꽃 셋 달린 덤불 / 두 톤 막대사탕 같은 나무 / 분홍빛 회색 타원 돌 | 2 — 평칠, 질감 없음, 프로그래머 아트처럼 보임 | 읽히지만 납작하다. 나무가 클립아트 같고 밝은 연두 아랫단이 눈을 끈다 | 돌: 특징 없는 분홍 타원이라 알약처럼 보인다 |
| 2 (C) | 흰·노란 꽃 덤불 / 진한 잎 덩이 나무 / 하이라이트와 금이 있는 회색 돌 | 4 — 잎 덩이가 컨셉 나무의 어두운 덩이 무늬에 가장 가깝다 | 잘 어울린다. 조금 어둡고 촘촘하다. 캐릭터보다 튀지 않는다 | 돌: 하이라이트가 반들반들해 보인다. 컨셉 돌은 무광에 이끼가 있다 |
| 3 (A) | 흰·노란 꽃과 보라 점의 둥근 덤불 / 여러 초록 잎 덩이 나무 / 납작한 회베이지 바위 | 4 — 잎 음영과 돌의 얼룩 질감이 가장 가깝다 | 잘 어울린다. 축척·선 느낌이 캐릭터와 맞고 튀지 않는다 | 꽃: 1배에서 너무 복잡해 꽃이 뭉개진다(컨셉은 데이지가 또렷하다) |
- 순위: 단계 2 ≈ 단계 3 > 단계 1. 판독자는 나무는 단계 2에, 꽃·돌 질감은 단계 3에 조금 더 점수를 주었다.
- 세 단계의 공통 차이(컨셉 대비):
  - 초록이 더 노랗고 채도가 높다(위 칠 색 표와 같은 결론).
  - 컨셉에는 단단한 외곽선이 없는데 후보는 모두 1px 갈색 외곽선이다. 이것은 기준서 3.4·K5가 정한 값이라 바꾸지 않았다.
  - 나무 머리가 매끈한 원이다. 컨셉은 들쭉날쭉한 잎 덩이에 가지가 갈라진다.
  - 돌이 작고 회색이고 깨끗한 타원이다. 컨셉은 더 큰 베이지 이끼 바위에 아래 풀이 난다.
  - 꽃이 1~2px 점이다. 컨셉 데이지는 크고 또렷하다. 14px 덤불 크기의 한계다.

## 합성 (합성 — 게임 화면 아님)
- 최신 전투 캡처 02-G2-1920x1080.png를 640×360으로 줄였다(정확히 1/3, 최근접). 그 위의 가장자리 16곳에 게임 크기로 놓았다(나무 3, 꽃 7, 돌 6).
  가운데(x 약 200~440, y 약 90~230)는 비웠다(기준서 3.2). 겹 순서는 화면 Y 순이다. HUD·아래 칸은 그대로 두었다.
- field_x3.png 머리에 "합성 — 게임 화면 아님"을 찍었다. 오른쪽에는 컨셉 조각을 같은 축척(컨셉 1px = 게임 640/1672 px, ×3)으로 두었다.
  같은 축척에서 보면 컨셉 나무는 게임 약 88px 폭이다. 견본 나무(36px 이하)는 기준서 3.4의 상한 40px를 따른 크기라 컨셉보다 훨씬 작다.
- 본 것: 단계 1~3 합성의 왼쪽 가장자리를 2배로 보았고, 단계 3의 field_x3 전체를 보았다. 처음 판의 검은 상자를 거기서 찾아 고쳤다.
  고친 뒤에는 투명 배경으로 풀 위에 놓인다. 두 시트도 다시 열어 보았다.
