Make three separate pixel-art UI frame sprites for a cozy fantasy 2D party survival game (characters are 48 pixels tall, screen 640x360). Use the image generation tool, then copy the results into the current working directory with these exact names: button_raw.png, panel_raw.png, cell_raw.png. Then report each file path, pixel size and sha256. Each file: ONE UI piece only, filling the canvas edge to edge (no margin, no drop shadow outside the piece), any area outside the piece flat solid #ff00ff magenta.
- button_raw.png: an empty rectangular button frame, NO text and NO icon on it. Exactly 32x16 pixel grid, every pixel is one 24x24 flat block, canvas 768x384. It must be 9-slice ready: all decoration of the frame stays inside a border exactly 4 pixels thick; the four 4x4 corners may differ, but the top, bottom, left and right edges between the corners must be the same pattern repeated (so they can be stretched); the centre 24x8 area is one flat fill colour (text will be written there later).
- panel_raw.png: an empty square window panel with a LEATHER border. Exactly 48x48 pixel grid, every pixel is one 16x16 flat block, canvas 768x768. 9-slice ready: the leather border is exactly 6 pixels thick on every side and holds all decoration (corners 6x6 may hold a small brass rivet or corner patch); the edges between corners repeat evenly; the inside 36x36 area is a dark brown leather fill with at most a very faint texture, dark enough that white text stays readable on it.
- cell_raw.png: one PARCHMENT inventory bag slot. Exactly 16x16 pixel grid, every pixel is one 40x40 flat block, canvas 640x640. Light parchment square, a 1-pixel slightly darker edge all round so neighbouring slots read as a grid, empty inside (an item icon of 16x16 will be drawn over it later).
Common rules: no anti-aliasing, no smooth gradients, flat colour blocks only, outermost outline 1 pixel dark brown #34140e (not black). Colours: leather #2f1108 #5c493c #774c3b #af642e #c2864d, brass #f8b828 #f8c838 #c2ad5f, parchment #fff9ed #f8daac #e4b87d #d3ae90 #cfa36c #c9a264.
Exclude: no text, no letters, no numbers, no icons, no items, no characters, no creatures, no gems or coins, no logos, nothing from existing games.
