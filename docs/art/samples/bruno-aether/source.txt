## 처리
- 클립 크기: walk 0.962배, attack 0.922배(머리카락 면적) → analyze 제안 gain 1.0395 / 1.0849를 클립 전체에 적용, offset [0,-8](출력 x8 좌표 = 1 게임 px, 발이 캔버스 밖으로 2px 나가 처리기가 멈춰서). 프레임별 배율은 맞추지 않음.
- 공격은 올린 칼이 64 캔버스 위로 약 7 게임 px, 앞으로 뻗은 칼이 오른쪽 밖으로 나가 처리 캔버스를 96x80 게임 px(768x640)로 넓혔다. → **Aether 공격은 게임 캔버스 64x64에 들어가지 않는다**(칼이 원본보다 길게 그려짐: 원본 약 12px → 약 22px).
- 부위별 색 되돌리기: walk ΔE 전 2.1~7.3 → 후 0.1~1.0 / attack 전 0.8~8.7 → 후 0.1~2.2, 단 attack steel(칼날)은 후에도 최대 7.78(칼이 새로 그려진 부분). 테두리 번짐 output_fringe PASS.
- 도트로 내리기: pixelize.py의 pixelize()(블록 최빈색, 기준서 3.5 팔레트 r2 45색)를 그대로 불러 8x8 블록 → 1px. 프레임마다 가장 아래 줄을 캔버스 맨 아래 줄(64 높이 63 / 80 높이 79)에 맞춤, 피벗 x 32(서 있는 그림과 같음). 정수 픽셀만.
- 고른 프레임: walk 원본 칸 15,16,17,18,19,20,21 (7장, 반복 후보 2위 start 15 len 7, 다리 한 주기) → walk/walk_00..06.png
  attack 원본 칸 10(들어올림),15(머리 위),20(내려치기 시작),22(휘두름, 흰 궤적 포함),25(앞으로 뻗음) → attack/attack_00..04.png, attack_05.png = 기준 그림(대기) 그대로(회복, 조각 방식 04와 같은 처리)
- 10fps(기준서: 걷기 0.6초 주기 → 7장 0.7초, 공격 0.6초).

## 판정(참고 기록 — 비교 후보라 통과 여부로 고르지 않음)
- 분석 표시: 둘 다 "키 검토 필요"(그림에 둘러싸인 키 색 영역 지움 = 다리·팔 사이 틈 / 그림 안 키 근처 색 남음). 시트를 눈으로 대조해 먹힌 부위는 보지 못했으나 확대 대조는 하지 않음(미확인).
  attack "끝 자세 불일치": 끝 구간(33~35칸) shape 0.593 > 0.15, inside 0.235 > 0.12 — 끝 장의 칼이 끝 입력보다 훨씬 길고 자세가 다르다.
- frames.py holes --ref: walk 6/7 PASS, walk_02 구멍 2px FAIL / attack 5/6 PASS, attack_01 구멍 6px FAIL. 조각 방식은 5/5 PASS였다.
- measure.py compare --id bruno --pose: walk --changed boots 7/7 FAIL(same_outside 66~76% 다름 — 몸 전체가 매 장 새로 그려짐, stroke_ratio 0.106~0.170 / 기준 0.1667), attack --changed steel 00~04 FAIL(bbox 비율이 달라 same_outside 판정 불가, stroke_ratio 0.137~1.02), 05(기준 그림)만 PASS. identity에 fixed 부위가 없어 부위 판정은 NOT_ASSESSED.
- 도트 흔들림(깜빡임): 머리 위 14줄의 이웃 프레임 간 바뀐 픽셀 수(가로 ±2px 맞춤 뒤) Aether 걷기 [92, 32, 128, 24, 98, 77, 81] / 조각 걷기 [0,0,0,0,0,0] / 조각 공격 [0,0,0,0,0]. → Aether→도트는 같은 머리·얼굴의 도트가 매 장 달라져 깜빡인다.
- 완성 GIF를 디코딩해 순서대로 직접 봄:
  - 걷기(오른쪽): 다리가 앞뒤로 번갈아 나오고 망토·팔이 흔들린다(조각보다 동작은 크고 자연스럽다). 단 **칼이 사라졌다**(입력 그대로인 0번 칸 말고는 1~35칸 모두 손에 칼이 보이지 않음 — Aether가 아래로 든 칼을 지움, 축소 시트로 본 판단), 몸이 약간 옆으로 돌아 더 날씬해 보이고, 머리카락·얼굴 도트가 매 장 깜빡인다.
  - 공격(오른쪽): 팔 전체로 칼을 머리 위로 들었다가(어깨·팔꿈치·손이 함께 움직임) 앞으로 내려친다 — 사용자가 지적한 "조각 방식은 팔이 가만히 있다"는 해결됨. 단 칼이 원본보다 두 배 가까이 길고, 휘두름 칸에 흰 궤적(효과)이 그림 안에 그려졌고, 64 캔버스를 위·오른쪽으로 벗어난다. 마지막 대기(기준 그림)로 넘어갈 때 한 번에 튄다. 들어올림 칸 얼굴이 입 벌린 표정으로 바뀜.
- 다른 계열 판독: 하지 않음(이 단계 범위 밖).
