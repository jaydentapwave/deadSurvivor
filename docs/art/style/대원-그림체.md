# 대원 그림체 안내 — 같은 그림체로 일관되게 뽑는 법

- 값의 원본은 [아트 기준서](../아트-기준서.md) 3.14절(K50~K56)이다. 이 문서는 그 값을 그림 생성에 쓰는 **절차·문구·점검표**만 모은다. 부딪히면 기준서를 따른다.
- 채택: 2026-11-22 사용자 "8번으로하자, 우선 아트스타일을 모두 정리를해서 일관성있게 이미지가 뽑힐 수 있게끔 해줘".
- 범위: 대원 4명(전사 bruno, 궁수 lena, 마법사 mira, 사제 bolt)과 몬스터 5종(8절). 몬스터는 2026-11-22 사용자 "몬스터 캐릭터도 마찬가지야, 전사 캐릭터를 기준으로 다시 설계를 해줘"로 정해졌다(기준서 1절 12행·K12의 "지금 그림 그대로"는 다음 기준서 개정 때 이 결정으로 바꾼다 — 아직 개정 전).

## 1. 그림체 견본 (모든 대원 생성에 넣는 입력)

| 무엇 | 파일 |
|---|---|
| 채택 견본(도트본, 72×72) | `Assets/Game/03.Resources/Art/HD2D/RoundDQ2/Characters/bruno_dq_c08.png` |
| 견본의 생성 원본(1152×1152, 16px 블록) | `docs/art/style/hero-08-generated.png` |
| 견본을 만든 프롬프트 원문 | `docs/art/style/hero-08-prompt.txt` |
| 게임 화면에서의 모습 | `output/hd2d-dq/char-r1/P3-c08.png`, `P3-lineup-labeled.png` |

생성 입력은 늘 둘이다: **그림체 = 견본(8번)**, **생김새 = 그 인물의 예전 그림**(`Assets/Game/03.Resources/Art/AIGenerated/Characters/<이름>/front/…`). 프롬프트에 "그림체·명암·선·비례는 첫째 그림, 인물의 머리색·옷·장비는 둘째 그림"이라고 쓴다. 드퀘 원본은 넣지 않는다.

## 2. 고정 값 (인물이 바뀌어도 같다)

| 항목 | 값 |
|---|---|
| 캔버스·키 | 72×72 칸, 키 56칸(y8~y63), 발 가운데 (36, 64), PPU 48, Point, 압축 없음 |
| 생성 크기 | 1152×1152, 한 칸 = 16×16 블록, 안티에일리어싱·그라데이션·디더 없음 |
| 비례 | 약 2.5등신, 얼굴이 넉넉히 보이게(앞머리가 눈을 가리지 않는다) |
| 얼굴 | **7절 "얼굴 규격"대로**(전사 8번 실측). 눈썹·입·코를 그리지 않는다 |
| 재질 | 색 가족 5개 이상(각 3% 이상), 한 가족이 45%를 넘지 않는다. 재질마다 5단계(진한 선·그늘 ~ 밝은 반사) |
| 선 | 실루엣과 재질 경계에 그 면의 가장 진한 색 선. 바깥 둘레의 50~70%가 어두운 칸, 빛 받는 왼쪽 위는 한 단계 밝게. 공통 갈색 선(#2f1108)을 몸 안에 긋지 않는다 |
| 빛 | 왼쪽 위. 가장 밝은 칸 L* ≥ 85, 가장 어두운 칸 L* ≤ 20 |
| 색 수 | 32~36색(내릴 때 디더 없이 양자화) |
| 장식 | 리벳·주머니·끈 같은 1~2칸 장식 없음. 금 장식 1~2곳. 배낭은 어깨 뒤로 조금 보이는 한 덩어리 |
| 후처리 | 알파 잘라내기 → `pixelize.py`로 72×72 → 32색 양자화. 중간값 필터·흐림·"정리" 금지(세부를 지우면 실패 — 개선 기록 P31) |

| 대원 | 색 가족(주 → 보조) | 실루엣 밖으로 나오는 장비 | 예전 그림에서 지킬 것 |
|---|---|---|---|
| bruno 전사 | 빨강(머리·망토·목도리) + 강철 은청 갑옷 + 살색 + 갈색 가죽 + 금 | 둥근 빨간 방패(은 테·가운데 돌기), 강철 칼 | 빨간 뾰족 머리 |
| lena 궁수 | 초록(두건·망토) + 갈색 가죽 갑옷 + 살색 + 밝은 금갈색 머리 + 강철(화살촉·버클) | 활(몸 옆으로), 등 뒤 화살통 | 뾰족 귀, 초록 두건, 초록 눈 |
| mira 마법사 | 파랑(고깔·로브) + 은회색 긴 머리 + 살색 + 금(테두리·별 장식 1곳) + 나무 갈색(지팡이) | 끝에 청록 구슬이 달린 지팡이, 넓은 챙 고깔 | 파란 눈, 은빛 긴 머리 |

"따라 하지 않을 것": 기존 게임의 캐릭터·문장·뿔 투구·의상 디자인, 도리야마 얼굴(기준서 3.8절, 캐릭터 관찰 문서).

## 4. 프롬프트 틀

견본 프롬프트(`hero-08-prompt.txt`)의 2~4번째 문단(재질 5개·얼굴·선과 명암·캔버스 규격)은 **그대로** 쓰고, 첫 문단(인물)과 재질 목록만 3절 표로 바꾼다. 문단을 줄이거나 말을 바꾸지 않는다 — 같은 문구가 같은 그림체를 낸다.

```
Generate ONE production-quality ORIGINAL chibi pixel-art RPG <직업> sprite, <이름>. Image 1 is the STYLE reference (rendering, shading steps, outline method, proportions, face drawing, pixel block size): match it exactly. Image 2 is OUR existing sprite of this character, used only for identity: <머리·옷·장비>. Facing <방향>. Standing, about 2.5 heads tall. Same sprite set as image 1 — the two must look drawn by the same artist.

CRITICAL readable distinct MATERIALS: <3절 색 가족을 면적 비율과 함께>. Keep at least FIVE clearly different color families, each >=3% area, large continuous shapes. Do NOT wash colors toward pink or gray.

(이하 견본 프롬프트의 얼굴 / 선·명암 / 캔버스 문단을 그대로)
```

한 회차 후보 4장(같은 설정 2장 × 2설정). 방향이 다른 그림은 그 인물의 **새 정면 그림**을 인물 입력으로 쓴다(예전 그림이 아니라).

## 5. 점검표 (보이기 전에 만든 쪽이 채운다)

| # | 볼 것 | 어떻게 |
|---|---|---|
| 1 | 견본과 같은 그림체인가 | 견본(8번)과 새 그림을 같은 배율로 나란히 놓고 직접 연다: 선 굵기·색, 명암 단계, 눈 그리는 법, 머리 크기 |
| 2 | 같은 인물인가 | 예전 그림과 나란히: 머리색·모자·장비 |
| 3 | 규격 | 72×72, 키 56칸(±1), 발 (36,64), 반투명 픽셀 0 |
| 4 | 재질·명도 | 색 가족 ≥ 5, 최대 가족 ≤ 45%, L* 폭, 바깥 둘레 어두운 칸 50~70%(견본 값 ±10%p 안) |
| 5 | 얼굴 | 7절 얼굴 규격 표를 칸 단위로 재서 채운다(눈 폭·높이·간격·색, 눈썹 0칸, 입 0칸). 전사 얼굴과 같은 배율로 나란히 놓고 직접 연다 |
| 6 | 넷이 한 벌인가 | 네 명을 한 줄에 세운 시트: 키·머리 크기·선 굵기·채도가 고르다 |
| 7 | 게임 화면 | 판 A 시험 구역에 세워 캡처, 풀밭에서 실루엣이 서는지·발이 뜨지 않는지 |
| 8 | 다른 계열 판독 | 만든 쪽과 다른 모델 계열에게 견본과 새 그림을 주고 "같은 화가가 그린 한 벌로 보이는가, 어긋나는 점"을 묻는다 |

측정 수치 `lum_step20`·`lowfreq`는 참고로만 적는다(견본 자체가 넘는다). 숫자를 맞추려고 세부를 지우지 않는다.

## 7. 얼굴 규격 (전사 8번 실측 — 2026-11-22 고침)

사용자 2026-11-22: "캐릭터를 봤는데 눈이좀 이상한것 같아, 전사를 제외하고, 입이 생겼고, 다시분석한다음에 만들어줘 … 전사 캐릭터를 기준으로 다시 설계를 해줘".
원인: 이 문서 2절과 프롬프트 얼굴 문단이 "눈썹 2, 짧은 입, 눈 2×2칸 이상"을 요구했는데, 채택된 전사 그림에는 눈썹도 입도 없다(프롬프트에 있었지만 그림에는 그려지지 않았고, 사용자는 그 그림을 골랐다). 세 명은 그 문구대로 큰 눈·눈썹·입이 생성됐고, 그 위에 3×3칸 눈·눈썹·3칸 입을 덧그렸다(`output/hd2d-dq/heroes-r1/retouch_faces.py`).

전사 `bruno_dq_front.png`에서 잰 값(72×72 칸 좌표):

| 항목 | 전사 값 | 잘못 나온 세 명(heroes-r1) |
|---|---|---|
| 눈 한 개 | **폭 2칸 × 높이 2칸**: 윗줄 [흰 점 #fbfbfb, 진한 눈동자 #180a12], 아랫줄 [흰 #fbfbfb, 살색 그늘 #c46d51]. 흰 칸이 얼굴 바깥쪽, 진한 칸이 안쪽 | 폭 4~5칸 × 높이 3~4칸, 초록·파랑 홍채 |
| 속눈썹 선 | 눈 바로 위 한 줄, 폭 3~4칸, 머리카락의 가장 진한 색(#2c0509) — 눈썹이 아니라 눈 윗선이며 앞머리 그늘과 이어진다 | 눈 위에 한 줄 띄운 별도 눈썹 3칸 |
| 눈 사이 | 살색 4칸(x36~39) | 1~3칸 |
| 입·코 | **없음(0칸)**. 눈 아래는 살색 3줄뿐 | 갈색 입 3칸 |
| 홍채 색 | 없음 — 눈동자는 진한 색 한 가지 | 인물별 색 |
| 얼굴 살색 폭 | 9~10칸, 눈은 얼굴 아래쪽 절반에 있다 | 11~13칸 |

- 세 명의 눈 색(초록·파랑)은 그리지 않는다. 인물 구분은 머리·모자·장비가 맡는다. (사용자가 눈 색을 원하면 그때 눈동자 1칸만 그 색의 가장 진한 단계로 바꾼다.)
- 생성 프롬프트의 얼굴 문단은 아래로 바꾼다(견본 프롬프트의 얼굴 문단은 쓰지 않는다):

```
FACE — copy the face drawing of image 1 exactly: two TINY simple eyes, each only 2 logical pixels wide and 2 tall (one white catchlight pixel on the outer side + one very dark pupil pixel), under a short dark upper-lash line that merges into the hair shadow. 4 skin pixels between the eyes. Eyes sit in the lower half of the face. ABSOLUTELY NO mouth, NO nose, NO separate eyebrows, NO coloured iris, NO large anime eyes, NO blush. Below the eyes only plain skin. Face skin about 9-10 logical pixels wide.
```

- 도트로 내린 뒤 눈이 규격과 다르면 **전사의 눈 칸 무늬를 그대로 옮겨** 그린다(색은 그 인물 팔레트의 가장 진한 머리색·흰색·살색 그늘). 눈썹·입을 더하는 손질은 금지.

## 8. 몬스터 (2026-11-22 사용자 결정 — 전사 그림 방식으로 다시 설계)

- 생김새는 그대로 우리 것(K12): 슬라임형 덩어리, 버섯, 가시 바위, 뿔 짐승(멧돼지), 부푼 가시 덩어리. 크기는 지금 그림의 칸 수(게임 데이터)를 지킨다.
- 그림 방식만 전사와 같게: 재질마다 4~5단계 명암, 빛은 왼쪽 위, 면 색을 따르는 진한 외곽선(공통 갈색 한 색 금지), 가장 밝은 칸 L* ≥ 85·가장 어두운 칸 L* ≤ 20, 리벳·점 같은 1~2칸 잔 장식 없음, 한 칸 = 화면 2px, 디더·안티에일리어싱 없음.
- 얼굴: 눈은 7절의 눈 무늬(2×2칸, 흰 점 + 진한 눈동자, 윗선)를 쓴다. **입·눈썹·코 없음**(멧돼지 엄니와 코 판은 얼굴 표정이 아니라 생김새라 남긴다). 슬라임·바위의 노란 빛나는 눈은 쓰지 않는다(색은 사용자 판정 때 되돌릴 수 있게 후보 한 장은 노란 눈으로 남긴다).
- 풀밭과의 분리(기준서 C8, ΔE ≥ 25)는 그대로 본다.
- 생성 입력: 그림체 = 전사 견본(8번), 생김새 = 그 몬스터의 지금 정면 그림(`Assets/Game/03.Resources/Art/AIGenerated/Monsters/HD2D8/<이름>_down.png`).

- **2026-11-22 사용자 판정(heroes-r2 미리보기를 본 뒤)**: "괜찮은것 같아, 몬스터는 좀 더 다양한 형태도 괜찮아, 몬서트 눈까지 통일할 필요는 없으니 다음 몬스터들은 그냥 해주면된다". → 대원 세 명 얼굴(7절 규격)과 몬스터 5종 정면 시안은 받아들여졌다. **앞으로 만드는 몬스터는 눈을 7절 무늬로 통일하지 않는다**(종류마다 어울리는 눈·얼굴, 빛나는 눈도 가능). 형태도 둥근 덩어리에 묶지 않고 다양하게 한다. 지킬 것은 그림 방식(명암 단계·면 색 외곽선·왼쪽 위 빛·잔 장식 없음)과 풀밭 분리뿐이다. 위 "얼굴" 줄의 통일 규칙은 이 판정으로 대체된다.
