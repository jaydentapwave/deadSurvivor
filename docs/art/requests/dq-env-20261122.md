## 2026-11-22 생성 실행 계약

- 생성 기준: **TRIPO-STATIC-PROP/r001**. 장식용 정적 소품 10개. 주변 지형·바닥·문자·리깅·동작은 포함하지 않는다. 충돌·장면 배치·Unity 규격 검사는 다음 단계 몫이다.
- 컨셉 채택: 사용자 "배경은 우선 괜찮은것 같고". 유료 승인 원문·상한은 위와 같고 옛 예산을 쓰지 않는다.
- 이번 설정: `3dkit.dq-env.config.json` → `docs/art/dq-env-asset-catalog.json`. 실행 앞에 `KIT3D_CONFIG=3dkit.dq-env.config.json`을 붙인다. 예전 `3dkit.config.json`과 카탈로그는 보존한다. 새 파일 분리는 예전 경로·팔레트와 승인 예산이 이번 작업에 섞이지 않게 하기 위한 방법이다.
- 공급자 옵션: `tripo-v3.1`, 에셋별 고정 seed, 후보 1개, `smart_low_poly=false`, `face_limit=<개별 상한>`, `texture=true`, `pbr=true`, `texture_quality=detailed`, `quad=false`. 실제 별칭 해석·견적은 각 `output/3d-art/dq-env/<id>/tripo/estimate.json`, 제출 옵션·입력 지문은 `request-frozen.json`에 보관한다. 생성 호출에 별도 프롬프트 필드가 없으므로 승인 컨셉 이미지를 입력으로 삼는다. 강한 그림자·광택 제외는 이미지와 최종 무광 재질로 관리하며 공급자 옵션으로 강제했다고 주장하지 않는다.
- 기하·텍스처: 나무 3,000삼각형·1024², 덤불 1,200·512², 큰 바위 1,500·512², 작은 돌 600·512². 기준서 3.6절에는 에셋별 수치가 없어 이번 지시의 목표를 쓴다. 기본색·UV 필요, 원본 노멀·ORM은 보존하되 최종 슬롯·무광 재질은 다음 Unity 단계에서 확인한다.
- 크기·좌표: 표의 키·폭을 m로 맞추고 표에 없는 깊이는 비율 보존. 바닥 중앙이 원점, +Y 위, 정면 +Z. 둘 이상의 치수가 지정된 경우 폭과 높이를 함께 맞추되 왜곡 배율을 기록한다. Blender가 실행되지 않으면 지시대로 **원본 GLB만** 전달하고 치수·원점·텍스처 크기 보정을 완료로 처리하지 않는다.
- 형태·색: 표의 분리된 잎 뭉치와 붙은 줄기, 바위의 둥근 실루엣을 보존한다. K41의 잎 카드는 생성 결과로 보장되지 않으므로 이 단계에서 준수로 판정하지 않는다. 생성사 미리보기와 18° 시점 확인 결과를 별도로 기록하며 최종 채택은 사람이 한다. 수관 색 K40 보정은 다음 단계에 방법을 넘긴다.

### 실행 중 확인한 제한·워크플로우 갱신 (이 요청에 적용)

- 입력 그림 10장은 manifest 지문과 일치하고 단일 입력 검사에 모두 통과해 배경 정리 사본은 만들지 않았다.
- Tripo `face_limit`은 이번 10개 최초 결과에서 목표 이하였으나 질감은 4096²로 왔다. **공급자 기하 목표 통과는 모바일 텍스처·치수 또는 시각 품질 통과가 아니다.**
- Blender는 Python 실행 전 Metal 초기화에서 충돌한다. 대체 그래픽 백엔드는 설치에서 지원하지 않는다. 후처리를 완료로 적지 않고 지시의 원본 GLB 전달 경로를 쓴다.
- 워크플로우 갱신 후보 → **이 요청에 반영**: 최초 1개 견적 때 Blender 시작 확인을 함께 해 후처리 가능 여부를 선확인한다. 고정된 시점의 공급자 미리보기만으로 게임 카메라 판정을 통과시키지 않는다. 추가 검사는 도입하지 않았고 중복 전체 Play·Unity 검사는 이 단계에서 실행하지 않는다.
- 시간·토큰 집계 도구 `Tools/Harness/session_time.py --markdown`은 최근 Claude 세션을 기본으로 잡았다. 그 표는 이번 Codex 시간으로 인용하지 않는다. 이번 실행은 현재 Codex thread의 토큰 이벤트와 실행 로그 시각을 별도로 기록한다.
