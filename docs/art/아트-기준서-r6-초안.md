# 아트 기준서 r6 초안 (HD-2D 전환 2단계)

- **상태: 초안 — 1단계 시안 고르기 전, 미승인. 승인된 기준서는 r5**([아트 기준서](아트-기준서.md)). 이 파일은 r5를 고치지 않는다. 승인되면 아래 행을 r5 본문에 옮기고 개정 기록(4절)에 r6을 적는다.
- 작성: 2026-11-18, Claude(하위 에이전트, 디렉터 지시). 사용자에게 아직 묻지 않았다. 갈림길은 `【시안 뒤 확정】` 칸에 후보로 남겼다.
- 범위: [HD-2D 전환 계획](../game/hd2d-전환-계획.md) 5절 2단계 "바뀌는 항목" 표의 절과 새 절만 적는다. 그대로 두는 항목은 5절, 계획이 "그대로"로 뒀지만 뜻이 바뀌는 항목은 6절이다.
- 근거 문서:
  - [HD-2D 사전 조사](../game/hd2d-사전조사.md) — 결정 D1~D16(1절), 기술(2절), 프로젝트 사실(3절), 카메라 계산(4절), 레퍼런스 값(5.2절), 모르는 것(8절)
  - [HD-2D 기법 관찰](reference/hd2d-study-20261117/hd2d-관찰.md) — HD-R001~R010
  - [HD-2D 전환 계획](../game/hd2d-전환-계획.md) 3절(목표 화면), 5절 2단계
- **레퍼런스 모드(r6에서 더하는 줄)**: 그림의 기준은 그대로 컨셉 PE-G001~G004 `follow`. HD-2D 스크린샷 HD-R001~R010은 `study` — 기법 값(카메라·흐림·빛·그림자·도트 대 3D 비율)만 보고, 캐릭터·에셋·UI·이름·구도·팔레트는 가져오지 않는다(관찰 문서 "가져오지 않는 것"). study 값이라 사용자 승인으로 확정한다(`art-decisions.md` 2절).
- 표기: `[레퍼런스]` 관찰 값, `[레퍼런스·해석]` 관찰 문서의 해석/제안, `[방법]` 에이전트가 정한 제작 방법, `[사용자]` 사용자 결정, `추정` 재지 않은 숫자, `[계산]` 사전 조사 4절 공식으로 계산한 값.
- 단위(r6에서 더함): **1유닛 = 1m, 캐릭터 키 48px = 1.0m**(사전 조사 3.3절 "1유닛 = 1m 가정"을 기준으로 굳힌다, `[방법]`). 예전 3D(046)는 영웅 0.8m라 예전 모델은 ×1.25로 옮긴다[계산].
