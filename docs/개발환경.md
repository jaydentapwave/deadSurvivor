이전 Documents/ChatGPT/데드 서바이버 경로는 물리적 호환 진입점이다. `.git` 포인터와 문서/도구/출력 링크가 같은 실제 작업 폴더를 가리키며 Git core.worktree는 Desktop 루트로 고정돼 있다. 파일/저장소 사본이 아니다. 이 진입점에는 Assets/Packages/ProjectSettings 링크를 두지 않아 Unity 프로젝트로 다시 열리는 혼동을 막는다. 새 Codex 작업에서도 Desktop 경로를 프로젝트로 선택한다. 과거 JSON/asset job은 원문/해시를 보존한다. 도구는 정확히 승인된 이전 루트만 재해석하며 임의의 alias·내부 symlink·경로 이탈은 계속 거부한다.

원격은 사용자 지정 [deadSurvivor](https://github.com/jaydentapwave/deadSurvivor), 기본 브랜치는 main이다. 연결된 GitHub 작성자와 noreply 이메일을 저장소에만 설정했고 전역 설정은 바꾸지 않는다. 클라우드 조직/프로젝트 식별자 두 값은 원본 백업 후 비웠고 cloudEnabled0 및 다른 사용자 설정은 보존했다.

.gitignore는 캐시·빌드·앱·기존1029.zip·Burst 디버그·검증 캡처·로컬 도구/상태를 제외한다. Assets/Packages/ProjectSettings와 필요한 .meta/lock은 포함한다. Art/Tests의 바위와 기존 검증 기준 자료를 통째로 제외하지 않는다. 기존 gate baseline은 갱신하지 않으며 현재 소스의 새 실행 증거를 요구한다.
