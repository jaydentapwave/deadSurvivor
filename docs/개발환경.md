Unity 추가 전 `.gitignore`는 캐시·빌드/실행 앱·기존 빌드 압축본 `1029.zip`·Burst 디버그 출력·검증 캡처 `MigrationVerification`·복제 참고본 `MigrationReference`·개인 IDE/의존성 폴더·로그/메모리 캡처/녹화·Blender 백업을 제외한다.
